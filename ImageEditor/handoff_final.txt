1. VISÃO GERAL DO PROJETO
================================================================================

Editor de imagens profissional no estilo Paint 3D, implementado em um unico
arquivo HTML (~4046 linhas). Suporta desenho a lapis, borracha, caneta
temporaria (que some), ferramenta mao para navegacao, zoom, e um sistema
completo de image stamps (carimbos) com 9 slots configuraveis, efeitos
visuais (blink, wobble, fadeIn, fadeOut), suporte a GIFs, undo/redo, 
export/import de projetos (.json), autosave com restauracao automatica
de sessao via localStorage.

2. ARQUITETURA ADOTADA
================================================================================

2.1. Orquestrador (App)
  - Classe principal que cria e coordena todos os managers.
  - Gerencia eventos de alto nivel (keyboard, mouse, resize).
  - Responsavel por inicializacao e disposicao (cleanup).

2.2. Managers
  Cada manager tem uma responsabilidade unica e clara:

  - EventBus: Pub/sub para comunicacao desacoplada entre modulos.
  - NotificationManager: Exibe notificacoes padronizadas (info, success, error, warning).
  - KeybindManager: Gerencia atalhos de teclado com persistencia em localStorage.
  - HistoryManager: Undo/Redo com suporte a strokes de desenho e Command objects.
  - CanvasManager: Zoom, pan, transformacao da tela.
  - LayerManager: Gerenciamento das camadas de canvas (background, permanent, temp, fading).
  - ToolManager: Registro e ativacao de ferramentas (Pencil, Eraser, FadingPen, Hand).
  - UIManager: Atualizacao da interface (status bar, tool options).
  - SettingsManager: Modal de configuracoes, renderizacao de keybinds e slots.
  - InputManager: Captura de eventos de teclado e mouse.
  - ImageStampManager: CRUD de stamps, renderizacao DOM, hit testing, validacao de estado.
  - StampSettingsManager: Configuracao dos 9 slots (imagem, tamanho, efeitos, keybind).
  - StampEffectManager: Definicao e validacao de efeitos (fadeIn, fadeOut, blink, wobble).
  - StampPersistenceAdapter: Adaptador para serializacao de stamps + settings.
  - ProjectPersistenceManager: Export/Import de projetos .json.
  - SessionPersistenceManager: Autosave e restauracao automatica via localStorage.
  - CursorManager: Cursor customizado com anel duplo e crosshair.
  - StampPreviewManager: Preview de stamp ao segurar tecla do slot.

2.3. Models (dados)
  - EditorState: Objeto global contendo TODO o estado da aplicacao.
    * canvas (scale, offset, image, dimensions)
    * tools (activeTool, isDrawing, fadingStrokes)
    * history (undoStack, redoStack, maxHistory)
    * stamps (list, nextZIndex)
    * stampSettings (slots, defaultSizePercent)
    * preview (activeSlot, isActive, effectState)
    * settings (keybinds, defaultKeybinds)
    * ui (isOptionsOpen)
    * input (deleteModeActive, moveModeActive, draggingStampId)

2.4. Commands (padrao Command)
  - AddStampCommand: Adiciona um novo stamp.
  - RemoveStampCommand: Remove um stamp existente.
  - MoveStampCommand: Move um stamp para nova posicao.
  - ReplaceSlotStampsCommand: Substitui stamps de um slot com novas configs.
  - Todos implementam: execute(), undo(), redo(), serialize(), deserialize().

2.5. Utilities
  - clamp(), debounce(), throttle(), lerp(), uuid()
  - screenToWorld(), worldToScreen(), getCanvasCoords()
  - formatKeybindDisplay()
  - assert() para desenvolvimento
  - debug.log/warn/error() para logging condicional

2.6. UI Controllers (dentro dos managers)
  - SettingsManager controla o modal e renderizacao dos slots.
  - UIManager controla status bar e tool options.
  - StampPreviewManager controla a preview layer.

2.7. Persistence Systems
  - KeybindManager: localStorage key 'image-editor-keybinds'
  - StampSettingsManager: localStorage key 'image-editor-stamp-slots'
  - ProjectPersistenceManager: Export/Import .json (download/upload)
  - SessionPersistenceManager: localStorage key 'image_editor_autosave'

6. FLUXO COMPLETO DOS IMAGE STAMPS
================================================================================

6.1. Configuracao do Slot
  1. Usuario abre Configuracoes > Image Slots.
  2. Seleciona um slot (1-9).
  3. Faz upload de imagem ou insere URL.
  4. Configura tamanho, efeitos, keybind.
  5. StampSettingsManager.setSlot() salva no localStorage e emite STAMP_SETTINGS_CHANGED.

6.2. Preview
  1. Usuario pressiona tecla do slot (ex: "1").
  2. StampPreviewManager._onKeyDown() detecta tecla.
  3. _activatePreview() cria elemento <img> na stamp-preview-layer.
  4. Aplica tamanho, efeito de surgimento (fadeIn) e efeito continuo (blink/wobble).
  5. Preview segue o mouse ate o usuario soltar a tecla.

6.3. Insercao
  1. Usuario clica com o mouse (botao esquerdo) enquanto segura a tecla do slot.
  2. _tryInsertStamp() verifica mouse button down e ferramenta ativa = "hand".
  3. _insertStamp() calcula posicao world e dimensoes (com aspect ratio).
  4. Cria AddStampCommand e executa via HistoryManager.pushCommand().
  5. ImageStampManager.add() adiciona ao EditorState.stamps.list e emite STAMP_ADDED.

6.4. Remocao
  1. Usuario pressiona X (delete-stamp-mode).
  2. Cursor muda para crosshair, modo delete ativo.
  3. Clica em um stamp existente.
  4. RemoveStampCommand e executado via HistoryManager.pushCommand().

6.5. Movimentacao
  1. Usuario pressiona V (move-stamp-mode).
  2. Cursor muda para move, modo move ativo.
  3. Clica e arrasta um stamp existente.
  4. Durante o arrasto: ImageStampManager.moveStamp() atualiza posicao e emite STAMP_MODIFIED.
  5. Ao soltar: MoveStampCommand registrado no historico (se posicao mudou).

6.6. Substituicao em Massa
  1. Usuario altera configuracao de slot com "Replace Existing Stamps" ativo.
  2. SettingsManager._checkSlotReplaceConfirmation() exibe confirmacao.
  3. ReplaceSlotStampsCommand substitui todos os stamps do slot com novas configs.
  4. Aspect ratio e preservado (fix aplicado na Etapa 10).

7. FUNCIONAMENTO DO HISTORICO
================================================================================

  - HistoryManager mantem duas pilhas: undoStack e redoStack.
  - Maximo: 50 entradas (configuravel em EditorState.history.maxHistory).
  - Suporta dois tipos de entrada:
    * Strokes de desenho: objetos simples com pontos, tamanho, cor.
    * Command objects: instancias de Command (stamp operations).
  - Command objects sao serializaveis via serialize()/deserialize().
  - Apos cada operacao, emite HISTORY_CHANGED e atualiza botoes Undo/Redo.
  - clear() reinicia ambas as pilhas.
  - restoreHistory() reconstroi o historico a partir de dados serializados.

================================================================================
8. FUNCIONAMENTO DO SISTEMA JSON (EXPORT/IMPORT)
================================================================================

8.1. Export
  - ProjectPersistenceManager.buildProjectSnapshot() gera snapshot completo:
    * canvasState (scale, offset, imageData como data URL, nome, dimensoes)
    * keybindSettings
    * stampSlotConfigurations
    * stamps (array completo com todos os dados)
    * historyState (undoStack + redoStack serializados)
  - exportProject() serializa como JSON, cria blob, faz download.

8.2. Import
  - importProject() abre seletor de arquivos.
  - _handleImportFile() le o arquivo, faz parse.
  - _executeImport() valida, sanitiza, pergunta confirmacao, restaura.
  - validateProject() verifica versao e sanitiza dados:
    * Remove duplicatas de ID
    * Preenche campos faltantes
    * Resolve conflitos de keybind
  - _restoreProject() limpa estado atual e recria tudo.
  - _finishRestore() restaura keybinds, slots, stamps, historico, UI.

9. FUNCIONAMENTO DO AUTOSAVE
================================================================================

  - SessionPersistenceManager gerencia autosave via localStorage.
  - Chave: 'image_editor_autosave'
  - Versao atual: 1
  - Debounce: 1000ms (evita escritas excessivas)
  - Limite: 4MB (soft-fail com warning)
  - Acionado por: STAMP_ADDED, STAMP_REMOVED, STAMP_MODIFIED (sem drag),
    STAMP_SETTINGS_CHANGED, IMAGE_LOADED
  - Reutiliza ProjectPersistenceManager.buildProjectSnapshot().
  - Indicador visual na status bar: "Saving...", "Saved", "Too large", "Save error".
  - Ao abrir o editor: verifica sessao salva, exibe dialogo de restauracao.
  - restoreSession() valida dados, limpa sessao, chama _restoreProject().
  - validateSessionData() verifica: objeto valido, versao, savedAt, projectData.

13. PONTOS CRITICOS QUE EXIGEM CUIDADO
================================================================================

  1. EditorState e a unica fonte da verdade. NUNCA confiar no DOM para estado.
  2. Stamp ID deve ser unico. Usar crypto.randomUUID() ou uuid().
  3. Nao chamar performAutosave() diretamente; usar scheduleAutosave() (debounce).
  4. restoreSession() chama clearSession() ANTES de _restoreProject().
  5. Nao salvar durante arrasto de stamps (verificar draggingStampId).
  6. Apos importar projeto, sessao e limpa e novo autosave e disparado.
  7. ImageStampManager._stampElements deve sempre refletir stamps.list.
  8. validateState() verifica consistencia stamp<->DOM (apenas em DEBUG_MODE).
  9. Debug mode desligado por padrao (DEBUG_MODE=false). Ativar com window.__DEBUG__=true.
  10. custom confirm dialog (confirmAsync) substitui nativo confirm().
  11. Canvas rect cache (_canvasRectCache) deve ser invalidado em resize/transform.
  12. ReplaceSlotStampsCommand preserva aspect ratio dos stamps existentes.
  13. StampPreviewManager deve ser destroy()/dispose() ao limpar.
  14. EventBus listeners retornam funcao de unsubscribe (sempre usar se possivel).
  15. dispose() em todos os managers para cleanup adequado.
