================================================================================
1. RESUMO DA ETAPA
================================================================================

Esta etapa implementou o sistema de preview das imagens dos slots 1-9
acompanhando o cursor em tempo real.

Ao pressionar e segurar a keybind configurada de um slot (padrao: teclas 1-9),
a imagem configurada aparece seguindo o cursor continuamente. Ao soltar a tecla,
a imagem desaparece. NENHUMA imagem e inserida permanentemente no editor nesta
etapa.

Todas as funcionalidades existentes (lapis, borracha, caneta que some, zoom,
pan, historico, keybinds, configuracao dos slots) continuam funcionando
exatamente como antes.

================================================================================
2. FUNCIONALIDADES IMPLEMENTADAS
================================================================================

2.1. PREVIEW NO CURSOR AO SEGURAR TECLA DO SLOT

  - Ao pressionar a keybind de um slot (1-9 por padrao):
    * A imagem configurada aparece centralizada no cursor
    * Funciona tanto com imagens de upload quanto com links

  - Ao soltar a tecla:
    * A imagem desaparece (instantaneamente ou com fade out)
    * NENHUMA imagem permanece no canvas

  - A imagem respeita o sizePercent configurado no slot
  - A largura da imagem e calculada automaticamente para manter a
    proporcao original (aspect ratio) da imagem

2.2. REGRA DE PRIORIDADE ENTRE SLOTS (MAIS RECENTE VENCE)

  - Se o usuario pressiona a tecla do Slot 1, a imagem do Slot 1 aparece
  - Se o usuario entao pressiona a tecla do Slot 2 (enquanto ainda segura
    a tecla do Slot 1), a imagem do Slot 2 SUBSTITUI IMEDIATAMENTE a do Slot 1
  - Ao soltar a tecla do Slot 2, NENHUMA imagem reaparece automaticamente
    (a imagem do Slot 1 NAO volta)
  - Implementado via controle de _heldSlots (Set) + _activeSlot (unico)

2.3. STAMP PREVIEW MANAGER (NOVO MANAGER)

  - Nome: StampPreviewManager
  - Responsabilidades:
    * Detectar slots ativos via keydown/keyup
    * Criar previews (elementos <img>)
    * Destruir previews (com ou sem efeito de desaparecimento)
    * Acompanhar o cursor continuamente (via mousemove)
    * Atualizar tamanho dinamicamente (com base na altura do canvas-area)
    * Coordenar efeitos de surgimento (fade in) e desaparecimento (fade out)
    * Coordenar efeitos continuos (piscar e balancar)
    * Impedir multiplos previews simultaneos
    * Preparar integracao futura com insercao permanente

2.4. STAMP PREVIEW LAYER (NOVA CAMADA DEDICADA)

  - ID: stamp-preview-layer
  - Elemento <div> dentro de #canvas-container, apos #image-stamp-layer
  - Posicionamento absoluto, sem bloquear cliques (pointer-events: none)
  - z-index: 10 (acima do image-stamp-layer que tem z-index: 5)
  - Acompanha zoom e pan automaticamente por estar dentro do canvas-container
  - Permanece oculta (display: none) quando nenhum preview esta ativo

2.5. EFEITO DE SURGIMENTO - FADE IN

  - Quando config.appearEffect === 'fadeIn':
    * A imagem inicia com opacity: 0
    * Transiciona para opacity: 1 com duracao configurada (effectSettings.appearDuration)
    * Usa CSS transition: 'opacity ${duration}ms ease'

2.6. EFEITO DE SURGIMENTO - PADRAO

  - Quando config.appearEffect nao e 'fadeIn':
    * A imagem aparece instantaneamente (sem animacao)

2.7. EFEITO DE DESAPARECIMENTO - FADE OUT

  - Quando config.disappearEffect === 'fadeOut':
    * A imagem CONGELA na posicao atual (para de seguir o cursor)
    * Executa animacao de opacidade ate 0
    * Remove o elemento APENAS apos a conclusao do efeito (setTimeout)
    * Duracao: effectSettings.disappearDuration (padrao 300ms)

2.8. EFEITO DE DESAPARECIMENTO - PADRAO

  - Quando config.disappearEffect nao e 'fadeOut' OU deactivacao for
    'immediate' (substituicao por outro slot, blur, etc.):
    * A imagem desaparece instantaneamente
    * Elemento removido imediatamente do DOM

2.9. EFEITO CONTINUO - PISCAR (BLINK)

  - Configuracoes:
    * Velocidade do piscar (blinkSpeed): 100-2000ms
    * Tempo visivel (blinkVisibleTime): 50-2000ms
    * Tempo invisivel (blinkInvisibleTime): 50-2000ms

  - Implementado via requestAnimationFrame:
    * Alterna opacity entre '1' e '0' baseado nos tempos configurados
    * Para automaticamente quando o preview e desativado
    * Nao causa travamentos

2.10. EFEITO CONTINUO - BALANCAR (WOBBLE)

  - Configuracao:
    * Intensidade: 1% a 100% (effectSettings.wobbleIntensity)
    * 50% = comportamento original (intensidade padrao de referencia)

  - Implementado via requestAnimationFrame:
    * Aplica transform: translate(tx, ty) rotate(rot)
    * Usa Math.sin para criar oscilacao suave
    * Intensidade mapeia linearmente: factor = intensity / 50
    * Em 50%: translate ~5px, rotate ~5deg
    * Duracao do ciclo: 400ms / factor (mais intenso = mais rapido)
    * Para automaticamente quando o preview e desativado

2.11. SUPORTE A GIFS

  - GIFs permanecem animados durante o preview
  - Como usamos <img> em vez de canvas, a animacao nativa do GIF e preservada
  - Funciona tanto para uploads (data URI) quanto para links (URL)

2.12. SUPORTE A LINKS E UPLOADS

  - Imagens de URL funcionam normalmente no preview
  - Imagens de upload (data URI) funcionam normalmente no preview

2.13. REACAO AO REDIMENSIONAMENTO

  - Quando a janela e redimensionada:
    * O preview recalcula automaticamente suas dimensoes
    * A posicao e reajustada
    * O tamanho e baseado na nova altura do canvas-area

2.14. INTEGRACAO COM KEYBINDS

  - O StampPreviewManager escuta keydown/keyup no document
  - Detecta conflitos com INPUT/TEXTAREA (ignora se focus estiver em campo)
  - Rejeita teclas do numpad (e.location === 3)
  - Ignora modifiers (control, alt, shift, meta)
  - Ignora key repeat (e.repeat)
  - Chama e.preventDefault() quando um slot e ativado
  - A KeybindManager existente continua responsavel pelos atalhos de ferramentas
  - Nao interfere com a KeybindManager (slot keys nao conflitam com tool keys)

2.15. ESTADO GLOBAL ATUALIZADO

  - Adicionado EditorState.preview:
    {
      activeSlot: null,    // Slot atualmente em preview (1-9 ou null)
      isActive: false,     // Se algum preview esta ativo
      effectState: {},     // Estado interno dos efeitos (reservado)
      lastBind: null,      // Ultima keybind que ativou o preview
    }

4. COMPORTAMENTO DAS KEYBINDS DE SLOT
================================================================================

4.1. DETECCAO

  - O StampPreviewManager escuta keydown/keyup em document
  - Converte e.key para lowercase
  - Ignora keys de comprimento > 1 exceto espaco (F1-F12, Enter, etc.)
  - Ignora modifier keys (ctrl, alt, shift, meta)
  - Ignora e.repeat (repeticao automatica)
  - Ignora numpad (e.location === 3)
  - Ignora quando focus esta em INPUT ou TEXTAREA
  - Compara a key normalizada contra config.keybind de cada slot

4.2. FLUXO

  1. Usuario pressiona tecla (ex: "1")
  2. KeybindManager.handleKeyDown() roda primeiro (getActionForKey retorna null)
  3. StampPreviewManager._onKeyDown() detecta slot correspondente
  4. Verifica se slot tem imagem configurada (config.source != null)
  5. Adiciona slot a _heldSlots
  6. Se slot e diferente de _activeSlot, ativa preview
  7. Usuario solta tecla
  8. Remove slot de _heldSlots
  9. Se slot solto == _activeSlot, desativa preview

4.3. NUMPAD

  - Keyboards events com location === 3 (numpad) sao rejeitados
  - Apenas a fileira superior de teclas funciona para slots

================================================================================
5. POSICIONAMENTO DO PREVIEW
================================================================================

  A imagem e centralizada exatamente sobre o cursor usando coordenadas world:

    worldX = (clientX - rect.left - offsetX) / scale
    worldY = (clientY - rect.top - offsetY) / scale

    img.style.left = worldX - imgWidth/2
    img.style.top = worldY - imgHeight/2

  Como a stamp-preview-layer esta dentro do canvas-container (que possui
  transform: translate + scale), as coordenadas world sao automaticamente
  mapeadas para a tela pelo navegador.

================================================================================
6. TAMANHO DO PREVIEW
================================================================================

  O tamanho e calculado com base na altura do canvas-area:

    height = canvasArea.clientHeight * (sizePercent / 100)

  A largura e calculada para manter a proporcao original:

    width = height * (naturalWidth / naturalHeight)

  O aspecto ratio e obtido do elemento <img> apos carregamento
  (img.naturalWidth / img.naturalHeight).

  Se a imagem ainda nao carregou:
    - A altura e definida
    - A largura fica como 'auto' (deixando o navegador calcular)
    - Quando a imagem carrega (onload), a largura e atualizada

================================================================================
7. EFICOS
================================================================================

7.1. FADE IN

  - opacity: 0 -> 1 com CSS transition
  - Forca reflow (void element.offsetWidth) para garantir que a transicao
    seja executada
  - Duracao: effectSettings.appearDuration (100-2000ms, padrao 300ms)

7.2. FADE OUT

  - opacity: 1 -> 0 com CSS transition
  - Durante o fade out, a imagem para de seguir o cursor (_fadingOut = true)
  - Elemento removido apos duracao configurada via setTimeout
  - Duracao: effectSettings.disappearDuration (100-2000ms, padrao 300ms)
  - Se a desativacao e 'immediate' (troca de slot, blur), nao executa fade out

7.3. PISCAR (BLINK)

  - Loop via requestAnimationFrame
  - Alterna opacity entre '1' e '0'
  - Tempos: blinkVisibleTime (visivel) e blinkInvisibleTime (invisivel)
  - Velocidade geral: blinkSpeed (usado apenas como referencia visual na
    configuracao, o efeito usa visibleTime + invisibleTime)
  - Para automaticamente quando preview e desativado ou _fadingOut

7.4. BALANCAR (WOBBLE)

  - Loop via requestAnimationFrame
  - Aplica transform: translate(tx, ty) rotate(rot)
  - Usa Math.sin para oscilacao senoidal
  - Intensidade controla amplitude: factor = intensity / 50
  - Duracao do ciclo: 400 / factor (ms)
  - Para automaticamente quando preview e desativado ou _fadingOut
