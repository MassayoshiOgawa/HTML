2. NOVOS COMPONENTES IMPLEMENTADOS
================================================================================

2.1. IMAGE STAMP LAYER (DOM)

  <div id="image-stamp-layer"></div>

  - Adicionado dentro de #canvas-container, apos o ultimo canvas (#layer-fading)
  - Referenciado via DOM['image-stamp-layer']
  - CSS: position absolute, top/left 0, width/height 0, pointer-events none, z-index 5
  - Acompanha automaticamente zoom e pan pois herda a transformacao do container
  - Permanece vazia nesta etapa (sem elementos filhos)

2.2. ImageStampManager (classe)

  Responsavel por gerenciar todas as imagens permanentes (stamps).

  Metodos:
    add(stampData)           - Adiciona stamp com ID unico e zIndex auto-incrementado
    remove(id)               - Remove stamp por ID
    getById(id)              - Busca stamp por ID
    getBySlot(slot)          - Retorna todos os stamps de um slot (1-9)
    getAll()                 - Retorna todos os stamps ordenados por zIndex
    replaceSlot(slot, data)  - Remove stamps de um slot e adiciona novo
    clear()                  - Remove todos os stamps e reseta nextZIndex
    toExportData()           - Prepara dados para exportacao futura

  Eventos emitidos:
    STAMP_ADDED   ('stamp:added')   - ao adicionar stamp
    STAMP_REMOVED ('stamp:removed') - ao remover stamp(s)

  Dependencias: EventBus

2.3. StampSettingsManager (classe)

  Responsavel pelas configuracoes dos slots 1-9.

  Metodos:
    getDefaultSlotConfig(slot) - Retorna configuracao padrao para um slot
    getSlot(slot)              - Retorna configuracao de um slot (cria se nao existir)
    setSlot(slot, config)      - Define configuracao de um slot
    getAllSlots()              - Retorna configuracoes de todos os slots 1-9
    resetSlot(slot)            - Reseta configuracao de um slot para o padrao
    toExportData()             - Prepara dados para exportacao futura

  Eventos emitidos:
    STAMP_SETTINGS_CHANGED ('stamp:settings-changed') - ao alterar configuracao

  Dependencias: EventBus

2.4. StampEffectManager (classe)

  Responsavel por definir a arquitetura de efeitos futuros.

  NENHUM efeito foi implementado. Apenas a estrutura de definicao.

  Efeitos definidos (estrutura apenas):
    fadeIn  - tipo 'appear',   default: { duration: 300 }
    fadeOut - tipo 'disappear', default: { duration: 300 }
    blink   - tipo 'image',     default: { interval: 500, count: 3 }
    wobble  - tipo 'image',     default: { amplitude: 5, duration: 400 }

  Metodos:
    getEffect(name)           - Retorna definicao de um efeito
    getEffectsByType(type)    - Retorna efeitos de um tipo especifico
    validateSettings(name, s) - Valida configuracoes de um efeito
    getAllEffects()           - Retorna todos os efeitos disponiveis

  Dependencias: nenhuma

2.5. StampPersistenceAdapter (classe)

  Nao implementa save/load real. Apenas prepara arquitetura.

  Metodos:
    toJSON()   - Prepara dados de stamps + settings + nextZIndex para exportacao
    fromJSON() - Prepara estrutura para importacao de dados (nao modifica estado)

  Dependencias: ImageStampManager, StampSettingsManager

2.6. STAMP COMMANDS (classes)

  Quatro classes de comando preparadas para futura integracao com Undo/Redo:

    AddStampCommand
      - Armazena stampData
      - execute(): adiciona stamp, guarda ID gerado
      - undo(): remove stamp pelo ID

    RemoveStampCommand
      - Armazena stampId
      - execute(): remove stamp, guarda dados removidos
      - undo(): readiciona stamp com dados salvos

    MoveStampCommand
      - Armazena stampId, oldX, oldY, newX, newY
      - execute(): move para newX/newY
      - undo(): move para oldX/oldY

    ReplaceStampCommand
      - Armazena slot, newStampData, oldStamps
      - execute(): salva stamps antigos, remove todos do slot, adiciona novo
      - undo(): remove novo, readiciona antigos

  Observacao: NAO integrados ao HistoryManager nesta etapa.

4. MODELOS DE DADOS
================================================================================

4.1. StampEntity

  {
    id:          string (UUID v4),
    slot:        number (0-9, 0 = sem slot),
    src:         string (URL ou data URI da imagem),
    sourceType:  string ('url' | 'datauri' | 'clipboard'),
    worldX:      number (coordenada X no espaco do mundo),
    worldY:      number (coordenada Y no espaco do mundo),
    width:       number (largura em pixels do mundo),
    height:      number (altura em pixels do mundo),
    zIndex:      number (ordem de sobreposicao, auto-incrementado),
    appearEffect:       string|null,
    appearSettings:     object|null,
    disappearEffect:    string|null,
    disappearSettings:  object|null,
    imageEffect:        string|null,
    imageEffectSettings: object|null,
    createdAt:   number (timestamp Date.now())
  }

4.2. SlotConfiguration

  {
    slot:           number (1-9),
    keybind:        string (tecla associada, padrao: '1'-'9'),
    source:         string|null (fonte da imagem),
    sourceType:     string|null ('url' | 'datauri' | 'clipboard'),
    sizePercent:    number (tamanho percentual, padrao: 15),
    appearEffect:   string|null,
    disappearEffect: string|null,
    imageEffect:    string|null,
    effectSettings: object,
  }
