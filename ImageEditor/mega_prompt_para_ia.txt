## INSTRUÇÃO GERAL

Você deve gerar um ÚNICO documento HTML contendo TODO o CSS e JavaScript embutido. Nenhum arquivo externo. O documento deve ser um site de edição de imagem profissional, inspirado visualmente no **Paint 3D da Microsoft**, com layout moderno, escuro/acizentado, toolbars flutuantes, glassmorphism sutil e animações suaves.

O JavaScript deve ser estruturado de forma modular e profissional, utilizando classes ou objetos especializados para cada subsistema, preparando o código para receber dezenas de novas ferramentas e funcionalidades futuras sem necessidade de reescrita.

## FUNCIONALIDADES PRINCIPAIS

### 1. UPLOAD DE IMAGEM COMO BACKGROUND
- O usuário faz upload de uma imagem (PNG, JPG, JPEG, WebP).
- A imagem imediatamente se torna o "background" do canvas central.
- A imagem deve ocupar o canvas inteiro, centralizada, mantendo proporção (cover ou contain — escolha contain para não cortar).
- Se nenhuma imagem for carregada, o canvas deve exibir um grid quadriculado (xadrez cinza claro/branco) como placeholder, com um texto central "Arraste ou clique para enviar uma imagem" e um ícone de upload estilizado.

### 2. ZOOM
- O usuário pode dar zoom em QUALQUER área da imagem.
- Zoom deve ser controlado por:
  - Scroll do mouse (roda) — zoom in/out suave.
  - Botão + e - na toolbar inferior ou lateral.
  - Slider de zoom na barra de status.
- O zoom deve ser suave (transição CSS ou requestAnimationFrame).
- O zoom deve focar na posição do cursor do mouse (zoom hacia o ponto onde o mouse está, não apenas no centro).
- O canvas deve ser um container com overflow hidden, e a imagem deve ser transformada via transform: scale() e translate().
- O fundo quadriculado (xadrez) deve ser visível nas bordas quando a imagem não preencher todo o canvas.
- O zoom mínimo deve ser 10% e o máximo 1000%.
- Exibir percentual do zoom em algum lugar (canto ou barra de status).

### 3. FERRAMENTAS DE EDIÇÃO (4 FERRAMENTAS)

#### 3.1. LÁPIS (Pencil)
- Desenha riscos livres na imagem.
- Cor: preto (por enquanto, futuro terá seletor de cor).
- Input range para controlar a grossura (1px a 50px).
- O desenho deve ser feito em uma camada (canvas) sobreposta à imagem de background.
- O cursor do mouse deve mudar para um ícone de lápis (ou um círculo do tamanho da grossura).

#### 3.2. BORRACHA (Eraser)
- Apaga os traços feitos pelo lápis/caneta.
- Input range para definir o tamanho da borracha (5px a 100px).
- Deve funcionar como a borracha do Paint: clica e arrasta para apagar.
- A borracha deve revelar a imagem original por baixo (deve apagar os desenhos da camada sobreposta, não a imagem em si).
- O cursor deve ser um quadrado ou círculo do tamanho definido.

#### 3.3. CANETA QUE SOME (Fading Pen)
- Rabisca igual ao lápis, mas os traços desaparecem após um tempo.
- Dois inputs range:
  - Grossura (1px a 50px).
  - Tempo na tela (0.5s a 10s).
- Implementação: cada segmento de traço deve ser desenhado com opacidade e timer. Use requestAnimationFrame ou setInterval para reduzir a opacidade gradualmente até 0 e então remover.
- Alternativa: usar trail de partículas ou stroke com fade-out animado via alpha.
- O efeito deve ser suave, os traços devem sumir gradativamente (não sumir de uma vez).
- Mesma cor: preta (futuro terá seletor).

#### 3.4. FERRAMENTA DE NAVEGAÇÃO — HAND TOOL
- Ferramenta específica para movimentação da área de trabalho (pan).
- Ícone próprio (mão) na toolbar.
- Atalho padrão: H.
- Permitir arrastar a área visível da imagem em qualquer direção.
- Funcionar corretamente em qualquer nível de zoom.
- Cursor apropriado:
  - Padrão: cursor "grab".
  - Enquanto arrasta: cursor "grabbing".
- Não interferir com ferramentas de desenho (ao trocar para hand tool, o desenho não deve ser afetado).
- O pan deve ser suave e responsivo.

### 4. SELEÇÃO DE FERRAMENTAS
- Toolbar vertical ou horizontal com ícones das 4 ferramentas.
- A ferramenta ativa deve estar destacada (cor diferente, brilho, borda).
- Ícones: use SVG inline ou Unicode. Exemplos:
  - Lápis: ✏️ ou ícone SVG de lápis.
  - Borracha: 🟤 ou ícone SVG.
  - Caneta: 🖊️ ou ícone SVG.
  - Mão: ✋ ou ícone SVG.
- Atalhos de teclado:
  - P = Lápis
  - E = Borracha
  - F = Caneta que some
  - H = Hand tool (mão)
  - Ctrl+Z = Desfazer último traço
  - Ctrl+Y = Refazer último traço desfeito

### 5. BOTÃO DE CONFIGURAÇÕES
- Ícone de engrenagem ⚙️ no canto superior direito ou na toolbar.
- Ao clicar, abre um painel/modal/overlay com opções.
- Dentro do painel, DEVE TER:
  - Botão "Enviar Nova Imagem" (input file hidden + botão estilizado).
  - Ao selecionar uma nova imagem:
    - O sistema RESETA TUDO (limpa todos os desenhos, reseta zoom para 100%, reseta posição).
    - Substitui a imagem de background pela nova.
    - Fecha o painel de configurações.
- Pode ter também informações como:
  - Nome do arquivo atual.
  - Dimensões da imagem.
  - Versão do editor.
- Dentro do painel de configurações, DEVE CONTER também a seção "Atalhos de Teclado" (descrita em seção específica abaixo).

### 6. BOTÃO DE RESET/DESFAZER E REFAZER
- Botão "Desfazer" (Ctrl+Z) que remove o último traço desenhado.
- Botão "Refazer" (Ctrl+Y) que refaz o último traço desfeito.
- Manter um histórico (array de objetos) de todos os strokes/paths desenhados.
- Implementação: cada ferramenta ao terminar um traço (mouseup) salva o path inteiro (pontos, grossura, tipo, timestamp). Desfazer remove o último e redesenha tudo. Refazer restaura o último removido.
- Máximo de 50 ações no histórico (limitar para não consumir memória).
- O histórico deve ser baseado em ações completas, não em eventos parciais.

- **PencilTool** — Implementação do lápis, estende Tool.
- **EraserTool** — Implementação da borracha, estende Tool.
- **FadingPenTool** — Implementação da caneta que some, estende Tool.
- **HandTool** — Implementação da ferramenta mão para pan, estende Tool.
- **HistoryManager** — Sistema de desfazer/refazer com limite configurável.
- **ZoomManager** — Controle de zoom, pan, smooth animation com requestAnimationFrame.
- **SettingsManager** — Gerenciamento do modal de configurações, keybinds, localStorage.
- **KeybindManager** — Sistema de atalhos de teclado, detecção, conflitos, personalização.
- **NotificationManager** — Sistema de notificações toast.
- **ExportManager** — Futuro sistema de exportação.
- **LayerManager** — Gerencia as camadas (layers) do editor.
- **UIManager** — Gerencia a interface do usuário, tooltips, atualizações de painel.

### Canvas Layers
- Use MÚLTIPLOS canvas sobrepostos, um para cada camada:
  - **Canvas Layer 0 (background)**: exibe a imagem original. Nunca é modificada.
  - **Canvas Layer 1 (permanent)**: onde os desenhos do lápis são feitos. Nunca é limpa automaticamente.
  - **Canvas Layer 2 (temp)**: camada temporária para pré-visualizações (ex: forma geométrica futura).
  - **Canvas Layer 3 (fading)**: camada utilizada pela caneta que desaparece. Limpa e redesenha constantemente.
- Todas dentro de um container que aplica zoom e pan.
- A borracha nunca deve apagar a imagem original (Layer 0).
- A caneta que some desenha na Layer 3, que é continuamente limpa e redesenhada com opacidade decrescente.
- Camadas devem permanecer separadas internamente para evitar destruição acidental da imagem original.
- Toda futura ferramenta deverá poder interagir com o sistema de layers.

### Gerenciamento de Zoom e Pan
- Variáveis: scale, offsetX, offsetY.
- No scroll (wheel): ajustar scale, ajustar offset para zoom em direção ao cursor.
- No drag da hand tool: ajustar offsetX/offsetY.
- Aplicar via: container.style.transform = `translate(${offsetX}px, ${offsetY}px) scale(${scale})`.
- Ou usar canvas context transforms: ctx.scale(scale), ctx.translate() — mas aí precisa converter coordenadas do mouse para coordenadas do canvas.
- Utilizar requestAnimationFrame para animações suaves de zoom.
- Botões dedicados: "Ajustar à tela" (fit to screen), "100%" (zoom original).
- Atalhos: Ctrl+0 = zoom 100%, Ctrl++ = ampliar, Ctrl+- = reduzir.
- Exibir percentual contínuo do zoom atual.
- Precisão elevada na posição do cursor durante zoom.

### Drawing System
- No mousedown: inicia um novo path (Stroke).
- Armazena array de pontos: [{x, y}].
- No mousemove: adiciona pontos ao path atual e desenha em tempo real.
- No mouseup: finaliza o stroke e salva no histórico.
- Redesenhar: a cada frame ou no mouseup, limpa o canvas e redesenha TODOS os strokes do histórico + o atual.
- Para performance com muitos traços, usar um canvas offline (offscreen) ou redesenhar apenas o necessário.

### Histórico Profissional (Undo + Redo)
- Array de strokes: cada stroke é { tool, points: [{x,y},...], size, color, layer }
- Ctrl+Z (Undo): remove o último stroke do array ativo e move para array de redo. Redesenha tudo.
- Ctrl+Y (Redo): pega o último do array de redo e move de volta para o array ativo. Redesenha tudo.
- Máximo de 50 ações no histórico (configurável).
- Histórico baseado em ações completas (não em eventos de mouse isolados).
- Compatível com todas as ferramentas (lápis, borracha, caneta, futuras).
- Cada ação armazena informações suficientes para reconstrução completa do estado.
- O histórico deve persistir entre redimensionamentos da janela.

### Fading Pen (Caneta que Some)
- Cada stroke da caneta que some tem um campo lifetime (ms).
- Ao criar o stroke, calcular expirationTime = Date.now() + lifetime.
- Em um loop (setInterval a cada 50ms ou requestAnimationFrame):
  - Para cada stroke da caneta, calcular alpha = max(0, (expirationTime - now) / lifetime).
  - Se alpha <= 0, remover do desenho.
  - Redesenhar com alpha.
- Alternativa mais performática: usar ctx.globalAlpha no redesenho.
- A camada de fading (Layer 3) é limpa e redesenhada constantemente com alphas atualizados.

### Checkerboard Pattern (Fundo do Canvas)
```css
background-image: 
  linear-gradient(45deg, #555 25%, transparent 25%),
  linear-gradient(-45deg, #555 25%, transparent 25%),
  linear-gradient(45deg, transparent 75%, #555 75%),
  linear-gradient(-45deg, transparent 75%, #555 75%);
background-size: 20px 20px;
background-position: 0 0, 0 10px, 10px -10px, -10px 0px;
```
Ou use SVG pattern inline.

### Submissão de Arquivo nas Configurações
- Input do tipo file dentro do modal de config.
- Aceitar: image/png, image/jpeg, image/webp.
- Ao mudar: ler File, criar URL com URL.createObjectURL, definir como src da imagem.
- Resetar: limpar canvas, limpar histórico, resetar zoom para 1, offset para 0, fechar modal.
- Atualizar informações (nome, dimensões) na status bar.
- Validar o arquivo antes de carregar (tipo MIME, integridade).
- Exibir mensagem de erro amigável se o arquivo for inválido ou corrompido.
- Utilizar revokeObjectURL para liberar memória de URLs antigas.

### Tratamento de Erros
- Adicionar tratamento profissional para falhas:
  - Arquivo inválido: exibir notificação toast "Formato de arquivo não suportado".
  - Arquivo corrompido: exibir notificação toast "Não foi possível carregar a imagem. O arquivo pode estar corrompido."
  - Falha de carregamento: exibir notificação toast com mensagem clara.
  - Falha de exportação: exibir notificação toast informando o problema.
  - Ações indisponíveis: exibir feedback visual se uma ação não puder ser executada.
- Mensagens devem ser claras, amigáveis e não técnicas.
- Jamais interromper o funcionamento completo do editor devido a um erro isolado.

### Performance e Otimização
- Utilizar requestAnimationFrame para renderização e animações.
- Minimizar redraws desnecessários (renderizar apenas quando necessário).
- Evitar loops excessivos (setInterval com intervalos grandes para fading).
- Liberar recursos não utilizados (URL.createObjectURL, canvas descartados).
- Para imagens grandes, considerar renderizar em resolução reduzida durante zoom extremo.
- Preparar o sistema para futuras ferramentas complexas sem degradação.
- Manter experiência fluida mesmo com grande quantidade de traços no histórico.

## SISTEMA DE CAMADAS (LAYERS)

O editor deve utilizar múltiplas camadas independentes e isoladas.

Estrutura mínima de camadas:

- **Camada 0 — Imagem Original**: Exibe a imagem de fundo. NUNCA é modificada por ferramentas de desenho.
- **Camada 1 — Desenhos Permanentes**: Onde lápis e outras ferramentas permanentes desenham.
- **Camada 2 — Temporária/Pré-visualização**: Para pré-visualizações de ferramentas futuras (formas, seleções).
- **Camada 3 — Caneta que Desaparece**: Exclusiva para a ferramenta de fading pen.

Regras:

- A borracha NUNCA deve apagar a imagem original (Camada 0).
- A borracha remove apenas traços da Camada 1 e/ou Camada 3.
- A caneta que some desenha exclusivamente na Camada 3.
- Camadas devem permanecer separadas internamente.
- Toda futura ferramenta deverá poder interagir com o sistema de layers.
- Cada camada pode ter opacidade, visibilidade e ordem de renderização independentes.

## SISTEMA DE HISTÓRICO PROFISSIONAL

Expandir o sistema de desfazer para um sistema completo de histórico.

Requisitos:

- **Desfazer (Undo)**: Ctrl+Z — remove a última ação e restaura o estado anterior.
- **Refazer (Redo)**: Ctrl+Y — restaura a última ação desfeita.
- **Limite configurável** de ações no histórico (padrão: 50, mínimo: 10, máximo: 200).
- **Histórico baseado em ações completas**: cada mouseup finaliza uma ação; mousedown+mousemove são uma única ação.
- **Compatível com todas as ferramentas**: lápis, borracha, caneta, hand tool (pan não entra no histórico), e futuras.
- Cada ação deve armazenar:
  - Tipo da ferramenta.
  - Array de pontos.
  - Grossura/configurações.
  - Cor.
  - Camada (layer) afetada.
  - Timestamp.
- O histórico deve permitir reconstrução completa do estado do editor.
- Desfazer deve restaurar exatamente o estado anterior, incluindo traços da caneta que some.
