# INSTRUÇÕES GERAIS OBRIGATÓRIAS (APLICAM-SE A TODAS AS ETAPAS)

Antes de iniciar esta implementação, siga rigorosamente todas as instruções abaixo.

* O projeto inteiro deve continuar existindo em **um único e singular arquivo HTML**.
* Esse único arquivo deve conter todo o código necessário utilizando exclusivamente:

  * HTML;
  * CSS;
  * JavaScript.
* **É proibido criar arquivos adicionais** de qualquer tipo, incluindo, mas não se limitando a:

  * `.js`;
  * `.css`;
  * `.json`;
  * `.ts`;
  * `.jsx`;
  * `.tsx`;
  * `.php`;
  * `.py`;
  * `.java`;
  * `.cs`;
  * módulos ES6 separados;
  * bibliotecas locais;
  * workers;
  * arquivos de configuração externos.
* A única exceção é a criação dos documentos de handoff solicitados pela etapa atual, que devem ser gerados apenas como conteúdo textual (`.txt`) para transferência de contexto entre execuções futuras da IA.
* Todas as novas funcionalidades devem ser implementadas alterando **somente o documento HTML principal já existente**.
* Não reescreva o projeto do zero. Trabalhe sobre a implementação atual, preservando todas as funcionalidades previamente concluídas.
* Mantenha compatibilidade total com as etapas anteriores.
* Preserve a arquitetura já existente, expandindo-a apenas quando necessário.
* Evite código duplicado; reutilize managers, utilities e estruturas já presentes no projeto sempre que possível.
* Utilize **UTF-8** em todo o documento para evitar problemas de codificação.
* Evite caracteres corrompidos (mojibake), símbolos inválidos ou textos ilegíveis na interface.
* Certifique-se de que todos os textos exibidos ao usuário sejam renderizados corretamente em diferentes navegadores modernos para desktop.
* Todo novo código deve possuir qualidade de produção, ser organizado, legível e consistente com o restante do projeto.
* Ao finalizar a etapa atual, revise se nenhuma funcionalidade anteriormente implementada foi quebrada ou alterada de forma não intencional.
* Caso exista qualquer conflito entre a etapa atual e o comportamento já implementado, priorize a preservação da compatibilidade e descreva claramente a solução adotada no documento de handoff.

Após ler e compreender estas instruções, prossiga com a implementação da etapa fornecida abaixo.
