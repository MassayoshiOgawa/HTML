1. RESUMO DA ETAPA
================================================================================

Esta etapa implementou toda a infraestrutura visual e logica das configuracoes
dos slots de imagens (1 a 9). O usuario agora pode configurar completamente
cada slot no painel de configuracoes, porem essas configuracoes ainda nao
possuem efeitos visiveis no canvas (sem preview no cursor, sem insercao).

Todas as funcionalidades existentes (lapis, borracha, caneta que some, zoom,
pan, historico, keybinds) continuam funcionando exatamente como antes.

2.1. NOVO TOGGLE "IMAGE SLOTS (1-9)" NAS CONFIGURACOES

  - Adicionado abaixo do toggle de Keybinds
  - Toggle recolhivel com animacao suave (max-height transition)

  - Todos iniciam fechados
  - Estado de expansao e preservado durante a sessao (via _slotExpanded)
  - Ao re-renderizar (apos upload/link), o estado expandido e restaurado

2.3. CONFIGURACAO DE KEYBIND POR SLOT

  - Sistema identico ao de keybinds existentes
  - Cada slot possui boto "Alterar" que entra em modo de captura
  - Detecta automaticamente a tecla pressionada
  - Salva automaticamente apos confirmacao
  - Detecta conflitos com outros slots E com keybinds principais
  - Exibe notificacao amigavel em caso de conflito
  - Permite restauracao para o padrao (botoes de reset por slot NAO
    implementados - usar o "Remover imagem" para limpar)

  KEYBINDS PADRAO:
    Slot 1 -> 1    Slot 2 -> 2    Slot 3 -> 3
    Slot 4 -> 4    Slot 5 -> 5    Slot 6 -> 6
    Slot 7 -> 7    Slot 8 -> 8    Slot 9 -> 9

  Restricoes: apenas fileira superior do teclado (sem numpad).

2.4. FONTE DA IMAGEM (UPLOAD E LINK)

  Upload:
    - Botao "Upload" em cada slot
    - Aceita: PNG, JPG, JPEG, WebP, GIF
    - Le o arquivo como data URI via FileReader
    - Exibe notificacao em caso de formato invalido
    - Nao apaga configuracao anterior em caso de erro

  Link direto:
    - Input de texto para URL
    - Botao "Aplicar" ou tecla Enter para confirmar
    - Valida o link tentando carregar a imagem via new Image()
    - Em caso de sucesso: salva a URL como source
    - Em caso de erro: exibe notificacao, nao altera configuracao anterior
    - Suporta URLs de GIFs animados

2.5. PREVIEW NAS CONFIGURACOES

  - Exibe miniatura de 64x64px apos configurar uma imagem
  - GIFs permanecem animados na miniatura
  - Quando nenhuma imagem configurada: mostra "Nenhuma imagem" com borda
    tracejada
  - Botao "Remover imagem" para limpar a configuracao

2.6. TAMANHO DA IMAGEM (SLIDER)

  - Input range com: minimo 10%, maximo 100%, step 2.5%
  - Exibe o valor atual continuamente (ex: 10%, 12.5%, ... 100%)
  - Salva automaticamente a cada alteracao

2.7. EFEITO DE SURGIMENTO (APPEAR)

  - Select com duas opcoes: "Padrao" e "Fade In"
  - Quando "Fade In" selecionado: mostra controle de duracao (slider)
  - Duracao: 100ms a 2000ms, step 50ms, padrao 300ms

2.8. EFEITO DE DESAPARECIMENTO (DISAPPEAR)

  - Select com duas opcoes: "Padrao" e "Fade Out"
  - Quando "Fade Out" selecionado: mostra controle de duracao (slider)
  - Duracao: 100ms a 2000ms, step 50ms, padrao 300ms

2.9. EFEITO CONTINUO (IMAGE EFFECT)

  - Select com tres opcoes: "Padrao", "Piscar", "Balancar"
  - Quando "Piscar" selecionado: mostra tres sliders:
    * Velocidade do piscar (100-2000ms, padrao 500ms)
    * Tempo visivel (50-2000ms, padrao 300ms)
    * Tempo invisivel (50-2000ms, padrao 200ms)
  - Quando "Balancar" selecionado: mostra um slider:
    * Intensidade do balanco (1-100%, padrao 50%)

2.10. SUBSTITUICAO EM MASSA (REPLACE EXISTING STAMPS)

  - Toggle switch "Replace Existing Stamps"
  - Quando ativado: armazena a intencao no estado/configuracao
  - NENHUMA substituicao real ocorre nesta etapa
  - Apenas armazena o flag replaceExisting no SlotConfiguration

4. ESTRUTURA COMPLETA DO SlotConfiguration (ATUALIZADA)

  {
    slot:              number (1-9),
    keybind:           string (tecla associada, padrao: '1'-'9'),
    source:            string|null (data URI ou URL da imagem),
    sourceType:        string|null ('url' | 'datauri'),
    sizePercent:       number (tamanho percentual, padrao: 15, min:10, max:100),
    appearEffect:      string|null (null | 'fadeIn'),
    disappearEffect:   string|null (null | 'fadeOut'),
    imageEffect:       string|null (null | 'blink' | 'wobble'),
    effectSettings:    object {
      appearDuration:      number (ms, para fadeIn, padrao 300),
      disappearDuration:   number (ms, para fadeOut, padrao 300),
      blinkSpeed:          number (ms, padrao 500),
      blinkVisibleTime:    number (ms, padrao 300),
      blinkInvisibleTime:  number (ms, padrao 200),
      wobbleIntensity:     number (porcentagem, padrao 50),
    },
    replaceExisting:   boolean (padrao false, apenas intencao)
  }

7. FUNCIONAMENTO DO SISTEMA DE UPLOAD

  1. Usuario clica "Upload" em um slot
  2. SettingsManager._activeSlot e definido como o numero do slot
  3. O input #slot-file-input e acionado via .click()
  4. Usuario seleciona um arquivo
  5. Evento change valida o tipo (image/png, image/jpeg, image/webp, image/gif)
  6. Se invalido: notificacao de erro, input resetado
  7. Se valido: FileReader le como data URI
  8. Configuracao do slot atualizada (source, sourceType) e salva
  9. renderImageSlots() e chamado para atualizar a UI

================================================================================
8. FUNCIONAMENTO DO SISTEMA DE LINKS

  1. Usuario digita URL no input de link do slot
  2. Clica "Aplicar" ou pressiona Enter
  3. URL e validada (new Image() com crossOrigin 'anonymous')
  4. Se onload: URL salva como source, notificacao de sucesso, UI atualizada
  5. Se onerror: notificacao de erro, configuracao anterior preservada
  6. URL vazia: notificacao de aviso

10. FUNCIONAMENTO DOS CONTROLES CONDICIONAIS

  Cada controle condicional usa classe .slot-cond com display: none por padrao
  e .slot-cond.show com display: block.

  Logica:
    - appearEffect == 'fadeIn' -> mostra controle de duracao
    - disappearEffect == 'fadeOut' -> mostra controle de duracao
    - imageEffect == 'blink' -> mostra tres sliders (velocidade, visivel, invisivel)
    - imageEffect == 'wobble' -> mostra slider de intensidade

  Ao mudar o select:
    - Atualiza config.effectSettings
    - Salva configuracao via setSlot()
    - Atualiza classe .show nos controles condicionais
