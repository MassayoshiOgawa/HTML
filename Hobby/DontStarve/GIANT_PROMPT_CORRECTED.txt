CHAPTER 1: PROJECT OVERVIEW
================================================================================

1.1 PURPOSE
This document provides the complete specification for recreating Don't Starve
(Klei Entertainment, April 2013) as a single self-contained HTML file.

1.2 TARGET PLATFORM
- Single HTML file (.html)
- Runs in any modern browser (Chrome, Firefox, Edge, Safari)
- No internet connection required
- No external dependencies, libraries, or frameworks
- No external images, sprites, or audio files
- All graphics procedurally drawn on Canvas 2D
- All audio procedurally generated using Web Audio API

1.3 CORE GAMEPLAY LOOP
1. Explore the procedurally generated world
2. Gather resources (twigs, grass, logs, rocks, flint, food)
3. Craft tools, weapons, armor, and structures
4. Manage survival stats: Health, Hunger, Sanity, Temperature
5. Fight or avoid hostile creatures
6. Prepare for nightfall (light source) and winter (warmth)
7. Survive as long as possible

1.4 VICTORY CONDITION
1. Craft the Divining Rod at a Prestihatitator
2. Use the Divining Rod to locate four Teleportato components
   (Ring, Box, Crank, Metallic Potato) hidden in Chess biome set pieces
3. Place all four components on the ground to form the Teleportato
4. Activate the Teleportato

1.5 KEY FEATURES TO IMPLEMENT
- Procedural world generation with 9 biomes
- Day/night cycle with dynamic lighting (8-minute days)
- Two seasons: Autumn (20 days) and Winter (16 days)
- Survival mechanics: Health, Hunger, Sanity, Temperature
- Crafting system with 5 technology tiers
- Combat system with kiting mechanics
- Inventory management (16 slots + 3 equipment slots)
- Base building with structures
- Cooking (fire + Crock Pot) and Drying Rack
- Farming (Basic and Improved farms)
- Hostile and passive creatures with state-machine AI
- Fire and combustion mechanics (trees can burn)
- Save/Load via localStorage
- Wilson's beard growth mechanics

CHAPTER 3: CORE ENGINE SYSTEMS
================================================================================

3.1 GAME LOOP
Uses requestAnimationFrame for 60fps rendering with fixed timestep.
FIXED_DT = 0.033 (~30 ticks/second for simulation).
Cap delta time at 0.05 seconds to prevent spiral-of-death.

fixedUpdate (in order): Input, Player Movement, Mob AI, Physics/Collision,
Combat, Projectiles, Fire Propagation, Plant Growth, Spoilage, Temperature,
Hunger/Sanity/Health Decay, Day/Night Cycle, Season Timer, Particles

render (in order): Clear Canvas, Ground Tiles, Decorations, Shadows, Entities,
Light Mask, Particles, HUD, UI Overlays

3.2 EVENT SYSTEM (EventBus)
Publish/subscribe for system decoupling.
Interface: EventBus.on(name, cb, ctx), .off(name, cb), .emit(name, data),
.once(name, cb)

Events emitted: day.start, day.dusk, day.night, season.change, player.damage,
player.death, player.respawn, entity.damage, entity.death, entity.spawn,
craft.item, pickup.item, build.structure, fire.start, fire.extinguish,
tree.fall, inventory.change, equip.change, save.game, load.game, world.generate

3.3 TIMER SYSTEM
Interface: TimerManager.after(delay, callback), .every(interval, callback),
.clear(id), .update(dt). Used for regrowth, spoilage, cooking, drying, fuel.

3.4 INPUT MANAGER
Tracks: keysDown, keysJustPressed, keysJustReleased, mouseX/Y,
screenMouseX/Y, mouseDown, mouseJustClicked, mouseRightDown,
mouseRightJustClicked, scrollDelta.

3.5 CAMERA SYSTEM
Follows player with lerp factor 0.08. Zoom: 0.5-2.0 via scroll wheel.
Viewport culling: 200px margin. World-to-screen: screenX=(worldX-camera.x)*zoom.

3.6 PROCEDURAL GRAPHICS GENERATOR
All assets generated at init on offscreen canvases. Nearest-neighbor
interpolation for pixel art. Loading screen with progress bar.
Asset generation priority: tiles, player, common mobs, items, structures, rares.

3.7 PROCEDURAL AUDIO GENERATOR
All sounds via Web Audio API. AudioContext on first interaction.
Sound buffers generated once, cached, played on demand.

3.8 SEEDED RNG (Mulberry32)
Seeded PRNG with: next(), nextInt(min,max), nextFloat(min,max),
pick(array), shuffle(array). Seed range: 0 to 2147483647.

5.4 WORLD GENERATION
Step 1: Height map (3-octave perlin/simplex noise: freq 0.005/0.01/0.02)
Step 2: Moisture map (freq 0.008) and Temperature map (freq 0.004)
Step 3: Biome assignment using height+moisture+temperature rules
Step 4: Smoothing (2 passes, 5/8 neighbors rule)
Step 5: Decoration placement
Step 6: Set pieces at noise anomalies
Step 7: Resource placement
Step 8: Road generation
Step 9: Initial entity spawning

5.5 BIOME ASSIGNMENT
h<0.25: m<0.3=marsh else swamp
h<0.4: grassland
h<0.55: m>0.6=savanna else grassland
h<0.7: t>0.5=deciduous else forest
h<0.85: forest
else: rocky

5.6 SET PIECES

Touch Stone: stone + 4 pig torches, 1-3 per world, resurrection point
Wormhole Pairs: 3-5 pairs, teleport with 15 sanity cost
Recreational Park: picnic table, Walking Cane loot, 2-3 Pig Houses

5.7 ROAD GENERATION

Cobblestone in chess biome: alternating grey stones, 3 tiles wide.

CHAPTER 7: SURVIVAL SYSTEMS
================================================================================

7.1 HEALTH
Max: 150 (Wilson). Integer 0-150. Regen: 1 HP per 30 seconds.
Damage sources: enemy attacks, starvation (1 HP/2s when hunger=0),
fire (5/s), freezing (1/s).
Heal sources: food, Healing Salve(+20), Honey Poultice(+30), sleep,
Butterfly Wings(+8), Spider Gland(+12 used).
Invulnerability frames: 0.5s (player flashes).

7.2 HUNGER
Max: 150. Displayed as green meter. Float 0-150.
Decay: 1 hunger per 10 seconds (0.10/s).
At 0 hunger: health drains at 1 HP per 2 seconds.

7.3 SANITY
Max: 200. Displayed as purple meter. Integer 0-200.
Gain: cooking/eating food, clothing(Top Hat +2.5/min, Dapper Vest +6.7/min),
picking flowers (+5 each, first 12 only), prototyping (+15 each).
Loss: darkness (-20/min), monster auras, monster food, evil items, grave digging (-20).
Threshold effects: <50% visual distortion, <25% shadow creatures appear,
<15% shadow creatures aggressive, 0% maximum effects.

7.4 TEMPERATURE (overview - see Ch15 for details)
Range: -20 to +40. Start: 30.
Only cold matters (no overheating in original game).
Trends toward ambient at 1 deg/s (modified by insulation).
Freezing at <=0: 1 damage/s, -20% speed, ice overlay.

7.5 SPOILAGE
Freshness: 1.0 to 0.0 (linear). Status: fresh(1.0-0.5), stale(0.5-0.2), spoiled(<0.2).
Stale: 50% food value. Spoiled: -15 HP, -15 sanity, +1 hunger if eaten.
Visual indicator: green border when fresh, yellow when stale, red when spoiled.
Ice Box: 50% spoilage rate (2x shelf life).
Spoiled food uses: fuel, fertilizer, pig feed.
Default spoil time: 6 days for most meats, 3 days fish, 10 days carrots,
4 days mushrooms, 40 days honey, 1 day petals.
(1 day = 8 minutes real time)

7.6 DURABILITY
Tools/weapons/armor have maxDurability. Each use reduces durability by 1
(tools/weapons) or by hit damage * armor% (armor).
Break sound at <15% durability. Destruction sound at 0 durability.
Armor stacking (multiplicative): damageTaken = hit * (1-armor1) * (1-armor2)
Armor dura loss: hit * armor% per piece.

7.7 DEATH
Health reaches 0: fade to red/black (2s), spawn skeleton with items,
death screen (cause, days, seed), retry/new/main menu buttons.
Save deleted on death if no resurrection.

7.8 RESURRECTION
Touch Stone (world structure, 1-3 per world): activate on right-click,
respawn with 50% stats, one-time use.
Meat Effigy (crafted TIER 4): 4 Boards + 4 Meat + 4 Beard Hair,
respawn with 50% stats, consumed on use, max 1 active.

7.9 STAT TABLE (WILSON)
Health: 150/150/0
Hunger: 150/150/0
Sanity: 200/200/0
Temperature: +40/30/-20

CHAPTER 11: COMBAT SYSTEM
================================================================================

11.1 DAMAGE CALCULATION
Player damage = weaponDamage * characterMultiplier (Wilson = 1.0)
Damage taken = rawDamage * (1 - armor1/100) * (1 - armor2/100)
Unarmed: 10 damage.

11.2 ATTACK CYCLE
Player: wind-up 0.2s, hit instant, recovery 0.3s, cooldown 0.5s (total 1.0s)
Enemy: wind-up 0.3-1.0s (visible), attack instant, recovery 0.3-1.0s (varies)
Kiting: attack during enemy wind-up then retreat before enemy attack lands.

11.3 HITSTUN & KNOCKBACK
0.2-0.5s freeze, pushed 8-16px away from attacker.
Both player and mobs experience these.

11.4 WEAPON STATS
Spear: 34 dmg, 100 uses

Blow Dart (Pipe): 75 dmg, 1 use (ranged)
Blow Dart (Sleep): puts target to sleep 10s, 1 use
Blow Dart (Fire): ignites target, 2 dmg/s for 5s, 1 use
Bee Mine: 30 dmg, 1 use (spawns bees on target)
Tooth Trap: 60 damage, 10 uses (triggered by mob)
Walking Cane: 0 damage (+25% speed)

11.5 TARGETING
F: auto-target nearest enemy within 80px.
Left-click enemy: manual attack.
Move: cancel wind-up.
Ctrl+F: force attack (hits friendlies too).

11.6 AGGRO STATES
IDLE -> SUSPICIOUS -> AGGRESSED -> FLEEING
Triggered by: player in detection range, attacking same-type mob,
night time, low sanity.
Group aggro: all same-type mobs within radius aggro when one is attacked.

Detection ranges: Spider 40px, Hound 100px, Tentacle 120px, Pig 30px(neutral).
Chase ranges: Spider 120px, Hound unlimited, Tentacle stationary, Pig 80px.

11.7 HIT EFFECTS
On hit: small white flash (one frame) at impact point + 3-5 impact particles (color matching damage type), spread 8-16px, lifetime 0.3s.

11.8 DAMAGE TYPES

FIRE: Sets target on fire (burning DoT)
NIGHTMARE: Bypasses 50% of armor

CHAPTER 12: LIGHTING SYSTEM

CHAPTER 13: DAY/NIGHT AND SEASONS

13.1 CYCLE
1 day = 8 minutes (480s) real time.
Autumn: Day 4min, Dusk 1.5min, Night 2.5min.

13.2 DAY TRACKING
Increments at dawn. Displayed top-center: "Day X".

13.3 SEASONS
AUTUMN: 20 days, mild (15-30 day, 5-15 night), abundant resources.

CHAPTER 14: WEATHER SYSTEM
================================================================================

No rain in original game. Only winter snow effects.

14.1 SNOW
Accumulates over first 3 days of winter: 30%, 60%, 100%.
Ground turns white. Trees get snow caps.
Small white particles (1-3px), 20-50 on screen, wind drift.
Melts over 2 days when winter ends.

14.2 FOG (Swamp only)
Thin white/grey mist at ground level. Drifts horizontally.
Above ground, below entities. Visual only.

14.3 WIND
Trees sway, grass bends, particles drift. Visual only. Stronger in winter.
Leaf particles: 3-8 leaves per tree in wind, green/brown, drift horizontally with slight fall, lifetime 2-4s.

================================================================================
CHAPTER 15: TEMPERATURE SYSTEM
================================================================================

15.1 MECHANICS
Player temp range: -20 to +40. Start: 30.
Trends toward ambient at 1 deg/s.
Ambient: Autumn day=20-30, Autumn night=5-15,
Winter day=-5 to 5, Winter night=-15 to -5.
Effective rate = baseRate / (1 + totalInsulation/100)

15.2 HEAT SOURCES
Fire within 8 tiles (128px). Inverse square of distance.
At 1 tile: +20 deg/s. At 8 tiles: +2 deg/s.

15.3 INSULATION VALUES
Beard: +15/+45/+75 (short/medium/long).
Winter Hat: +120. Beefalo Hat: +240. Puffy Vest: +120.
Total insulation = clothing + beard (additive).

15.4 FREEZING (temp <= 0)
1 damage/s. -20% move speed. Ice crystal overlay. Breath particles.
Warning message. Thermometer UI with blue-white gradient.

CHAPTER 16: FIRE & COMBUSTION
================================================================================

16.1 FUEL BURN TIMES
Log: 60s, Twigs: 8s, Cut Grass: 5s, Charcoal: 45s, Manure: 30s,
Boards: 120s, Rope: 12s, Petals: 2s, Silk: 8s, Honey: 15s, Spoiled Food: 10s.

16.2 ADDING FUEL
Click fire with fuel in inventory: fuel += burnTime, item consumed.
Radius temporarily +10% for 2 seconds.

16.3 FIRE DYNAMICS
Radius scales with fuel percent (100% full -> 25% almost out).
Flicker: +/-10-15% radius every 0.1-0.3s.

16.4 COOKING
Right-click fire with food: place in cooking slot (4 slots per fire).
Cook time: 10-20s. Ding sound when done.
If unclaimed for 30s after cooking: food burns into Charcoal.

16.5 FIRE SPREAD
Flammable entities within 40px checked every 2s.
Trees: 20% chance. Grass: 40%. Saplings: 40%. Berry bushes: 30%.
Spider dens: 25%. Wooden structures: 10%.
Campfire CAN spread. Fire Pit CANNOT spread.

16.6 FIRE DAMAGE
Standing in fire: 5 dmg/s. Burning tree near entity: 2 dmg/s within 20px.
Burning mobs: 2 dmg/s.

16.7 CAMPFIRE vs FIRE PIT
Campfire: TIER 0, 6 fuel slots, CAN spread fire, smaller radius.
Fire Pit: TIER 1, 12 fuel slots, CANNOT spread (stone ring), larger radius.

16.8 EXTINGUISHING
Fires burn out when fuel = 0. No manual extinguishing.
Ice Staff can freeze and extinguish.

16.9 FIRE AND SMOKE PARTICLES
Fire: 10-20 orange/yellow embers per fire, rising 20-60px, lifetime 0.5-1.5s, size 2-4px, sinusoidal horizontal drift.
Smoke: 5-10 grey particles per fire, rising 40-100px, lifetime 1-3s, size 4-8px, expand and fade as they rise.

================================================================================
CHAPTER 26: PERFORMANCE & OPTIMIZATION
================================================================================

26.1 TARGETS: 60 FPS modern browsers, 30 FPS minimum, <200MB RAM, <5s load time.
26.2 RENDERING: viewport culling (200px margin), pre-render tiles to offscreen
    canvas, cache light mask between frames.
26.3 ENTITY: object pooling (particles, items, projectiles, damage numbers).
    Max: 200 mobs, 500 particles, 100 dropped items.
26.4 SPATIAL: chunk-based entity queries (8x8 tiles per chunk).
    Only update AI for mobs within 200px of player.
    Mob update frequency: distant every 5 ticks, nearby every tick.
26.5 PATHFINDING: limit A* range to 50 tiles, max 3 pathfinding calls per frame,
    cache paths for static obstacles.
26.6 MEMORY: clear destroyed entities immediately, reuse objects,
    avoid string concat in loops, limit sound cache to 50 sounds.
