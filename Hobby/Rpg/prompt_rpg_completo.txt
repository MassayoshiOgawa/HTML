1. VISÃO GERAL DO PROJETO
================================================================================

Nome do Jogo: "Crônicas de Aetheris — O Legado Esquecido"
Gênero: RPG 2D Top-Down
Plataforma: Navegador (HTML5)
Tecnologias: HTML, CSS, JavaScript (puros, SEM bibliotecas externas)
Canvas: Deve usar <canvas> para renderização principal
Resolução: 1920x1080 (full HD), adaptável via escala
Estilo Visual: Pixel Art refinado com sprites desenhados via Canvas API
FPS Alvo: 60 FPS (gameloop usando requestAnimationFrame)

O jogador assume o papel de um herói em um mundo de fantasia medieval chamado
Aetheris. O jogo deve ser completamente funcional, com sistema de movimentação,
combate em tempo real, mapa procedural, inventário completo, agricultura,
diálogos com NPCs, lojas, sistema de crafting, missões e progressão de classe.

2. HISTÓRIA E LORE DO MUNDO
================================================================================

2.1 LORE PRINCIPAL:
--------------------
Há milênios, o mundo de Aetheris era governado por cinco Cristais Primordiais:
Vida, Magia, Força, Sabedoria e Tempo. Estes cristais mantinham o equilíbrio
do mundo. Uma civilização avançada conhecida como "Os Primordiais" usava os
cristais para sustentar uma era de ouro.

Porém, um evento conhecido como "A Fratura" ocorreu quando um poderoso ser
chamado Malachar, um Primordial corrompido, tentou absorver todos os cinco
cristais para si. Na batalha resultante, os cristais se fragmentaram em
inúmeros pedaços e se espalharam pelo mundo. A civilização Primordial caiu,
e o mundo foi lançado em uma era de trevas.

Séculos se passaram. O conhecimento sobre os cristais se tornou lenda. O
mundo se reconstruiu em pequenos reinos e vilas. Monstros e criaturas
corrompidas pelos fragmentos dos cristais vagam pela terra.

O jogador é um "Desperto" — alguém que demonstrou afinidade com um fragmento
de cristal, ganhando habilidades especiais. Sua jornada começa na Vila
Amanhecer, um pequeno assentamento na borda da Floresta Sussurrante.

2.2 OBJETIVO PRINCIPAL:
-----------------------
O jogador deve explorar o mundo, derrotar monstros, completar missões,
coletar fragmentos dos Cristais Primordiais e, eventualmente, enfrentar
Malachar, que retornou para tentar completar seu plano.

2.3 REGIÕES DO MUNDO:
---------------------
O mundo é dividido em 6 regiões principais:

1. VILA AMANHECER (Início - Seguro):
   - Cidade inicial do jogador
   - NPCs amigáveis, lojas básicas, tutorial
   - Animais de fazenda, campos de treinamento
   - Bioma: Campos verdes com clima temperado

2. FLORESTA SUSSURRANTE (Nível 1-10):
   - Floresta densa com criaturas mágicas
   - Slimes, lobos, plantas carnívoras
   - Bioma: Floresta temperada com névoa leve

3. MONTANHAS GÉLIDAS (Nível 10-25):
   - Região montanhosa coberta de neve
   - Yetis, lobos de gelo, golems de gelo
   - Bioma: Tundra com neve e vento cortante

4. PÂNTANO NECROTIC (Nível 25-40):
   - Pântano corrompido com energia sombria
   - Mortos-vivos, espectros, criaturas corruptas
   - Bioma: Pântano com água venenosa e névoa roxa

5. DESERTO DOS ETERNOS (Nível 40-55):
   - Deserto escaldante com ruínas antigas
   - Escorpiões gigantes, múmias, elemental de fogo
   - Bioma: Deserto com tempestades de areia

6. TORRE DO ETERNO (Nível 55-70 - Final):
   - A torre de Malachar, cheia de desafios
   - Chefes poderosos, salas de puzzle
   - Bioma: Interior de torre com estética sombria

2.4 PERSONAGENS PRINCIPAIS (NPCs):
-----------------------------------
- ELARA: Mestre da guilda dos aventureiros (Vila Amanhecer)
- VELHO THORM: Sábio ancião que conhece a história dos cristais
- LYSANDRA: Ferreira e especialista em equipamentos
- CORVO: Mercador misterioso que viaja entre regiões
- GUARDIÃO DA TORRE: Primeiro chefe importante
- MALACHAR: Chefão final

3. SISTEMA DE MAPA E MOVIMENTAÇÃO
================================================================================

3.1 CONTROLES:
--------------
- W / Seta para Cima: Mover para cima
- A / Seta para Esquerda: Mover para esquerda
- S / Seta para Baixo: Mover para baixo
- D / Seta para Direita: Mover para direita
- Clique Esquerdo: Interagir / Selecionar / Atacar (alvo)
- Clique Direito: Usar habilidade especial / Abrir menu contextual
- E: Abrir inventário
- Q: Abrir árvore de talentos
- F: Interagir com NPCs/objetos
- 1-0: Atalhos de habilidades
- Espaço: Dash / Esquivar (curta distância)
- Tab: Alternar minimapa
- Esc: Menu de pausa / Fechar janelas
- I: Inventário rápido
- M: Mapa completo
- L: Missões ativas
- P: Status do personagem

3.2 MOVIMENTAÇÃO:
-----------------
- Movimentação em 8 direções (incluindo diagonais)
- Velocidade base: 3 pixels por frame (a 60fps)
- Colisão com tiles sólidos (paredes, árvores, água, etc.)
- Colisão com NPCs e objetos interagíveis
- Smooth movement (interpolação de posição)
- O personagem deve ter animação de sprites baseado na direção:
   4 frames de animação para cada direção (parado, andando frame 1,
   andando frame 2, andando frame 3)
- Dashing: Espaço + direção -> dashes 40px instantaneamente (cooldown 3s)

3.3 SISTEMA DE TILES:
---------------------
- Tile size: 32x32 pixels
- Mapa renderizado em câmera que segue o jogador
- O jogador fica sempre centralizado na tela (exceto quando perto de bordas)
- Viewport: 30x20 tiles visíveis (960x640 da área do jogo)
- Camadas de tiles:
   * Camada 0: Chão (grama, pedra, areia, etc.)
   * Camada 1: Decorativos (flores, arbustos, pequenas pedras)
   * Camada 2: Objetos sólidos (árvores, paredes, água)
   * Camada 3: Objetos acima do personagem (copas de árvores, tetos)

3.4 COLISÃO:
-----------
- Sistema de bounding box AABB (Axis-Aligned Bounding Box)
- Colisão verificada antes do movimento (movimento só ocorre se não houver
  colisão na nova posição)
- Grid de colisão: matriz booleana do tamanho do mapa
- Objetos interagíveis têm hitbox expandida para facilitar interação
- NPCs têm colisão e podem ser atravessados apenas se forem aliados

4. GERAÇÃO PROCEDURAL DE MAPAS
================================================================================

4.1 ALGORITMO DE GERAÇÃO:
-------------------------
Usar algoritmo de Perlin Noise simplificado para gerar os mapas:

1. GERAR HEIGHTMAP:
   - Usar Perlin Noise 2D com 4 octaves
   - Persistência: 0.5
   - Lacunaridade: 2.0
   - Escala inicial: 0.1
   - O heightmap gera valores entre -1 e 1

2. ASSIGNAR BIOMAS:
   - Baseado no heightmap e temperatura simulada
   - Valores < -0.3: Água (oceano, rios, lagos)
   - Valores entre -0.3 e -0.1: Areia (praias, margens)
   - Valores entre -0.1 e 0.3: Grama (planícies)
   - Valores entre 0.3 e 0.6: Floresta (árvores esparsas)
   - Valores > 0.6: Montanha (pedra, neve se for região fria)

3. GERAR ESTRUTURAS:
   - Colocar árvores aleatoriamente em tiles de floresta
   - Colocar pedras em tiles de montanha
   - Colocar flores e arbustos em tiles de grama
   - Posicionar NPCs em locais pré-definidos
   - Posicionar baús e itens no chão aleatoriamente

4. CONECTIVIDADE:
   - Garantir que a vila inicial esteja sempre em área segura
   - Garantir que o jogador consiga navegar entre regiões
   - Usar BFS para verificar se o spawn é acessível
   - Regenerar se o jogador ficar preso

5. TRANSIÇÃO ENTRE MAPAS:
   - Nas bordas de cada mapa, há pontos de transição
   - Ao andar até a borda, o jogo carrega o próximo mapa
   - Tela de transição: fade out 0.5s, carrega, fade in 0.5s
   - O jogador aparece no ponto de entrada correspondente

6. MAPA MUNDO (OVERWORLD):
   - Mapa gigante de 256x256 tiles (cada tile = 32px)
   - Cada zona: 64x64 tiles
   - Apenas a zona atual e zonas adjacentes são renderizadas
   - Pooling de zonas para performance

4.4 PERLIN NOISE SIMPLIFICADO:
------------------------------
Implementar Perlin Noise 2D:
- Função fade(t): t*t*t*(t*(t*6-15)+10)
- Função lerp(a,b,t): a+(b-a)*t
- Função grad(hash,x,y): usar tabela de permutação de 512
- Noise2D(x,y): retorna valor entre -1 e 1
- OctaveNoise(x,y,octaves,persistence,lacunarity):
  Soma de noise em diferentes frequências e amplitudes

-----------------------

- Clampear para não mostrar áreas fora do mapa
- Shake de câmera ao tomar dano (duração 0.2s, intensidade 4px)
- Zoom: scroll do mouse (0.5x a 2x, padrão 1x)

5. SISTEMA DE COMBATE
================================================================================

5.1 MECÂNICAS BASE:
--------------------
- Combate em tempo real (não por turnos)
- HP do jogador: 100 + (nível x 20) + bônus de classe
- Mana/Energia: 50 + (nível x 10) + bônus de classe
- Stamina: 100 base (usada para ataques físicos especiais)
- Defesa: reduz dano recebido (fórmula: danoRecebido = danoBruto x (100/(100+defesa)))
- Esquiva: chance de evitar dano completamente
- Crítico: chance de dano dobrado (dano crítico = dano x (1.5 + bônus))
- Resistência mágica: reduz dano mágico (mesma fórmula da defesa)

5.2 ATRIBUTOS DO PERSONAGEM:
-----------------------------
6 atributos principais:
- FORÇA: +2 dano físico por ponto
- DESTREZA: +0.5% crítico + 0.3% esquiva por ponto
- CONSTITUIÇÃO: +10 HP + 1 defesa por ponto
- INTELIGÊNCIA: +2 dano mágico por ponto
- SABEDORIA: +10 mana + 1 resistência mágica por ponto
- CARISMA: 0.5% desconto em lojas + 2% recompensa de missões por ponto

O jogador ganha 3 pontos de atributo por nível.

5.3 NÍVEL E EXPERIÊNCIA:
-------------------------
Fórmula de XP: xpNecessario(n) = 100 x n^1.5 x 1.1^n
Onde n = nível atual. Arredondar para inteiro.

XP ganho:
- Monstro normal: 10 x nível_monstro x 1.2
- Monstro elite: 50 x nível_monstro x 1.5
- Chefe: 200 x nível_chefe x 2.0
- Missão: 50 x nível_requerido x 1.5

5.4 CÁLCULO DE DANO:
---------------------
danoBase = atributoEscalável x multiplicadorDaHabilidade
danoBruto = danoBase + (danoBase x 0.05 x nívelPersonagem)
danoFinal = danoBruto x (100 / (100 + defesaInimiga)) x modificadoresElementais

Crítico: danoFinal = danoFinal x (1.5 + bônusDeCrítico)

Tipos de dano:
- Físico: Corte, Perfuração, Impacto
- Mágico: Fogo, Gelo, Raio, Terra, Vento, Luz, Trevas, Natureza
- Puro: ignora defesa e resistências
- Veneno: dano ao longo do tempo

Fraquezas e Resistências Elementais:
- Fraqueza: 1.5x dano
- Resistência: 0.5x dano
- Imunidade: 0x dano
- Absorção: cura ao invés de dano

5.5 SISTEMA DE HP E MANA DOS MONSTROS:
---------------------------------------
hpMonstro = 30 x nívelMonstro x multiplicadorDeTipo x modificadorDeRegião

multiplicadorDeTipo: normal=1.0, elite=3.0, chefe=10.0
modificadorDeRegião: vila=0.8, floresta=1.0, montanha=1.5,
                      pantano=2.0, deserto=2.5, torre=3.0

danoAtaqueMonstro = 5 x nívelMonstro x multiplicadorDeAtaque
Onde multiplicadorDeAtaque varia por tipo de monstro (0.8 a 2.0)

5.6 SISTEMA DE COMBATE EM TEMPO REAL:
--------------------------------------
- Clique esquerdo no monstro: ataque básico (range baseado em arma)
- Teclas 1-9 e 0: habilidades equipadas na hotbar
- Ao usar habilidade: animação -> projétil/efeito -> dano
- Monstros têm IA com padrões:
   1. PATRULHA: andar aleatório dentro de um raio do spawn
   2. DETECÇÃO: raio de 4-8 tiles, ativado quando jogador entra
   3. PERSEGUIÇÃO: move em direção ao jogador
   4. ATAQUE: quando está no raio de ataque (1-4 tiles dependendo do tipo)
   5. RECUO: quando HP < 20%, chance de 40% de fugir
   6. CHAMAR REFORÇOS: elite/chefe, 30% de chance quando HP < 50%
- Monstros dropam itens ao morrer:
   * Ouro: nível x (5 a 15)
   * XP: conforme fórmula acima
   * Itens comuns: 60% de chance
   * Itens raros: 20% de chance
   * Itens épicos: 5% de chance
   * Itens lendários: 0.5% de chance
- Loot aparece no chão por 60s, depois desaparece
- Pressione F perto do loot para pegar

================================================================================
6.1 GUERREIRO (WARRIOR)
================================================================================
Descrição: Mestre do combate corpo a corpo. Tanque e DPS físico.
Atributos Base: FOR:10 DES:5 CON:8 INT:2 SAB:3 CAR:4
HP Base: 140 | Mana Base: 40 | Stamina Base: 120
Bônus/Nível: HP+25, Mana+5, Stamina+8

--- PASSIVAS DO GUERREIRO ---
PASSIVA 1: "RESISTÊNCIA DE FERRO"
Efeito: Reduz dano recebido em 5% + 1% por nível. Nível 50: 55%.
Mecânica: danoRecebido = danoRecebido x (1 - (0.05 + nivel x 0.01))

PASSIVA 2: "FÚRIA DO CAMPO DE BATALHA"
Efeito: Cada hit recebido aumenta dano físico em 2% por 5s (max 10 stacks).
Mecânica: Array de timestamps. Dano = base x (1 + 0.02 x stackCount).

PASSIVA 3: "MESTRE DAS ARMAS"
Efeito: Armas corpo a corpo causam 20% mais dano. 20% chance de Sangramento
(5% HP máximo do alvo por 3s).
Mecânica: dano x1.2. 20% chance aplicar debuff sangramento.

7.2 ESTRUTURA DE CADA ITEM:
---------------------------
{
    id: string,           // ID único do item (ex: 'pocao_vida_pequena')
    nome: string,         // Nome para exibição
    tipo: 'arma' | 'armadura' | 'acessorio' | 'consumivel' | 'material' |
          'missao' | 'ferramenta' | 'semente' | 'planta' | 'receita' | 'fragmento',
    raridade: 'comum' | 'incomum' | 'raro' | 'epico' | 'lendario',
    nivel: number,        // Nível requerido para usar
    descricao: string,    // Descrição do item
    icone: string,        // Código do ícone (caractere ou emoji)
    cor: string,          // Cor da borda do item (baseado na raridade)
    empilhavel: boolean,  // Pode empilhar?
    quantidade: number,   // Quantidade atual
    maxQuantidade: number,// Máximo por stack
    valor: number,        // Valor de venda em ouro
    atributos: {         // Bônus de atributos (se equipável)
        forca?: number,
        destreza?: number,
        constituicao?: number,
        inteligencia?: number,
        sabedoria?: number,
        carisma?: number,
        hp?: number,
        mana?: number,
        defesa?: number,
        resMagica?: number,
        danoFisico?: number,
        danoMagico?: number,
        critico?: number,
        esquiva?: number,
    },
    efeito: {             // Se consumível
        tipo: 'cura_hp' | 'cura_mana' | 'buff' | 'dano',
        valor: number,
        duracao?: number, // segundos
    },
    requisitos?: {        // Requisitos para equipar
        forca?: number,
        destreza?: number,
        nivel?: number,
        classe?: string,
    }
}

- Preço de venda = valorBase x 0.4 (com bônus de CARISMA)

- Clique no item do jogador: vende

7.8 SISTEMA DE PESO:
---------------------

- Se acima de 90% da capacidade: velocidade reduzida em 20%
- Se acima de 100%: não pode correr/dash, velocidade -50%
- Bolsa de expansão de carga: +20 kg (comprada na loja)

8. SISTEMA DE PLANTAÇÃO/AGRICULTURA
================================================================================

8.1 VISÃO GERAL:
-----------------
O jogador pode cultivar plantas em solo fértil (tile ID 23: SOLO_FERTIL).
O sistema de plantação funciona em tempo real (incluindo quando o jogo está
fechado, usando timestamps).

8.2 ETAPAS DO PLANTIO:
-----------------------
1. PREPARAR SOLO: Use uma enxada em um tile de grama/terra para criar
   SOLO_FERTIL (ID 23). Isso consome 10 stamina.

2. REGAR: Com um regador (item comprado na loja), clique no solo fértil
   para transformá-lo em SOLO_UMIDO (ID 24). Consome água do regador.
   O regador tem 10 cargas, recarregável em fontes de água.
   O solo precisa ser regado imediatamente antes de plantar.

3. PLANTAR: Com a semente selecionada no inventário, clique no
   SOLO_UMIDO para plantar. O tile muda para PLANTA_ESTAGIO1 (ID 25)
   e o tempo de crescimento começa.

4. CRESCER: A planta passa por estágios automaticamente:
   - Estágio 1 (ID 25): 0-33% do tempo total
   - Estágio 2 (ID 26): 33-66% do tempo total  
   - Estágio 3 (ID 27): 66-100% do tempo total
   - Pronto (ID 28): 100% completo

5. COLHER: Quando a planta está no estágio PLANTA_PRONTA (ID 28),
   pressione F para colher. O item vai para o inventário.

8.3 TEMPOS DE CRESCIMENTO:
---------------------------
- Trigo: 5 minutos
- Cenoura: 8 minutos
- Batata: 10 minutos
- Tomate: 12 minutos
- Erva Mágica: 20 minutos
- Flor de Luz: 30 minutos
- Planta Sombria: 25 minutos

O tempo real é verificado por timestamps salvos no localStorage.

8.4 CUIDADOS ADICIONAIS:
-------------------------
- Replantio: Se não colher dentro de 10 minutos após ficar pronto,
  a planta morre (volta a SOLO_FERTIL).
- Solo resseca: Se o solo ficar sem planta por 5 minutos, volta a
  SOLO_FERTIL normal.
- Adubo: Item especial que reduz tempo de crescimento em 25%.
- Proteção: Espantalho (craftável) reduz chance de pragas em 50%.
- Pragas: 10% de chance por ciclo de uma praga atacar (planta morre).
  Inseticida (vendido na loja) previne por 30 minutos.

danoHabilidade(danoBase, nivelHabilidade, nivelJogador, atributo) {
    return (danoBase + atributo * 1.5) * (1 + 0.1 * (nivelHabilidade - 1)) * (1 + 0.03 * (nivelJogador - 1));
}

hpMonstro(hpBase, nivelMonstro, tipo) {
    const multTipo = {normal: 1, elite: 3, chefe: 10};
    return hpBase * (1 + 0.15 * (nivelMonstro - 1)) * multTipo[tipo];
}

xpNecessario(nivel) {
    return Math.floor(100 * Math.pow(nivel, 1.5) * Math.pow(1.1, nivel));
}

danoReduzido(dano, defesa) {
    return dano * (100 / (100 + defesa));
}

chanceCritico(destreza, bonusClasse) {
    return 0.05 + destreza * 0.005 + bonusClasse;
}

chanceEsquiva(destreza, bonusClasse) {
    return 0.02 + destreza * 0.003 + bonusClasse;
}

14.4 GAME LOOP PRINCIPAL:
--------------------------
function gameLoop(timestamp) {
    const deltaTime = (timestamp - lastTimestamp) / 1000;
    lastTimestamp = timestamp;

    // 1. Processar input
    inputHandler.process();

    // 2. Atualizar entidades
    player.update(deltaTime);
    enemies.forEach(e => e.update(deltaTime));
    projectiles.forEach(p => p.update(deltaTime));
    particles.forEach(p => p.update(deltaTime));
    npcs.forEach(n => n.update(deltaTime));

    // 3. Processar física e colisões
    physics.update(deltaTime);
    collisionSystem.check();

    // 4. Atualizar câmera
    camera.follow(player);
    camera.update(deltaTime);

    // 5. Renderizar
    renderer.clear();
    renderer.drawMap();
    renderer.drawDecorations();
    renderer.drawItems();
    renderer.drawEnemies();
    renderer.drawNPCs();
    renderer.drawPlayer();
    renderer.drawAbovePlayer();
    renderer.drawProjectiles();
    renderer.drawParticles();
    renderer.drawUI();

    // 6. Loop
    requestAnimationFrame(gameLoop);
}

function fade(t) { return t * t * t * (t * (t * 6 - 15) + 10); }
function lerp(a, b, t) { return a + t * (b - a); }
function grad(hash, x, y) {
    const h = hash & 3;
    const u = h < 2 ? x : y;
    const v = h < 2 ? y : x;
    return ((h & 1) === 0 ? u : -u) + ((h & 2) === 0 ? v : -v);
}
function perlinNoise2D(x, y, perm) {
    const X = Math.floor(x) & 255;
    const Y = Math.floor(y) & 255;
    const xf = x - Math.floor(x);
    const yf = y - Math.floor(y);
    const u = fade(xf);
    const v = fade(yf);
    const aa = perm[perm[X] + Y];
    const ab = perm[perm[X] + Y + 1];
    const ba = perm[perm[X + 1] + Y];
    const bb = perm[perm[X + 1] + Y + 1];
    return lerp(lerp(grad(aa, xf, yf), grad(ba, xf - 1, yf), u), lerp(grad(ab, xf, yf - 1), grad(bb, xf - 1, yf - 1), u), v);
}
function octaveNoise(x, y, octaves, persistence, lacunarity, perm) {
    let value = 0, amplitude = 1, frequency = 1, maxValue = 0;
    for (let i = 0; i < octaves; i++) {
        value += amplitude * perlinNoise2D(x * frequency, y * frequency, perm);
        maxValue += amplitude;
        amplitude *= persistence;
        frequency *= lacunarity;
    }
    return value / maxValue;
}
function generatePermutationTable(seed) {
    const perm = new Array(512);
    const p = Array.from({length: 256}, (_, i) => i);
    let s = seed;
    for (let i = 255; i > 0; i--) {
        s = (s * 16807 + 0) % 2147483647;
        const j = s % (i + 1);
        [p[i], p[j]] = [p[j], p[i]];
    }
    for (let i = 0; i < 512; i++) { perm[i] = p[i & 255]; }
    return perm;
}

function calcularDano(atacante, defensor, habilidade, tipoDano) {
    let atributoDano;
    switch (tipoDano) {
        case 'fisico': atributoDano = atacante.atributos.forca * 2; break;
        case 'magico': atributoDano = atacante.atributos.inteligencia * 2; break;
        default: atributoDano = 0;
    }
    const danoBase = atributoDano * habilidade.multiplicador;
    const danoComNivel = danoBase + (danoBase * 0.05 * (atacante.level - 1));
    let reducao;
    if (tipoDano === 'magico') {
        reducao = 100 / (100 + defensor.resistenciaMagica);
    } else {
        reducao = 100 / (100 + defensor.defesa);
    }
    let danoFinal = danoComNivel * reducao;
    const elemento = tipoDano.replace('magico_', '');
    if (defensor.fraquezas && defensor.fraquezas.includes(elemento)) { danoFinal *= 1.5; }
    if (defensor.resistencias && defensor.resistencias.includes(elemento)) { danoFinal *= 0.5; }
    if (defensor.imunidades && defensor.imunidades.includes(elemento)) { danoFinal = 0; }
    const chanceCrit = atacante.chanceCritico || 0.05;
    if (Math.random() < chanceCrit) {
        const multCrit = atacante.multCritico || 1.5;
        danoFinal *= multCrit;
        return { dano: Math.round(danoFinal), critico: true };
    }
    return { dano: Math.round(danoFinal), critico: false };
}

class StatusEffect {
    constructor(tipo, valor, duracao, stacks) {
        this.tipo = tipo;
        this.valor = valor;
        this.duracao = duracao;
        this.tempoRestante = duracao;
        this.tickRate = 1;
        this.tickTimer = 0;
        this.stacks = stacks || 1;
    }
    update(dt, alvo) {
        this.tempoRestante -= dt;
        this.tickTimer += dt;
        if (this.tickTimer >= this.tickRate) {
            this.tickTimer = 0;
            this.applyTick(alvo);
        }
        return this.tempoRestante > 0;
    }
    applyTick(alvo) {
        switch (this.tipo) {
            case 'queimadura': alvo.takeDamage(this.valor * this.stacks, 'magico_fogo'); break;
            case 'veneno': alvo.takeDamage(this.valor * this.stacks, 'veneno'); break;
            case 'sangramento': alvo.takeDamage(this.valor * this.stacks, 'fisico_corte'); break;
        }
    }
}

function startNewGame(classeId, nomeJogador) {

    const mapa = new MapGenerator(Date.now(), 'vila');
    mapa.generate();
    const spawn = mapa.getSpawnPoint();
    jogador.x = spawn.x;
    jogador.y = spawn.y;
    const inventario = new Inventory();
    const missoes = new QuestSystem();
    const combate = new CombatSystem();
    inventario.addItem({id: 'pocao_vida_pequena', quantidade: 3});
    inventario.addItem({id: 'pocao_mana_pequena', quantidade: 2});
    missoes.addQuest('mq01_o_despertar');

    game.start();
    if (!localStorage.getItem('tutorial_completo')) { game.startTutorial(); }
}

function continueGame() {
    const saveData = loadGame();
    if (!saveData) return;
    const jogador = Player.fromSave(saveData.player);
    const mapa = MapGenerator.fromSave(saveData.map);
    const inventario = Inventory.fromSave(saveData.inventory);
    const missoes = QuestSystem.fromSave(saveData.quests);
    const combate = new CombatSystem();
    const game = new Game(jogador, mapa, inventario, missoes, combate);
    game.start();
}

43.1 EVENTBUS IMPLEMENTACAO:
------------------------------
class EventBus {
    constructor() {
        this._listeners = {};
        this._idCounter = 0;
    }
    on(event, callback) {
        if (!this._listeners[event]) this._listeners[event] = [];
        const id = this._idCounter++;
        this._listeners[event].push({ id, callback });
        return id;
    }
    off(id) {
        for (const event in this._listeners) {
            this._listeners[event] = this._listeners[event].filter(l => l.id !== id);
        }
    }
    emit(event, data) {
        if (!this._listeners[event]) return;
        this._listeners[event].forEach(l => l.callback(data));
    }
}

Desenhar via Canvas API (sem imagens externas):

function desenharJogador(ctx, jogador, camera) {
    const sx = jogador.x - camera.x;
    const sy = jogador.y - camera.y;
    const dir = jogador.direction; // 0=cima, 1=baixo, 2=esq, 3=dir
    const frame = jogador.animFrame;

    // Corpo base
    ctx.fillStyle = jogador.equipment.armor ? CORES[jogador.equipment.armor.cor] : '#4488CC';
    ctx.fillRect(sx - 12, sy - 16, 24, 32);

    // Cabeca
    ctx.fillStyle = '#FFD5A0';
    ctx.beginPath();
    ctx.arc(sx, sy - 18, 8, 0, Math.PI * 2);
    ctx.fill();

    // Arma (se equipada)
    if (jogador.equipment.weapon) {
        ctx.fillStyle = '#AAAAAA';
        if (dir === 1) ctx.fillRect(sx + 10, sy - 4, 12, 4); // direita
        else if (dir === 3) ctx.fillRect(sx - 22, sy - 4, 12, 4); // esquerda
        else if (dir === 0) ctx.fillRect(sx - 2, sy - 24, 4, 12); // cima
        else ctx.fillRect(sx - 2, sy + 12, 4, 12); // baixo
    }

    // Perna (animacao)
    ctx.fillStyle = '#335577';
    const pernaOffset = Math.sin(frame * Math.PI / 2) * 3;
    ctx.fillRect(sx - 8, sy + 8 + pernaOffset, 6, 8);
    ctx.fillRect(sx + 2, sy + 8 - pernaOffset, 6, 8);
}

function desenharSlime(ctx, inimigo, camera) {
    const sx = inimigo.x - camera.x;
    const sy = inimigo.y - camera.y;
    const pulo = Math.sin(inimigo.animTimer * 3) * 2;

    // Corpo (forma de gota)
    ctx.fillStyle = inimigo.cor || '#44CC44';
    ctx.beginPath();
    ctx.ellipse(sx, sy + 4 + pulo, 12, 10 + pulo/2, 0, 0, Math.PI * 2);
    ctx.fill();

    // Olhos
    ctx.fillStyle = '#FFFFFF';
    ctx.beginPath();
    ctx.arc(sx - 4, sy - 2 + pulo, 3, 0, Math.PI * 2);
    ctx.arc(sx + 4, sy - 2 + pulo, 3, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = '#000000';
    ctx.beginPath();
    ctx.arc(sx - 3, sy - 1 + pulo, 1.5, 0, Math.PI * 2);
    ctx.arc(sx + 5, sy - 1 + pulo, 1.5, 0, Math.PI * 2);
    ctx.fill();
}

class AudioManager {
    constructor() {
        this.ctx = new (window.AudioContext || window.webkitAudioContext)();
        this.musicVolume = 0.3;
        this.sfxVolume = 0.5;
        this.musicPlaying = false;
    }
    playTone(frequency, duration, type, volume) {
        const osc = this.ctx.createOscillator();
        const gain = this.ctx.createGain();
        osc.type = type || 'square';
        osc.frequency.value = frequency;
        gain.gain.setValueAtTime(volume || this.sfxVolume, this.ctx.currentTime);
        gain.gain.exponentialRampToValueAtTime(0.001, this.ctx.currentTime + duration);
        osc.connect(gain);
        gain.connect(this.ctx.destination);
        osc.start();
        osc.stop(this.ctx.currentTime + duration);
    }
    playHit() { this.playTone(200, 0.1, 'square', 0.3); }

class CollisionSystem {
    constructor(mapData, tileSize) {
        this.mapData = mapData;
        this.tileSize = tileSize;
        this.collisionGrid = [];
        this.buildCollisionGrid();
    }
    buildCollisionGrid() {
        this.collisionGrid = [];
        for (let y = 0; y < this.mapData.length; y++) {
            this.collisionGrid[y] = [];
            for (let x = 0; x < this.mapData[0].length; x++) {
                const tile = this.mapData[y][x];
                this.collisionGrid[y][x] = this.isTileSolid(tile);
            }
        }
    }
    isTileSolid(tile) {
        const solidTiles = [8, 9, 10, 11, 12, 17]; // IDs solidos
        return solidTiles.includes(tile);
    }
    checkCollision(x, y, width, height) {
        const left = Math.floor(x / this.tileSize);
        const right = Math.floor((x + width - 1) / this.tileSize);
        const top = Math.floor(y / this.tileSize);
        const bottom = Math.floor((y + height - 1) / this.tileSize);
        for (let ty = top; ty <= bottom; ty++) {
            for (let tx = left; tx <= right; tx++) {
                if (ty < 0 || ty >= this.collisionGrid.length || tx < 0 || tx >= this.collisionGrid[0].length) return true;
                if (this.collisionGrid[ty] && this.collisionGrid[ty][tx]) return true;
            }
        }
        return false;
    }
    resolveCollision(entity, dx, dy) {
        const newX = entity.x + dx;
        const newY = entity.y + dy;
        if (!this.checkCollision(newX, entity.y, entity.width, entity.height)) {
            entity.x = newX;
        }
        if (!this.checkCollision(entity.x, newY, entity.width, entity.height)) {
            entity.y = newY;
        }
        return { x: entity.x, y: entity.y };
    }
    isWalkable(x, y) {
        const tx = Math.floor(x / this.tileSize);
        const ty = Math.floor(y / this.tileSize);
        if (ty < 0 || ty >= this.collisionGrid.length || tx < 0 || tx >= this.collisionGrid[0].length) return false;
        return !this.collisionGrid[ty][tx];
    }
}

class MapGenerator {
    constructor(width, height, seed) {
        this.width = width || 256;
        this.height = height || 256;
        this.seed = seed || Date.now();
        this.tiles = [];
        this.perm = generatePermutationTable(this.seed);
    }
    generate(region) {
        this.tiles = [];
        const scale = 0.05;
        for (let y = 0; y < this.height; y++) {
            this.tiles[y] = [];
            for (let x = 0; x < this.width; x++) {
                const noiseValue = octaveNoise(x * scale, y * scale, 4, 0.5, 2.0, this.perm);
                let tileId = 0; // Grama clara
                if (noiseValue < -0.3) tileId = 8; // Agua
                else if (noiseValue < -0.1) tileId = 3; // Areia
                else if (noiseValue < 0.3) tileId = 0; // Grama
                else if (noiseValue < 0.6) tileId = 1; // Grama escura
                else tileId = 4; // Pedra
                this.tiles[y][x] = tileId;
            }
        }
        this.placeStructures();
        this.placeSpawn();
        return this.tiles;
    }
    placeStructures() {
        // Arvores (2x2)
        for (let i = 0; i < 50; i++) {
            const x = 10 + Math.floor(Math.random() * (this.width - 20));
            const y = 10 + Math.floor(Math.random() * (this.height - 20));
            if (this.tiles[y][x] === 1) {
                this.tiles[y][x] = 10; // Arvore parte 1
                this.tiles[y][x+1] = 10;
                this.tiles[y+1][x] = 10;
                this.tiles[y+1][x+1] = 10;
            }
        }
        // Pedras
        for (let i = 0; i < 30; i++) {
            const x = Math.floor(Math.random() * this.width);
            const y = Math.floor(Math.random() * this.height);
            if (this.tiles[y][x] === 4) {
                this.tiles[y][x] = 10; // Pedra grande
            }
        }
    }
    placeSpawn() {
        let spawnX = Math.floor(this.width / 2);
        let spawnY = Math.floor(this.height / 2);
        for (let r = 1; r < 20; r++) {
            for (let dy = -r; dy <= r; dy++) {
                for (let dx = -r; dx <= r; dx++) {
                    const x = spawnX + dx;
                    const y = spawnY + dy;
                    if (y >= 0 && y < this.height && x >= 0 && x < this.width) {
                        if (this.tiles[y][x] === 0) {
                            this.spawnX = x;
                            this.spawnY = y;
                            return;
                        }
                    }
                }
            }
        }
    }
}

49.1 ESTADOS DA IA:
--------------------
Cada inimigo tem uma maquina de estados:
{
    PATROL: Andar aleatoriamente dentro do raio de patrulha
        - Escolher ponto aleatorio a cada 3-5s
        - Mover em direcao ao ponto
        - Ao chegar, esperar 1-2s e escolher novo ponto
        - Deteccao: verificar se jogador esta no detectionRange

    CHASE: Perseguir o jogador
        - Mover em direcao ao jogador
        - Se jogador sair do detectionRange por 3s: voltar a PATROL
        - Se estiver em attackRange: mudar para ATTACK

    ATTACK: Atacar o jogador
        - Executar animacao de ataque
        - Causar dano no jogador
        - Cooldown de ataque (1-3s dependendo do monstro)
        - Se jogador sair do attackRange: voltar a CHASE

    FLEE: Fugir do jogador (HP < 20%)
        - Mover em direcao oposta ao jogador
        - Se recuperar HP > 30% ou jogador sair do range: voltar a PATROL
        - 40% de chance de ativar quando HP < 20%

    SPECIAL: Ataque especial (elites/chefes)
        - Usado a cada 3-4 ataques normais
        - Animacao especial com efeitos visuais
        - Dano maior ou efeito em area
        - Cooldown interno

    SUMMON: Invocar aliados (necromantes, chefes)
        - Usado quando HP < 50% pela primeira vez
        - Invoca 2-3 monstros menores
        - Cooldown de 30s
}

updateIA(inimigo, jogador, dt) {
    const dx = jogador.x - inimigo.x;
    const dy = jogador.y - inimigo.y;
    const dist = Math.sqrt(dx*dx + dy*dy);

    switch (inimigo.aiState) {
        case 'PATROL':
            inimigo.patrolTimer -= dt;
            if (inimigo.patrolTimer <= 0) {
                inimigo.patrolTarget = {
                    x: inimigo.spawnX + (Math.random() - 0.5) * inimigo.patrolRange * 2,
                    y: inimigo.spawnY + (Math.random() - 0.5) * inimigo.patrolRange * 2
                };
                inimigo.patrolTimer = 3 + Math.random() * 2;
            }
            // Mover para patrolTarget
            const pdx = inimigo.patrolTarget.x - inimigo.x;
            const pdy = inimigo.patrolTarget.y - inimigo.y;
            const pDist = Math.sqrt(pdx*pdx + pdy*pdy);
            if (pDist > 5) {
                inimigo.x += (pdx / pDist) * inimigo.velocidade * dt * 60;
                inimigo.y += (pdy / pDist) * inimigo.velocidade * dt * 60;
            }
            // Deteccao
            if (dist < inimigo.detectionRange) {
                inimigo.aiState = 'CHASE';
            }
            break;

        case 'CHASE':
            if (dist < inimigo.attackRange) {
                inimigo.aiState = 'ATTACK';
                inimigo.attackTimer = 0;
            } else if (dist > inimigo.detectionRange * 1.5) {
                inimigo.aiState = 'PATROL';
                inimigo.patrolTimer = 0;
            } else {
                inimigo.x += (dx / dist) * inimigo.velocidade * dt * 60;
                inimigo.y += (dy / dist) * inimigo.velocidade * dt * 60;
            }
            break;

        case 'ATTACK':
            inimigo.attackTimer -= dt;
            if (inimigo.attackTimer <= 0) {
                // Atacar
                jogador.takeDamage(inimigo.dano, inimigo.tipoDano);
                inimigo.attackTimer = inimigo.attackCooldown;
                // Chance de ataque especial (elite/chefe)
                if (inimigo.tipo === 'elite' || inimigo.tipo === 'chefe') {
                    if (Math.random() < 0.3) usarAtaqueEspecial(inimigo, jogador);
                }
            }
            // Se fugir do alcance
            if (dist > inimigo.attackRange * 1.2) {
                inimigo.aiState = 'CHASE';
            }
            // Verificar flee
            if (inimigo.hp / inimigo.maxHp < 0.2 && Math.random() < 0.01) {
                inimigo.aiState = 'FLEE';
            }
            break;

        case 'FLEE':
            const fleeX = inimigo.x - dx;
            const fleeY = inimigo.y - dy;
            const fleeDist = Math.sqrt(fleeX * fleeX + fleeY * fleeY);
            if (fleeDist > 0) {
                inimigo.x += (fleeX / fleeDist) * inimigo.velocidade * 1.5 * dt * 60;
                inimigo.y += (fleeY / fleeDist) * inimigo.velocidade * 1.5 * dt * 60;
            }
            if (dist > inimigo.detectionRange * 2) {
                inimigo.aiState = 'PATROL';
            }
            break;
    }
}
