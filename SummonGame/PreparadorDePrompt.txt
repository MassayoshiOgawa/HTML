Vou te pedir pra fazer um mega prompt(armarzena-lo na pasta PromptsGerados), q é basicamente um prompt grande para realizar uma ideia, evitando o erro e implementando a ideia de forma responsiva e escalável, para q futuramente seja adicionado mais conteúdo ou modificações/alterações. coloque no prompt q a IA não pode criar outros documentos de outras linguagens(java, python, c++, c etc), e só poderá crair documentos caso for pedido no prompt. no prompt, coloque ideias, conceitos, regras, tudo necessário para q a IA consiga implementar a ideia de forma profissional e precisa. Leia com muita atenção e de forma completa o documento HTML SummonGame.html, e também leia por completo a documentação dele, q é a Documentacao_Completa.txt, q ao fazer qualquer alteração no código html, registrar a alteração na documentação de forma profissional, limpa e bem estruturada. Antes de criar o prompt, caso vc tenha alguma duvida sobre algo, pergunte, faça as perguntas q vc precisa saber para fazer o prompt de forma profissional e clara, o usuário vai responder suas perguntas, e SE AINDA vc tiver duvidas, pergunte novamente, não haverá problema algum nisso, precisamos criar o melhor prompt possivel, e após isso, faça o prompt, caso não tenha duvidas, apenas faça o prompt. Lembre-se, todas as alteração pro jogo devem ser feitas somente no documento html chamado SummonGame.html, não se deve criar outro documento, tipo, documento css, ou js pra implementar uma ideia.
