* botão de reiniciar jogo

* legenda visual das letras do mapa
* preview/colorização automática das letras

IMPORTANTE:

PARTE 1 — BOTÃO DE CONFIGURAÇÕES
================================

Criar um botão pequeno no canto superior direito:

* estilo minimalista/horror combinando com o jogo
* ícone de engrenagem
* sempre visível durante gameplay
* abrir/fechar menu de configurações

O menu deve conter:

1. Restart Game
2. Map Editor
3. Close

O botão "Restart Game":

* deve chamar o sistema atual de restart
* resetar corretamente:

  * player
  * monster
  * artifacts
  * summonCount
  * portas
  * visão
  * nightTransition
  * HUD
  * partículas

==================================================
PARTE 2 — SISTEMA DE MAPA ASCII
===============================

Criar um editor de mapa onde o usuário pode ESCREVER texto e o jogo gera o mapa automaticamente.

O sistema deve:

* ler linha por linha
* ignorar espaços vazios
* converter caracteres em estruturas do jogo
* gerar colisão corretamente
* gerar tiles corretamente
* gerar portas corretamente
* gerar altar corretamente
* permitir mapas customizados

EXEMPLO:

OOOOOOOOOOOO
OCCCCCCCCCCO
OCCCCdCCCCCO
OCCCCACCCCCO
OOOOOOOOOOOO

Espaços devem ser COMPLETAMENTE ignorados.
Eles NÃO contam como tiles.
Eles servem apenas para organização visual.

==================================================
PARTE 3 — LEGENDA DE LETRAS
===========================

Criar uma legenda VISUAL dentro do menu explicando cada letra.

EXEMPLO:

O = Wall
C = Floor
G = Grass
d = Door
A = Altar
P = Player Spawn
M = Monster Spawn
F = Artifact Spawn
W = Furniture/Obstacle

A legenda deve ficar visível no editor.

================================

A caixa de texto do editor NÃO pode ser textarea simples.

Ela deve:

* colorir cada letra automaticamente
* cada símbolo deve possuir uma cor diferente
* parecer um editor real

EXEMPLO:

* O = marrom escuro
* C = bege madeira
* G = verde
* d = dourado
* A = vermelho brilhante
* P = azul
* M = roxo/vermelho
* F = ciano
* W = cinza

IMPORTANTE:
A renderização deve continuar MONOESPAÇADA.
Cada caractere deve ocupar exatamente o mesmo espaço horizontal.

==================================================
PARTE 5 — PROBLEMA DE PROPORÇÃO
===============================

IMPORTANTE:
Atualmente 3 letras na horizontal NÃO equivalem visualmente a 3 letras na vertical.

Você deve corrigir isso.

O editor precisa:

* usar fonte monospace REAL
* altura da linha correta
* largura fixa dos caracteres
* grid perfeitamente quadrado visualmente
* sem distorção vertical

O editor deve parecer um editor de tilemap ASCII profissional.

==================================================
PARTE 6 — GERAÇÃO DO MAPA
=========================

Criar um parser robusto.

O parser deve:

* converter texto em matriz de tiles
* detectar dimensões automaticamente
* ignorar espaços vazios
* validar caracteres inválidos
* impedir crash em mapas mal formatados

Cada letra deve gerar:

* tile visual
* colisão
* estruturas especiais

EXEMPLOS:
O -> parede sólida
C -> chão interior
G -> grama
d -> porta funcional
A -> altar
P -> spawn do player
M -> spawn do monstro
F -> spawn de artefato

W -> obstáculo sólido interno
