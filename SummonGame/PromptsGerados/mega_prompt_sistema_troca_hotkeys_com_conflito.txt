2. OBJETIVO PRINCIPAL
================================================================================

Implementar um sistema de configuracao de hotkeys (teclas) por jogador que
funciona em DOIS contextos diferentes:

  CONTEXTO A — TELA DE SELECAO DE CLASSES (#class-select):
    Cada painel de jogador (.player-setup-panel) ganha um botao "Configure
    Hotkeys" que, ao ser clicado, expande a configuracao das 7 teclas
    daquele jogador DENTRO do proprio painel. A configuracao usa o mesmo
    sistema de rebinding ja existente (clicar no botao da tecla, pressionar
    nova tecla no teclado).

  CONTEXTO B — PAINEL DE CONFIGURACOES DURANTE A PARTIDA (#settings-panel):
    O sistema atual de configuracao de hotkeys (#hotkey-config, funcao
    buildHotkeyConfig) mostrava todas as teclas de TODOS os jogadores
    expandidas. Agora deve mostrar apenas botoes com o nome de cada
    jogador (ex: "P1 - Name", "P2 - Name"), e ao clicar em um desses
    botoes, as 7 teclas daquele jogador expandem INLINE abaixo do nome.
    Outro clique no mesmo nome recolhe (toggle).

  EM AMBOS OS CONTEXTOS — DETECCAO DE CONFLITOS:
    Apos qualquer rebind de tecla, o sistema verifica se a mesma tecla
    esta sendo usada por OUTRO jogador para QUALQUER acao. Se houver
    conflito, o botao da tecla conflitante recebe borda vermelha e um
    atributo title (tooltip) informando qual jogador e qual acao esta
    usando a mesma tecla. O rebind e PERMITIDO mesmo com conflito
    (apenas avisa, nao bloqueia).

  function checkKeyConflicts() {
    const btns = document.querySelectorAll('.key-btn:not(.waiting)');
    // Mapa: tecla -> array de botoes (para O(1) lookup)
    const keyMap = {};
    for (const btn of btns) {
      const key = btn.textContent.trim().toLowerCase();
      if (!key || key === '...') continue;
      if (!keyMap[key]) keyMap[key] = [];
      keyMap[key].push(btn);
    }

    // Para cada tecla com 2+ botoes de jogadores DIFERENTES
    for (const [key, btnList] of Object.entries(keyMap)) {
      // Agrupa por playerIndex
      const playerGroups = {};
      for (const btn of btnList) {
        const pi = btn.dataset.player;
        if (!playerGroups[pi]) playerGroups[pi] = [];
        playerGroups[pi].push(btn);
      }
      const uniquePlayers = Object.keys(playerGroups);
      if (uniquePlayers.length < 2) continue; // sem conflito (mesmo jogador)

      // Ha conflito: marcar todos os botoes desses players
      for (const [pi, buttons] of Object.entries(playerGroups)) {
        // Encontrar o nome do jogador
        let playerName = 'P' + (parseInt(pi) + 1);
        // Construir mensagem de conflito
        const conflicts = [];
        for (const [otherPi, otherBtns] of Object.entries(playerGroups)) {
          if (otherPi === pi) continue;
          const otherName = 'P' + (parseInt(otherPi) + 1);
          for (const ob of otherBtns) {
            const actionLabel = {
              'up': 'Move Up', 'down': 'Move Down',
              'left': 'Move Left', 'right': 'Move Right',
              'interact': 'Interact', 'ability': 'Ability',
              'use': 'Use/Cycle Item'
            }[ob.dataset.action] || ob.dataset.action;
            conflicts.push(otherName + ' usa ' + key.toUpperCase() + ' para ' + actionLabel);
          }
        }
        for (const btn of buttons) {
          btn.classList.add('conflict');
          btn.title = 'Conflito: ' + conflicts.join('; ');
        }
      }
    }

    // Botoes SEM conflito: limpar marcacao
    for (const btn of btns) {
      const key = btn.textContent.trim().toLowerCase();
      if (!key || key === '...') continue;
      const list = keyMap[key] || [];
      const playerSet = new Set(list.map(b => b.dataset.player));
      if (playerSet.size < 2) {
        btn.classList.remove('conflict');
        btn.title = '';
      }
    }
  }

  - O sistema funciona para QUALQUER numero de jogadores (MAX_PLAYERS).
