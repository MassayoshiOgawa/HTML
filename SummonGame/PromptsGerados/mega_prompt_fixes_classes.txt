FIX 4: Locker Guy - Porta trancada nao pode abrir + trancar porta aberta
================================================================================

PROBLEMA 4a: A porta com cadeado CONSEGUE SER ABERTA. Isso ocorre porque
o metodo DoorEntity.toggle() nao verifica se a porta esta trancada.
Quando uma porta de um GRUPO (double door) e aberta, o toggle propaga
para os membros do grupo, incluindo a porta trancada, abrindo-a.

LOCAL: Classe DoorEntity, metodo toggle() (procure por 'class DoorEntity').

ALTERACAO: Adicionar verificacao de lockedDoor no inicio do toggle().
Se a porta esta trancada, NAO permitir toggle (retornar sem fazer nada).

CODIGO ATUAL (aproximado):
  toggle(skipPropagation) {
    if (this.animating || this.debounceTimer > 0) return;
    if (!skipPropagation && this.groupMembers) {
      for (var i = 0; i < this.groupMembers.length; i++) {
        var member = this.groupMembers[i];
        if (member !== this) member.toggle(true);
      }
    }
    this.open = !this.open;
    this.animating = true;
    this.animTimer = 0;
  }

CODIGO NOVO:
  toggle(skipPropagation) {
    if (this.animating || this.debounceTimer > 0) return;
    // VERIFICACAO DE PORTA TRANCADA
    if (this.game && this.game.lockedDoor && this.game.lockedDoor.doorRef === this) {
      return; // Porta trancada: nao abre
    }
    if (!skipPropagation && this.groupMembers) {
      for (var i = 0; i < this.groupMembers.length; i++) {
        var member = this.groupMembers[i];
        if (member !== this) member.toggle(true);
      }
    }
    this.open = !this.open;
    this.animating = true;
    this.animTimer = 0;
  }

NOTA: O DoorEntity precisa de acesso ao game. Verificar se a classe
DoorEntity ja tem uma referencia ao game (this.game). Se nao tiver,
adicionar no construtor ou passar game como parametro, ou acessar
via uma variavel global. Alternativa: verificar game.lockedDoor
diretamente (se game for acessivel no escopo).

Verificar tambem o metodo forceOpen() da DoorEntity. Adicionar a mesma
verificacao de lockedDoor no inicio de forceOpen():

  forceOpen() {
    if (!this.open && !this.animating) {
      // VERIFICACAO DE PORTA TRANCADA
      if (this.game && this.game.lockedDoor && this.game.lockedDoor.doorRef === this) {
        return; // Porta trancada: nao abre
      }
      if (this.groupMembers) { ... }
      this.toggle(true);
    }
  }

PROBLEMA 4b: Se o jogador usar F (cadeado) em uma porta ABERTA, a porta

LOCAL: Funcao activateAbility(), bloco do lockerguy.

CODIGO ATUAL (aproximado):

CODIGO NOVO:

IMPORTANTE: Apos fechar a porta com toggle(), ela iniciara uma animacao
