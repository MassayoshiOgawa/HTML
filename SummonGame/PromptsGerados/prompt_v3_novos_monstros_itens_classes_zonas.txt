================================================================================
1. CONTEXTO TECNICO DO PROJETO (LEIA COM ATENCAO)
================================================================================

O SummonGame eh um jogo top-down 2D single-file HTML5 Canvas (~7283 linhas).
NAO use frameworks externos. Tudo eh vanilla JS + Canvas 2D.

ARQUITETURA:
- Game Loop: requestAnimationFrame -> update(dt) -> render()
- Classe Game central orquestra tudo
- Entidades: Player, MonsterEntity, DoorEntity, ArtifactEntity, Particle
- FSM do monstro: patrol -> chase -> search -> taunted
- Pathfinding: BFS em grid
- Fog of War: Bresenham raycasting + visibilityGrid/visibilityAge
- Colisao: 4-point corner check (margem 4px player, 3px monstro)

ESTRUTURA DO ARQUIVO (ordem das secoes):
1. <style> - CSS para HUD, botoes, icones de classes, icones de itens
2. <body> - Estrutura DOM (canvas, paineis, overlays)
3. <script> - Todo o JS:
   - CONFIGURATION (const TILE_SIZE, cores, DEFAULT_KEYBINDS)
   - ITEMS (objeto Items com 9 itens: beartrap, landmine, crucifix, bloxy_cola,
     cake, witches_brew, medkit, apple, noise_maker)
   - ITEM ICONS (funcoes canvas para renderizar icones)
   - ITEM RARITY (weightedRandomRarity, getRandomItemByRarity)
   - MONSTER TYPES (objeto MonsterTypes com 12 tipos)
   - PLAYER CLASSES (objeto PlayerClasses com 20 classes)
   - DEFAULT MAP (array de strings 37x18)
   - MAP PARSER (funcao parseMap)
   - PARTICLE SYSTEM (classe Particle)
   - DOOR ENTITY (classe DoorEntity com grupos de portas)
   - ARTIFACT ENTITY (classe ArtifactEntity)
   - PLAYER (classe Player com inventario, interacao, habilidade)
   - MONSTER (classe MonsterEntity com FSM, BFS, visao, ataque)
   - GAME CLASS (classe Game com ~4000 linhas: loadMap, loops, shop, save/load)
   - INPUT HANDLING, UI HANDLERS, INITIALIZATION

FLUXO DE ROUND:
1. Player segura E no altar (tile 'A') -> ritual inicia (summonDelay=5)
2. Apos summonDelay, spawnMonster() eh chamado
3. Monstro ativo -> jogadores coletam artefatos (tiles 'F')
4. Todos artefatos coletados -> monstro morre, round termina
5. GOTO 1 para proximo round

SHOP SYSTEM:
- Tiles 'S' no mapa = shops
- Cada shop gera 1 item aleatorio por round no initShops()
- Player segura E perto do shop -> buyFromShop() -> verifica currency e espaco
- Tiles 'T' no mapa = trash (vender itens)
- LuckySpender: 85% chance de duplicar item comprado

ITEM USAGE:
- Tap R (<0.3s) = ciclo de slots
- Hold R (>=1s) = usar item no slot selecionado
- Traps: colocados no chao na posicao do player
- Consumables: efeito aplicado imediatamente

ROUND END:
- getRandomItemByRarity() escolhe item com giveOnRoundEnd: true
- Item gratuito dado a cada jogador vivo ao final do round

MAPA DEFAULT (37x18 tiles):
  O=Wall, C=Floor, G=Grass, d=Door, A=Altar, P=PlayerSpawn,
  M=MonsterSpawn, F=Artifact, U=Waypoint, W=Furniture,
  S=Shop, T=Trash, m=RandomMonsterSpawn
