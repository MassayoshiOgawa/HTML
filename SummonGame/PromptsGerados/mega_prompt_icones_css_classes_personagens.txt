OBJETIVO PRINCIPAL
================================================================================

Substituir TODAS as letras que representam classes (ex: 'O', 'S', 'H', '$', 
'R2', 'LK') por ÍCONES VISUAIS CSS profissionais, minimalistas e PERFEITOS 
para cada classe de personagem.

Cada ícone deve SER um quadrado de 48x48px que contém uma ilustração CSS 
puramente geométrica (usando ::before, ::after, border, border-radius, 
box-shadow, gradientes, clip-path, transform, etc.) que represente visualmente 
o conceito da classe.

O ícone NÃO pode ultrapassar o campo quadrado de 48x48px. Deve caber 
perfeitamente com padding visual interno adequado.

================================================================================
DIRETRIZES DE DESIGN GLOBAL (LEIA COM MUITA ATENÇÃO)
================================================================================

A. PALETA DE CORES:
   - Fundo do quadrado: #1a1a2e (padrão, herdado do CSS existente)
   - Fundo selecionado: #2a2a3e (mantido pelo CSS existente)
   - Cada ícone deve usar cores que CONTRASTEM com o fundo escuro
   - Use cores vibrantes mas não saturadas demais: tons intermediários com 
     boa legibilidade sobre fundo escuro (#1a1a2e)
   - Prefira cores com luminosidade média-alta (ex: #4fc3f7, #ff8844, 
     #44ff44, #ffcc00, #cc88ff, #ff6688, #88ccff, #ffaa44)
   - Evite cores muito escuras (serão invisíveis sobre #1a1a2e)
   - Use tons metálicos (gradientes cinza/prata) para classes de suporte
   - Use tons quentes (laranja/amarelo/vermelho) para classes ofensivas
   - Use tons frios (azul/ciano/roxo) para classes mágicas/tecnológicas
   - Use tons terrosos (marrom/verde musgo) para classes utilitárias

B. ESTILO MINIMALISTA:
   - Linhas limpas, formas geométricas puras
   - Sem detalhes excessivos: o ícone deve ser reconhecível em 48x48px
   - Máximo 3 elementos visuais por ícone (ex: círculo + linha + ponto)
   - Use gradientes sutis para dar profundidade, mas sem exageros
   - Cantos arredondados onde apropriado
   - Simetria ou assimetria proposital (nada acidental)

C. CONSISTÊNCIA VISUAL:
   - Todos os ícones devem parecer parte da mesma FAMÍLIA de design
   - Espessura de linha consistente (~3-4px em escala 48px)
   - Estilo de sombra consistente (box-shadow sutil)
   - Proporções internas similares (elemento principal ocupa ~60-70% do espaço)
   - Padding visual: ~8-10px de margem interna para não encostar nas bordas

D. TÉCNICA CSS:
   - Use ::before e ::after para criar formas
   - Use border-radius para cantos arredondados e círculos
   - Use transform: rotate(), scale(), skew() para orientação
   - Use linear-gradient e radial-gradient para cores e profundidade
   - Use box-shadow para sombras e destaques (inset e externo)
   - Use clip-path para formas complexas (triângulos, polígonos)
   - Use border com diferentes cores/lados para criar setas e formas
   - NUNCA use imagens, SVG, data URIs ou fontes externas
   - APENAS CSS puro no elemento e pseudo-elementos

E. ABORDAGEM TÉCNICA PARA O ÍCONE:
   - Crie uma classe CSS .class-icon-{key} para cada classe
   - A classe NÃO define background (o fundo já vem do .class-icons div)
   - A classe define APENAS o conteúdo visual do ícone via ::before e ::after
   - Use position: relative no elemento e position: absolute nos pseudo-elementos
   - Centralize tudo com top: 50%; left: 50%; transform: translate(-50%, -50%)

PARTE B - REGRAS TÉCNICAS OBRIGATÓRIAS:

1. TODOS os pseudo-elementos (::before, ::after) devem ter:
   - position: absolute
   - content: '' (OBRIGATÓRIO para pseudo-elementos existirem)
   
2. Centralização no elemento pai (48x48px):
   - Use top: 50%; left: 50%; transform: translate(-50%, -50%) 
     para elementos centrados
   - Ou calcule posições absolutas com px

3. NÃO defina width/height nem background no .class-icon-{key}. 
   O tamanho (48x48) e background (#1a1a2e) JÁ VEM do elemento pai 
   (.class-icons div). A classe do ícone só adiciona o conteúdo visual.

4. Use cores com contraste adequado contra fundo #1a1a2e (azul muito escuro).
   Cores recomendadas: tons com luminosidade > 40%.

5. Use z-index quando necessário para empilhamento de pseudo-elementos.

6. Use opacity e rgba() para transparências e sobreposições.

7. Use border-radius com valores diferentes para cada canto quando necessário 
   (ex: border-radius: 50% 50% 0 0 para semicírculo no topo).

8. Use clip-path com polygon() para formas complexas (triângulos, raios, 
   setas, trapézios). Sintaxe:
     clip-path: polygon(x1 y1, x2 y2, x3 y3, ...)
   As coordenadas são porcentagens relativas ao elemento.

9. Use transform: rotate(deg) para orientar elementos em ângulos.

10. Use repeating-linear-gradient() para padrões (listras, texturas).
