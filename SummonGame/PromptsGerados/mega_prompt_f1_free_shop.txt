DESCRICAO DA FEATURE: SHOP GRATUITO NO MODO F1
================================================================================

O jogo ja possui um modo debug (F1) que ativa/desativa game.debugMode.
Atualmente, F1 ativa: visao total, telhado desativado, grid de tiles,
waypoints visiveis, estado da IA do monstro, cone de visao, FPS, etc.

A NOVA FEATURE: Quando o modo F1 estiver ativo (game.debugMode === true),
o player pode comprar itens da loja (tile 'S') GRATUITAMENTE.

REGRAS DE COMPORTAMENTO:

1. Custo forcado = 0:
   - Quando game.debugMode === true, a funcao buyFromShop() NAO deve
     deduzir moedas (this.currency) do jogador.
   - O player pode comprar mesmo que tenha 0 coins.
   - A verificacao de saldo insuficiente ("Not enough money") deve ser
     PULADA quando debugMode estiver ativo.

2. Item permanece no shop:
   - Quando game.debugMode === true, o item comprado NAO deve ser marcado
     como sold (shopData.sold = false permanece).
   - O shop continua disponivel para compras repetidas (comportamento de
     "vending machine": voce recebe o item, mas ele continua la).

3. Espaco no inventario continua sendo verificado:
   - Mesmo com debugMode ativo, se o inventario do player estiver cheio
     (!player.hasSpace()), a compra deve ser NEGADA com a mensagem
     "'s inventory is full."
   - Isso evita bugs de item perdido.

4. Lojas acessiveis mesmo com monstro vivo:
   - Atualmente, a interacao com shops (Player.checkInteraction) so
     acontece se todos os monstros estiverem mortos
     (game.activeMonsters.every(m => !m.alive)).
   - Quando game.debugMode === true, esta verificacao deve ser IGNORADA.
   - O player pode interagir com shops mesmo com monstro vivo.
   - A renderizacao das lojas (renderShops) tambem so acontece se monstro
     estiver morto. Quando debugMode === true, esta verificacao deve ser
     IGNORADA (shops sempre renderizadas).
   - O mesmo se aplica a renderizacao das lixeiras (renderTrashBins).

5. Texto de interacao mostra "FREE":
   - No texto de prompt de interacao (getInteractionText dentro de
     updateHotbarHUD), quando o tipo for 'shop' e game.debugMode === true,
     o texto deve mostrar "FREE" em vez do preco.
   - Texto de prompt: "Pressione {TECLA} para pegar {NOME_DO_ITEM} FREE"
   - Texto de progresso (enquanto segura a tecla): "Pegando {NOME_DO_ITEM} FREE..."
   - Use a palavra "FREE" em maiusculo para ficar claro.

6. Global:
   - Quando F1 esta ativo, TODOS os players se beneficiam do free shop.
   - Nao ha distincao por player.

7. Manter modo F1 existente:
   - NAO refaca ou remova nenhuma funcionalidade existente do modo F1.
   - Apenas ADICIONE a feature de compra gratuita.
   - Todas as outras funcionalidades do debug mode continuam funcionando
     normalmente (visao total, FPS, waypoints, etc).
