FIX 3: Monstro "Twins" (Gemeos) com colisao entre si
================================================================================

PROBLEMA: Quando o monstro Twins (spawnCount: 2) esta ativo, os dois
gemeos podem se sobrepor, passando um atraves do outro. Devem ter
colisao entre si.

LOCAL: MonsterEntity, metodo canMoveTo() ou followPath().
Tambem adicionar logica no update() para empurrar gemeos sobrepostos.

IMPLEMENTACAO:

A) Em MonsterEntity.canMoveTo(), adicionar verificacao de colisao com
   outros monstros gemeos (procure por 'canMoveTo(px, py)'):

   Adicionar ANTES do return true no final:
     // Colisao entre gemeos (Twins)
     if (this.type === 'twins') {
       for (var mi = 0; mi < this.game.activeMonsters.length; mi++) {
         var other = this.game.activeMonsters[mi];
         if (other === this || !other.alive || other.type !== 'twins') continue;
         var odx = px - other.px;
         var ody = py - other.py;
         var odist = Math.sqrt(odx * odx + ody * ody);
         if (odist < TILE_SIZE * 0.76) return false; // distancia minima entre gemeos
       }
     }

   NOTA: TILE_SIZE * 0.76 = 2 * (TILE_SIZE * 0.38) = diametro de um gemeo.
   Isso impede que os corpos se sobreponham.

B) Em MonsterEntity.update(), apos mover o monstro (final do update),
   adicionar um empurrao suave se dois gemeos estiverem muito proximos
   (para evitar que fiquem travados). Adicionar apos a linha
   'this.tileY = Math.floor(this.py / TILE_SIZE);':

     if (this.type === 'twins') {
       for (var mi = 0; mi < this.game.activeMonsters.length; mi++) {
         var other = this.game.activeMonsters[mi];
         if (other === this || !other.alive || other.type !== 'twins') continue;
         var dx = this.px - other.px;
         var dy = this.py - other.py;
         var dist = Math.sqrt(dx * dx + dy * dy);
         var minDist = TILE_SIZE * 0.76;
         if (dist < minDist && dist > 0.001) {
           var overlap = minDist - dist;
           var nx = dx / dist;
           var ny = dy / dist;
           this.px += nx * overlap * 0.5;
           this.py += ny * overlap * 0.5;
           other.px -= nx * overlap * 0.5;
           other.py -= ny * overlap * 0.5;
         }
       }
     }

EDGE CASES:
- Apenas gemeos (type === 'twins') colidem entre si. Outros monstros
  de tipos diferentes NAO colidem (comportamento atual mantido).
- Se houver 2 gemeos e 1 outro monstro, gemeos colidem entre si mas
  nao com o terceiro.
- O empurrao (push) e feito APOS o movimento normal, corrigindo
  sobreposicoes que possam ocorrer.
