1. DESCRICAO DAS IDEIAS
================================================================================

IDEA A — DOUBLE DOOR SEMPRE VISIVEL:
  Portas duplas (grouped doors) atualmente renderizam INTERIOR_COLOR em
  renderTiles() quando estao em grupo, fazendo com que parecam chao e
  fiquem invisiveis quando o player esta longe. Portas simples renderizam
  DOOR_CLOSED_COLOR diretamente em renderTiles(), entao sao sempre
  visiveis. A correcao e: portas agrupadas tambem devem renderizar
  DOOR_CLOSED_COLOR em renderTiles().

IDEA B — NERF NO MONSTRO (VISAO):
  A visao do monstro (canSeePlayer()) atualmente tem:
    - range maximo: 195 pixels
    - cone de visao: Math.PI / 3 (60 graus)
  As novas especificacoes:
    - range maximo: AUMENTAR (ex: 220 ou 250 pixels)
    - cone de visao: DIMINUIR em 15% (Math.PI / 3 * 0.85 ≈ 51 graus)
  Ajustar tambem os valores de canDetectBehind() se aplicavel.

IDEA C — UI CIRCULAR DE PROGRESSO:
  Substituir a barra de progresso horizontal (elemento DOM #interaction-bar)
  por um circulo oco desenhado no Canvas, posicionado sobre o artefato ou
  altar que esta sendo interagido. Conforme o progresso (interactTimer /
  interactDuration), um arco preenche o circulo com gradiente de vermelho
  (0%) para verde (100%) no sentido horario.

  Detalhes do circulo:
    - Tamanho: 90% do tamanho do player (player radius = TILE_SIZE * 0.3,
      entao circle radius = TILE_SIZE * 0.3 * 0.9 ≈ 8.6px, OU usar um
      tamanho fixo maior como TILE_SIZE * 0.4 para melhor visibilidade
      — ver secao 5);
    - Circulo oco (apenas contorno);
    - Grossura da linha: 15% do diametro do circulo;
    - Gradiente: vermelho (angulo inicial) → verde (angulo final),
      no sentido horario, proporcional ao progresso;
    - Aparece em cima do artefato/altar assim que o player comeca a
      interagir (player.interacting = true);
    - Some quando a interacao termina.

  A UI circular deve usar o mesmo sistema de interacao existente
  (player.interactTimer, player.interactDuration, game.interactDisplay).
  O texto de prompt ("Hold key to summon") e o label ("Summoning...")
  podem permanecer como DOM (elemento #interaction-label) ou ser
  removidos — usar julgamento para manter o label de texto apenas.

4.2 — NOVO METODO renderInteractionCircle(ctx):

  Adicionar na classe Game, na secao de rendering:
    renderInteractionCircle(ctx) {
      // 1. Nao desenhar se nao houver interacao em progresso
      if (!this.interactDisplay) return;
      const data = this.interactDisplay;
      const type = data.type;
      // So desenhar para tipos que usam progresso (artifact, altar)
      // (door nao precisa de progresso circular)
      if (type !== 'artifact' && type !== 'altar') return;
      // type 'shop' e 'trash' tambem usam interacao? Verificar.
      // Use os mesmos tipos que existem no codigo.

      // 2. Encontrar o player que esta interagindo
      let interactingPlayer = null;
      for (const p of this.players) {
        if (p.interacting && p.interactTarget) {
          if (type === 'artifact' && p.interactType === 'artifact') {
            interactingPlayer = p; break;
          }
          if (type === 'altar' && p.interactType === 'altar') {
            interactingPlayer = p; break;
          }
        }
      }
      if (!interactingPlayer) return;

      // 3. Posicao do alvo (mundo -> tela)
      const target = data.target;
      let worldX, worldY;
      if (type === 'artifact') {
        worldX = target.tileX * TILE_SIZE + TILE_SIZE / 2;
        worldY = target.tileY * TILE_SIZE + TILE_SIZE / 2;
      } else if (type === 'altar') {
        worldX = target.x * TILE_SIZE + TILE_SIZE / 2;
        worldY = target.y * TILE_SIZE + TILE_SIZE / 2;
      }
      const sx = worldX - this.camX;
      const sy = worldY - this.camY;

      // 4. Verificar se esta na tela (culling basico)
      if (sx < -50 || sx > this.canvas.width + 50 || sy < -50 || sy > this.canvas.height + 50) return;

      // 5. Parametros do circulo
      const playerRadius = TILE_SIZE * 0.3;
      const circleRadius = playerRadius * 0.9;   // 90% do player
      const lineWidth = circleRadius * 2 * 0.15; // 15% do diametro
      const progress = Math.min(1, Math.max(0, interactingPlayer.interactTimer / this.interactDuration));

      // 6. Gradiente vermelho -> verde no sentido horario
      // Usar createConicGradient se disponivel, ou arco com multiplas cores
      const startAngle = -Math.PI / 2;  // comecar do topo (12h)
      const endAngle = startAngle + Math.PI * 2 * progress;

      // Desenhar fundo do circulo (parte nao preenchida - cinza escuro)
      ctx.beginPath();
      ctx.arc(sx, sy, circleRadius, 0, Math.PI * 2);
      ctx.strokeStyle = 'rgba(255,255,255,0.2)';
      ctx.lineWidth = lineWidth;
      ctx.stroke();

      // Desenhar arco de progresso com gradiente
      if (progress > 0) {
        ctx.beginPath();
        ctx.arc(sx, sy, circleRadius, startAngle, endAngle);
        ctx.strokeStyle = createProgressGradient(ctx, sx, sy, circleRadius, progress);
        ctx.lineWidth = lineWidth;
        ctx.lineCap = 'round';
        ctx.stroke();
        ctx.lineCap = 'butt';
      }
    }

    helper function createProgressGradient(ctx, cx, cy, radius, progress):
      // Criar gradiente conico do vermelho (0) ao verde (progresso)
      // createConicGradient(startAngle, cx, cy)
      const gradient = ctx.createConicGradient(-Math.PI / 2, cx, cy);
      gradient.addColorStop(0, '#ff0000');       // vermelho (inicio)
      gradient.addColorStop(0.5, '#ffff00');     // amarelo (meio)
      gradient.addColorStop(1, '#00ff00');       // verde (fim)
      return gradient;

    NOTA: Se createConicGradient nao for suportado no navegador,
    usar fallback: arco simples com cor interpolada ou multiplos
    segmentos de arco com cores intermediarias.

4.5 — COMPORTAMENTO DESEJADO:

  - Sem interacao: nada desenhado (nem circulo, nem barra)
  - Player comeca interagir com artifact ou altar:
    Circulo aparece em cima do alvo, animando de vermelho a verde
  - Interacao cancelada (soltou tecla): circulo some
  - Interacao completa: circulo some, acao executada
  - Interacao com porta: sem circulo (porta e instantanea/toggle)
  - Multiplayer: cada player tem seu proprio progresso; o circulo
    aparece sobre o alvo do player que esta interagindo.
    Se multiplos players estiverem interagindo com alvos diferentes,
    o circulo deve aparecer em cada alvo respectivo.

    SIMPLIFICACAO RECOMENDADA: O sistema atual usa apenas UM
    this.interactDisplay por vez (o ultimo player que comecou
    a interagir). Manter essa logica. O circulo segue o mesmo
    display.

5. DEFINICOES DE TAMANHO DO CIRCULO
================================================================================

Parametros chave (podem ser alterados futuramente):
  circleRadius: TILE_SIZE * 0.4  (12.8px — ligeiramente maior que o player
                para boa visibilidade. Alternativa: TILE_SIZE * 0.3 * 0.9)

  startAngle:   -Math.PI / 2 (topo, 12 horas)
  direction:    horario (aumento de angulo)

Estes valores devem ser definidos como constantes no inicio da funcao
para facil ajuste futuro.

11. NOTAS ADICIONAIS
================================================================================

- A UI circular e UMA RENDERIZACAO NO CANVAS, nao um elemento DOM.
  Isso permite que ela siga as coordenadas do mundo (artefato/altar)
  e se mova com a camera, alem de permitir desenho arbitrario
  (arcos, gradientes, circulos ocos).

- A grossura da linha de 15% foi definida como valor inicial e pode
  ser alterada futuramente. Deve ser uma constante facil de modificar.

- O progresso do circulo reflete player.interactTimer / interactDuration.
  Para altar, a duracao e 4 segundos. Para artefato, 1.5 segundos.

- O circulo NAO aparece para interacao com porta (toggle instantaneo).

- Para portas duplas, a cor DOOR_CLOSED_COLOR em renderTiles garante
  que mesmo sem o renderDoors detalhado, o jogador veja que ha uma
  porta ali.
