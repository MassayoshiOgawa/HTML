2.1 - PROBLEMA ATUAL
Em Game.loadMap(), o codigo que cria/reposiciona jogadores usa:

    const ox = i > 0 ? ((i % 2 === 1 ? 1 : -1) * Math.ceil(i / 2)) : 0;

Isso resulta em:
  P1: offset=0,  sx=playerSpawn.x,   sy=playerSpawn.y
  P2: offset=+1, sx=playerSpawn.x+1, sy=playerSpawn.y
  P3: offset=-1, sx=playerSpawn.x-1, sy=playerSpawn.y
  P4: offset=+2, sx=playerSpawn.x+2, sy=playerSpawn.y

Problemas:
  1. Todos compartilham o mesmo Y (sy = playerSpawn.y), podendo sobrepor
  2. Nao verifica se o tile na posicao calculada e valido (passavel)
  3. Em mapas futuros, pode haver uma parede (O), moveis (W), ou porta solida (d) na coordenada calculada

2.3 - NOVO METODO: Game.findSpawnPosition(baseX, baseY, playerIndex)
Adicionar este metodo na classe Game (antes ou depois de loadMap):

    findSpawnPosition(baseX, baseY, playerIndex) {
      // Calcula offsets baseados no indice do jogador
      // P1: +0, P2: +1, P3: -1, P4: +2
      let offsetsX = [0, 1, -1, 2];
      let offsetsY = [0, 0, 0, 0];
      
      if (playerIndex >= offsetsX.length) playerIndex = 0;
      let tx = baseX + offsetsX[playerIndex];
      let ty = baseY + offsetsY[playerIndex];
      
      // Verifica se a posicao calculada e valida (dentro do mapa e passavel)
      if (this.isWalkableTile(tx, ty)) {
        return { x: tx, y: ty };
      }
      
      // Se nao for valida, faz busca em raio crescente ao redor do spawn
      for (let radius = 1; radius <= 5; radius++) {
        // Prioriza tiles na horizontal (mesma linha)
        for (let dx = -radius; dx <= radius; dx++) {
          const checkX = baseX + dx;
          const checkY = baseY;
          if (this.isWalkableTile(checkX, checkY)) {
            return { x: checkX, y: checkY };
          }
        }
        // Depois tenta linhas acima e abaixo
        for (let dy = -radius; dy <= radius; dy++) {
          if (dy === 0) continue; // ja verificamos dy=0
          for (let dx = -radius; dx <= radius; dx++) {
            const checkX = baseX + dx;
            const checkY = baseY + dy;
            if (this.isWalkableTile(checkX, checkY)) {
              return { x: checkX, y: checkY };
            }
          }
        }
      }
      
      // Fallback: retorna o proprio spawn mesmo que seja invalido
      return { x: baseX, y: baseY };
    }

2.4 - NOVO METODO AUXILIAR: Game.isWalkableTile(tx, ty)
Adicionar este metodo auxiliar:

    isWalkableTile(tx, ty) {
      if (tx < 0 || ty < 0 || tx >= this.mapWidth || ty >= this.mapHeight) return false;
      const tile = this.tiles[ty][tx];
      if (tile === 'O' || tile === 'W') return false;
      if (tile === 'd') {
        const door = this.doorEntities.find(d => d.tileX === tx && d.tileY === ty);
        if (door && door.solid) return false;
      }
      return true;
    }

Obs: isWalkableTile replica a logica de colisao de Player.canMoveTo() sem a margem de 4px. Apenas verifica se o tile e' fundamentalmente transponivel.
