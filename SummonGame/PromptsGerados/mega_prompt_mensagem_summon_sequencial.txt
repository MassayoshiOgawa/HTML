1. DESCRICAO DA IDEIA
================================================================================

Quando um jogador completa o ritual de summon no altar (tile 'A'), apos o
delay de 3 segundos (this.summonDelay), o monstro e spawnado via
spawnMonster(). Atualmente, spawnMonster() ja define uma mensagem unica:
  this.monsterTypeMessage = mt.name + ' heard you. Run. (Round ...)'
  this.monsterTypeMsgTimer = 3.0

A nova ideia substitui e MELHORA este sistema com duas fases sequenciais:

FASE 1 (duracao: 2 segundos):
  Exibir no centro da tela (exatamente onde o elemento #message aparece):
    "<nome do monstro> ouviu voce. Corra."
  (sem asteriscos, sem italico, apenas o nome do monstro direto)
  Esta frase substitui a mensagem "Summoning ritual begins..." existente
  e a antiga mensagem "heard you. Run.".

FASE 2 (duracao: 3 segundos, inicia automaticamente apos Fase 1):
  Exibir em cima da barra de itens (hotbar), centralizado horizontalmente,
  a descricao do monstro (mt.desc).
  Posicao: acima do #hotbar-hud (que esta a bottom:10px), aproximadamente
  a bottom:80px, centralizado.
  A descricao nao deve bloquear as mensagens normais do jogo (showMessage).
  Mensagens normais continuam aparecendo no centro da tela normalmente,
  agora com FONTE 20% MAIOR.

COMPORTAMENTO EM MULTIPLAYER:
  A mensagem e global — todos os jogadores veem as duas fases.
  Nao depende de qual jogador iniciou o summon.

2. FLUXO COMPLETO DO NOVO SISTEMA
================================================================================

Evento: Player completa interacao no altar, summonDelay inicia (3s)
  -> Durante summonDelay: mensagem normal "Summoning ritual begins..." (existe)
  -> Quando summonDelay chega a 0: spawnMonster() e chamado
     spawnMonster() agora deve:

     1. Selecionar tipo de monstro (weightedRandom), incrementar round etc
     2. this.summonPhase = 'name'        (fase atual: exibindo nome)
     3. this.summonPhaseTimer = 2.0      (duracao da fase 1)
     4. this.summonPhaseMessage = mt.name + ' ouviu voce. Corra.'
        (guardar para ser exibido no centro)
     5. this.monsterDesc = mt.desc       (guardar descricao para fase 2)
     6. this.summoning = false           (ritual terminou)
     7. Spawnar o monstro (codigo existente)
     8. this.summonCount++, roundNumber++ etc (codigo existente)

Game.update() (a cada frame):
  Se summonPhase for 'name':
    decrementar summonPhaseTimer por dt
    Se summonPhaseTimer <= 0:
      summonPhase = 'desc'
      summonPhaseTimer = 3.0
      (a fase 2 comeca automaticamente)
  Se summonPhase for 'desc':
    decrementar summonPhaseTimer por dt
    Se summonPhaseTimer <= 0:
      summonPhase = ''     (fim, limpar)
      summonPhaseMessage = ''
      monsterDesc = ''

RENDERIZACAO:

  FASE 1 (summonPhase === 'name'):
    Usar o sistema de mensagem central existente (#message DOM element).
    Chamar showMessage( summonPhaseMessage ) com duracao de 2 segundos.
    (showMessage original usa messageTimer = 2.5 — ajustar ou criar
     logica para que a fase 1 dure exatamente 2 segundos sem conflito)

    IMPORTANTE: A mensagem "ouviu voce. Corra." DEVE substituir a mensagem
    antiga "mt.name + ' heard you. Run.'" que estava em monsterTypeMessage.
    O campo this.monsterTypeMessage e this.monsterTypeMsgTimer deixam de
    existir ou sao substituidos pelo novo sistema sequencial.

  FASE 2 (summonPhase === 'desc'):
    Novo elemento DOM (criado no <body> junto com os outros elementos):
    <div id="summon-desc"></div>

    CSS deste elemento:
      position: absolute
      bottom: 80px          (acima da hotbar que esta a bottom:10px)
      left: 50%
      transform: translateX(-50%)
      z-index: 10
      color: #fff
      font-size: 18px
      text-align: center
      pointer-events: none
      font-family: 'Courier New', monospace
      text-shadow: 0 0 6px rgba(0,0,0,0.9)
      opacity: 0 (inicial, transicao via classe 'show')
      transition: opacity 0.3s

    Controlado via:
      showSummonDesc(text):
        el = document.getElementById('summon-desc')
        el.textContent = text
        el.classList.add('show')
      hideSummonDesc():
        el.classList.remove('show')

  MENSAGENS NORMAIS (showMessage) COM FONTE 20% MAIOR:
    O elemento #message atual tem font-size: 24px.
    Alterar para font-size: 28.8px (24 * 1.2 = 28.8, arredondar para 29px).
    Manter todas as outras propriedades CSS inalteradas.
    As mensagens normais (coleta de artefato, item comprado, etc) continuam
    funcionando exatamente como antes, sem serem bloqueadas pela fase 2.

Game.update() — NOVA SECAO:
  Apos a secao "Monster type message" (ou substituindo-a):
    if (this.summonPhase === 'name') {
      this.summonPhaseTimer -= dt;
      if (this.summonPhaseTimer <= 0) {
        this.summonPhase = 'desc';
        this.summonPhaseTimer = 3.0;
        this.hideSummonDesc(); // garantir que desc anterior sumiu
        this.showSummonDesc(this.monsterDesc);
        // Esconder a mensagem central
        this.showMessage('');
      }
    } else if (this.summonPhase === 'desc') {
      this.summonPhaseTimer -= dt;
      if (this.summonPhaseTimer <= 0) {
        this.summonPhase = '';
        this.hideSummonDesc();
        this.monsterDesc = '';
        this.summonPhaseMessage = '';
      }
    }

  Quando summonPhase muda de 'name' para 'desc', a mensagem central some
  (showMessage('')) e a descricao aparece acima da hotbar.

  Enquanto summonPhase esta ativo, o sistema de mensagens normais
  (showMessage) continua funcional — outras mensagens podem aparecer
  no centro mesmo durante a fase 2.
