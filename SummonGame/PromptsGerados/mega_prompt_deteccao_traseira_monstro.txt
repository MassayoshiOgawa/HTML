1. DESCRICAO DA IDEIA
================================================================================

Atualmente, quando o modo debug (F1) esta ativo no jogo SummonGame, o jogador
pode ver o cone de visao frontal do monstro (renderVisionCone), que mostra a
area de 120 graus (2*PI/3) a frente do monstro com alcance de 195 pixels.

Porem, o monstro tambem possui um sistema de deteccao traseira chamado
canDetectBehind(), que detecta o jogador quando ele esta muito proximo por
tras do monstro. Esta area de deteccao traseira NAO e exibida visualmente
no modo debug, deixando o jogador sem nocao do tamanho real dessa zona de
risco.

OBJETIVO: Criar um novo metodo de renderizacao (ou estender o existente)
para exibir visualmente, quando F1 estiver ativo, o raio/area de deteccao
traseira do monstro, permitindo que o jogador veja claramente o tamanho
dessa zona de deteccao.

3. ESPECIFICACAO TECNICA DA IMPLEMENTACAO
================================================================================

3.1 - O QUE DESENHAR:
  Um setor circular (tipo "fatia de pizza") atras do monstro representando
  a area de deteccao traseira, com as seguintes caracteristicas:
  - Raio: 45 pixels (mesmo valor usado em canDetectBehind)
  - Arco: de facingAngle + PI*0.65 ate facingAngle - PI*0.65 (percorrendo
    o lado MAIS LONGO, ou seja, por tras do monstro)
  - Isso resulta em um setor de aproximadamente 126 graus (2*PI - 2*PI*0.65)

3.2 - VISUAL (APARENCIA):
  - Cor de preenchimento: rgba(255, 165, 0, 0.15) — laranja claro
    semi-transparente (diferente do vermelho do cone frontal)
  - Cor do contorno: rgba(255, 165, 0, 0.5) — laranja mais opaco
  - Espessura da linha: 1 pixel
  - Deve ser desenhado como um arc + lineTo para formar um setor fechado,
    similar ao renderVisionCone() mas com as cores laranja

3.3 - POSICIONAMENTO MATEMATICO:
  Coordenadas de tela:
    rx = this.px - game.camX
    ry = this.py - game.camY
  Angulos:
    startAngle = this.facingAngle + Math.PI * 0.65
    endAngle   = this.facingAngle - Math.PI * 0.65
  NOTA: No canvas, arcos sao desenhados no sentido horario. Como queremos
  o arco MAIS LONGO entre startAngle e endAngle, precisamos garantir que
  o desenho percorra o lado correto. Em canvas 2D, se startAngle > endAngle
  e usamos counterclockwise=false (sentido horario), o arco vai do maior
  para o menor passando pelo lado "frente". Para pegar o lado "tras",
  precisamos usar counterclockwise=true OU inverter a logica.
  SOLUÇÃO RECOMENDADA: Usar counterclockwise=true no arc():
    ctx.arc(rx, ry, 45, this.facingAngle + Math.PI * 0.65, this.facingAngle - Math.PI * 0.65, true)
  Isso fara o arco percorrer de startAngle ate endAngle no sentido
  anti-horario, que e o lado "traseiro" (o arco mais longo).

3.4 - CONDICOES DE EXIBICAO:
  - So deve ser desenhado se:
    a) this.alive === true (monstro esta vivo)
    b) game.debugMode === true (F1 ativo)
  - Exatamente as mesmas condicoes do renderVisionCone()

3.5 - METODO RECOMENDADO:

Metodo renderVisionCone() atual (linha ~1262):
------------------------------------------------
  renderVisionCone(ctx, game) {
    if (!this.alive || !game.debugMode) return;
    const rx = this.px - game.camX;
    const ry = this.py - game.camY;
    const r = 195;
    ctx.strokeStyle = 'rgba(255,0,0,0.3)';
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.arc(rx, ry, r, this.facingAngle - Math.PI / 3, this.facingAngle + Math.PI / 3);
    ctx.lineTo(rx, ry);
    ctx.closePath();
    ctx.stroke();
  }

Metodo canDetectBehind() (linha ~983):
------------------------------------------------
  canDetectBehind() {
    const player = this.findNearestPlayer();
    if (!player) return false;
    const dx = player.px - this.px;
    const dy = player.py - this.py;
    const dist = Math.sqrt(dx * dx + dy * dy);
    if (dist > 45) return false;
    const angleToPlayer = Math.atan2(dy, dx);
    let diff = angleToPlayer - this.facingAngle;
    while (diff > Math.PI) diff -= Math.PI * 2;
    while (diff < -Math.PI) diff += Math.PI * 2;
    if (Math.abs(diff) > Math.PI * 0.65) return true;
    return false;
  }
