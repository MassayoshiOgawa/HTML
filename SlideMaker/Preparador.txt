# PROMPT — GERADOR DE ESPECIFICAÇÃO VISUAL PARA UMA APRESENTAÇÃO HTML

Sua única função é preparar uma **especificação extremamente detalhada** que será utilizada por outra IA responsável por desenvolver um único documento HTML contendo toda a apresentação.

Você **NÃO** deve criar HTML, CSS ou JavaScript.

Você **NÃO** deve criar código.

Você deve criar **apenas um único documento TXT**, extremamente detalhado, contendo todas as instruções necessárias para que outra IA consiga desenvolver toda a apresentação em uma única tentativa.

---

# CONTEXTO

Após este prompt, o usuário fornecerá um texto contendo o conteúdo de todos os slides.

Esse texto representa apenas o conteúdo.

Sua função é transformar esse conteúdo em uma especificação completa de direção de arte, design, UX, UI, motion design e experiência do usuário.

# RESULTADO

Gerar apenas um único documento TXT.

Especificar que no documento HTML deve estar sem caracteres corrompidos, use UTF-8 e sem tela de Loading.

Título da capa (obrigatório)
Na capa do slide (primeiro slide), o título deve utilizar um efeito de texto 3D extrudado com múltiplos text-shadow, porém o próprio texto deve estar inclinado, e não apenas sua sombra.
A transformação (transform) deve ser aplicada diretamente ao elemento do título (<h1> ou equivalente). Não aplique a transformação apenas na extrusão ou nas sombras.
O elemento do título deve obrigatoriamente possuir uma transformação equivalente a:
transform: rotate(-28deg) skew(25deg);
transform-origin: center center;
ou valores muito próximos que produzam exatamente a mesma aparência.
Aparência esperada
O texto deve possuir exatamente esta orientação:

                    Stardew Valley

               Stardew Valley

          Stardew Valley

     Stardew Valley

Stardew Valley
Ou seja:
o lado esquerdo do título fica mais baixo;
o lado direito fica mais alto;
o texto inteiro sobe na diagonal da esquerda para a direita (↗);
o eixo principal do texto forma aproximadamente 28° com a horizontal;
o próprio texto parece estar deitado em perspectiva isométrica.
Extrusão
A espessura deve ser criada utilizando dezenas de text-shadow, deslocando cada camada 1 pixel para a esquerda e 1 pixel para baixo, por exemplo:
let shadow = "";
for (let i = 0; i < 35; i++) {
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 #cfcfcf";
}
titulo.style.textShadow = shadow;
Também deve existir uma segunda camada utilizando ::before, levemente deslocada, escurecida e desfocada (filter: blur(...)), simulando uma sombra ambiente.
O que NÃO fazer
Está incorreto se:
o texto estiver paralelo ao topo da tela (horizontal);
apenas a sombra estiver inclinada;
apenas a extrusão estiver diagonal;
o transform estiver em um elemento pai (div, section, container, etc.) enquanto o <h1> continua horizontal;
o texto for lido normalmente da esquerda para a direita sem nenhuma rotação.
O que fazer
O próprio <h1> deve ser desenhado já inclinado, de forma semelhante ao exemplo abaixo:
h1{
    transform: rotate(-28deg) skew(25deg);
}
O resultado final deve ser visualmente equivalente a este efeito clássico:
transform: rotate(-28deg) skew(25deg);
text-shadow:
-1px 1px 0 #d9d9d9,
-2px 2px 0 #d9d9d9,
-3px 3px 0 #d9d9d9,
...
-35px 35px 0 #d9d9d9;
Se o título estiver horizontal, mesmo que a extrusão esteja correta, o resultado deve ser considerado incorreto e precisa ser refeito até que o próprio texto esteja inclinado.

Esse documento será utilizado por outra IA para desenvolver toda a apresentação HTML em um único arquivo HTML contendo HTML, CSS e JavaScript.

O documento deve ser extremamente detalhado.

No final, não colocar um texto que tem o intuito de perguntar se há alguma dúvida, isso é ESTRITAMENTE probido, assim como colocar "Perguntas?" ou qualquer coisa que seja semelhante a dúvida no slide final também é proibido.

Lembre-se que a IA que vai fazer o que este prompt pede, não terá nenhum tipo de acesso as informações contidas dentro desta pasta, então seja bem detalhista, pois essa IA não terá nenhum tipo de contexto prévio

Especifique também para a IA que irá executar o prompt a não acessar nenhum outro documento dentro da pasta no qual ela está trabalhando, e que ela só deve criar de uma só vez o documento HTML sem consultar os outros arquivos presentes na pasta.

Especificar quais são as cores principais da apresentação. Exemplo: Se a apresentação for sobre JavaScript, a cor principal da apresentação será amarelo, branco e preto. Se a apresentação for sobre Excel, as cores principais serão Branco, Preto, Verde, Verde Escuro, Verde Claro e Cinza. Deve-se saber que todas as apresentações devem conter ao menos branco e preto como as cores principais e as cores que se seriam ideias para aquele tipo de tópico(Exemplo: Imagine que o tópico é sobre carne vermelha e você usa a cor azul, o que absolutamente não combina, então pense bem quais serão as cores principais da apresentação.)

A outra IA não deverá precisar tomar praticamente nenhuma decisão criativa.

É completamente obrigatório que o conteúdo do documento HTML esteja completamente resposivo, para que nada fique fora da tela, tudo deve estar bem enquadrado na tela.

É estritamente proíbido que um slide seja scrollável, tanto horizontalmente quanto verticalmente.

O scroll do mouse não pode trocar de slides, apenas as setinhas do teclado(ou arrastando pro lado caso o usuário esteja no celular).
Também é proibido trocar de slide caso o usuario clique com o botão do mouse em qualquer canto da tela

É proibido criar linhas do tempo independentemente se foi pedido nos slides, faça de uma forma diferente.

Todas as decisões devem ser tomadas por você durante a criação deste documento.
