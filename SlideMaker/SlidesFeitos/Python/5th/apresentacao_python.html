Tipos de Dados Básicos

int, float, complex
# Números em Python
x = 42 # int
y = 3.14 # float
z = 1+2j # complex
Python suporta inteiros de precisão arbitrária e números complexos nativamente.
str (imutável)
nome = "Python" # aspas duplas
lingua = 'Programação' # aspas simples
texto = """Docstring""" # multi-linha
Strings são sequências imutáveis de caracteres Unicode. Suportam fatiamento e concatenação.
True e False
ativo = True
if ativo:
    print('ok') # executa
Booleanos são subclass de int. True == 1 e False == 0. Use para controle de fluxo.
list, tuple, dict, set
nums = [1, 2, 3] # list
dados = {'chave': 'valor'} # dict
unico = {1, 2, 3} # set
Cada tipo de coleção tem propriedades específicas: mutável, ordenado, único, etc.

Programação Orientada a Objetos

Pessoa
- _nome: str
- _idade: int
+ __init__(self, nome, idade)
+ __str__(self) → str
+ get_nome(self) → str
Herança Polimorfismo Encapsulamento
class Pessoa:
    def __init__(self, nome, idade):
        self._nome = nome
        self._idade = idade

    def __str__(self):
        return f"{self._nome}, {self._idade} anos"

    @property
    def nome(self):
        return self._nome
