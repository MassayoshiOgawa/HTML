6. ANIMAÇÕES GLOBAIS — SISTEMA COMPLETO
=====================================================================================

PRINCÍPIO: Nenhum elemento aparece antes de sua animação. Estado inicial: opacity 0, transform aplicado. A transição entre slides segue: saída completa do anterior → estabilização → entrada do novo.

DURAÇÕES PADRÃO:
  Fade In/Out:          400-600ms
  Slide In (direção):   500-700ms
  Scale In:             400-600ms
  Blur In:              500-700ms
  Stagger entre itens:  80-120ms
  Transição entre slides: 600-800ms (cross-fade)
  Delay após troca de slide: 100ms (antes de iniciar animações de entrada)

EASING PADRÃO (usar em todas as animações CSS):
  Entrada: cubic-bezier(0.16, 1, 0.3, 1)  — "ease out quart" suave
  Saída:   cubic-bezier(0.55, 0, 1, 0.45) — "ease in quart"
  Geral:   cubic-bezier(0.25, 0.46, 0.45, 0.94)

STAGGER: Múltiplos elementos do mesmo tipo entram em cascata com delay de 100ms entre cada um.

COREOGRAFIA PADRÃO (ordem de entrada em cada slide):
  1. Background (já está, não anima — é fixo)
  2. Elementos decorativos de fundo (círculos, linhas, formas abstratas) — delay: 0ms
  3. Título principal — delay: 150ms
  4. Subtítulo — delay: 300ms
  5. Cards/Blocos de conteúdo — delay: 400ms (com stagger)
  6. Texto, listas, parágrafos — delay: 500ms (com stagger)
  7. Código, gráficos — delay: 600ms
  8. Ícones, badges — delay: 700ms (com stagger)
  9. Botões, CTAs — delay: 800ms
  10. Efeitos finais (glow, partículas especiais) — delay: 900ms

TRANSIÇÃO ENTRE SLIDES:
  Base: Cross-fade com zoom sutil (scale 1.02 → 1.00)
  Quando o usuário avança: slide atual fade out (300ms), pausa de 80ms, novo slide fade in com zoom
  Quando o usuário volta: mesma transição, sem diferença
  Variações entre slides especificadas na seção de cada slide

REINICIALIZAÇÃO: Ao sair de um slide, TODOS os elementos devem retornar ao estado inicial (opacity 0, transforms resetados). Ao retornar, a animação completa deve ser executada novamente.

MICROANIMAÇÕES CONTÍNUAS (após entrada, em idle):
  Títulos: leve respiração de glow (opacidade do text-shadow varia 0.8-1.0 em 3s loop)
  Cards: flutuação vertical de 2-3px em 4s loop
  Partículas: movimento contínuo (já fazem parte do background)
  Botões: glow pulsante muito sutil
  Ícones decorativos: rotação de 0.5 graus ou flutuação
