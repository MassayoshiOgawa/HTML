Boas Práticas e Estilo

📐 PEP 8 — guia de estilo oficial ▼
PEP 8 define convenções de estilo para código Python: indentação de 4 espaços, linhas de até 79 caracteres, nomes em snake_case para variáveis e funções.
✏️ Nomes descritivos e código legível ▼
Use nomes que expliquem a intenção: calcular_media() em vez de calc(). Código legível é mais importante que código curto.
🧪 Testes com unittest / pytest ▼
Escreva testes automatizados. pytest é a ferramenta mais popular: simples, poderosa e com suporte a fixtures e parametrização.
📖 Documentação com docstrings ▼
Documente funções e classes com docstrings (PEP 257). Use """triplas aspas""" para descrever parâmetros, retornos e exemplos de uso.
