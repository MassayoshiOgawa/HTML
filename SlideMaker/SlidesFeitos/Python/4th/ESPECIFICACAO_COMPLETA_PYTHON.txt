- Page Up: slide anterior

SWIPE (TOUCH):
- Swipe para esquerda: próximo slide
- Swipe para direita: slide anterior
- Sensibilidade: 50px de distância mínima
- Apenas em dispositivos touch

TRANSIÇÃO ENTRE SLIDES:
Todas as transições seguem este protocolo:
1. Usuário solicita mudança
2. Slide atual inicia fade out (opacidade 1 → 0, escala 1 → 0.97, blur 0 → 6px, duração 400ms ease-out)
3. Após 400ms, slide atual display:none
4. Novo slide display:block, opacity:0, com elementos no estado inicial
5. Pequeno delay de 50ms para estabilização DOM
6. Inicia sequência de entrada do novo slide

Exceção: Entre slides com conteúdo relacionado (ex: 4→5, 9→10→11), usar crossfade
com o slide anterior permanecendo como fundo desfocado enquanto o novo entra.

TÍTULO 3D EXTRUDADO — ESPECIFICAÇÃO DETALHADA:
O título "Python: Uma Linguagem Versátil e Poderosa" deve usar efeito 3D
extrudado com text-shadow, SEM rotação, SEM skew, SEM perspective.

Cor do texto principal: #FFFFFF (branco puro, SEM gradiente no texto)
A extrusão usa múltiplas camadas de text-shadow em gradiente de cor:
- Primeiras camadas (próximas ao texto): #5A9FD4 (azul Python claro)
- Camadas intermediárias: #3776AB (azul Python médio)
- Últimas camadas (mais distantes): #1A4C6A (azul escuro)
- Transição suave entre as cores

Implementação via JavaScript:
let shadow = "";
const steps = 40;
for (let i = 0; i < steps; i++) {
  const progress = i / steps;
  // Deslocamento: -i px horizontal, i px vertical (sombra para baixo e levemente esquerda)
  const r = Math.round(55 + (26 - 55) * progress);     // 55 → 26
  const g = Math.round(118 + (76 - 118) * progress);    // 118 → 76
  const b = Math.round(171 + (74 - 171) * progress);    // 171 → 74
  const color = `rgb(${r}, ${g}, ${b})`;
  shadow += (shadow ? "," : "") + (-i) + "px " + i + "px 0 " + color;
}
titulo.style.textShadow = shadow;
