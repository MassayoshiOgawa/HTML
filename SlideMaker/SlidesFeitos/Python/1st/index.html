História do Python

Da década de 80 até os dias atuais

1980s A Ideia

Guido van Rossum começa a desenvolver o Python como sucessor da linguagem ABC. O nome foi inspirado no grupo Monty Python.

1991 Primeira Versão

Primeira versão pública lançada em 20 de fevereiro de 1991. Já incluía classes, funções e tratamento de exceções.

1994 Python 1.0

Primeira versão oficial 1.0. Introdução de lambda, map, filter e reduce.

2000 Python 2.0

Grande marco. List comprehensions, garbage collection, suporte a Unicode. Python começa a ganhar massa crítica.

2008 Python 3.0

Revolução que quebrou compatibilidade com Python 2. Print vira função, divisão real, melhorias de string e muito mais.

Hoje Presente e Futuro

Python é a linguagem que mais cresce no mundo. Dominante em IA, Ciência de Dados e Automação. Versão 3.13+ continua evoluindo.
