O que é Python?
Uma linguagem que transformou a programação

Python é uma linguagem de programação de código aberto, de alto nível e interpretada, criada por Guido van Rossum em 1991.

Sua sintaxe clara e legível torna o código fácil de entender e manter. É uma das linguagens mais amigáveis para iniciantes e ao mesmo tempo poderosa o suficiente para profissionais.

Primeira versão (0.9.0)
Criada por Guido van Rossum — desenvolvedor holandês. O nome Python foi inspirado no grupo de comédia britânico Monty Python's Flying Circus. O objetivo era criar uma linguagem intuitiva, poderosa e divertida de usar.
