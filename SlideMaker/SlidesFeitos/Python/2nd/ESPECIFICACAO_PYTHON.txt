8. SISTEMA GLOBAL DE ANIMAÇÕES E TRANSIÇÕES

TRANSIÇÃO ENTRE SLIDES:
- Tipo: Cross-fade com elevação sutil
- Saída: slide atual fade out (opacity 1 → 0) + translateY(-15px) + scale(0.98)
- Pausa: 200ms com tela preta
- Entrada: novo slide fade in (opacity 0 → 1) + translateY(15px → 0) + scale(0.98 → 1)
- Duração da saída: 400ms, easing: cubic-bezier(0.4, 0, 0.2, 1)
- Duração da entrada: 600ms, easing: cubic-bezier(0.4, 0, 0.2, 1)
- Intervalo entre saída e entrada: 200ms
- O slide de saída só termina completamente antes do próximo começar
- Funciona igual nos dois sentidos (avançar e retroceder)

ESTADO INICIAL DOS ELEMENTOS (ANTES DA ANIMAÇÃO):
Antes do slide tornar-se ativo, todos os elementos devem estar:
- opacity: 0
- No caso de elementos com movimento: transform: translateY(30px) ou translateX(-20px) dependendo do elemento
- No caso de blur: filter: blur(8px)
- No caso de escala: transform: scale(0.95)
- COMPLETAMENTE INVISÍVEIS. NENHUM flash de conteúdo permitido.

ORDEM GERAL DE ENTRADA DOS ELEMENTOS (coreografia):
1. Background e partículas (já devem estar ativos desde o início)
2. Elementos decorativos (linhas, formas geométricas, blobs)
3. Cards e painéis de vidro
4. Título principal (com glow)
5. Subtítulo
6. Conteúdo (texto, listas, parágrafos) — em ordem de leitura
7. Ícones
8. Badges, tags, labels
9. Botões e elementos interativos
10. Efeitos finais (glow que aumenta, destaques)

TIMING PADRÃO:
- Cada elemento usa duração entre 500ms e 900ms
- Stagger entre elementos similares: 80ms a 120ms
- Delay do primeiro elemento: 100ms após slide ativo
- Easing padrão: cubic-bezier(0.4, 0, 0.2, 1) — ease-out suave
- Easing para entradas mais dramáticas: cubic-bezier(0.34, 1.56, 0.64, 1) — overshoot suave

MICROANIMAÇÕES CONTÍNUAS:
- Botões: glow pulsando muito sutilmente (opacity varia 0.3 a 0.6, 3s loop)
- Cards: float vertical de 1px a -1px (4s loop) 
- Partículas: movimento perpétuo
- Indicador de slide ativo na barra: pulse de glow
- Badges: leve brilho metálico passando (5s loop)

REINICIALIZAÇÃO: Ao sair de um slide, todos os elementos devem voltar ao estado inicial. Ao retornar, toda a animação deve rodar novamente do início.

11. EFEITO 3D EXTRUDADO — TÍTULO DA CAPA (SLIDE 1)

O título do primeiro slide "Python: A Linguagem de Programação Versátil e Poderosa" deve usar um efeito de texto 3D extrudado.

IMPLEMENTAÇÃO OBRIGATÓRIA:
- Texto PERFEITAMENTE HORIZONTAL (sem rotação, sem skew, sem perspectiva no elemento)
- A profundidade 3D é criada exclusivamente com text-shadow
- Dezenas de camadas de text-shadow, cada uma deslocada 1px da anterior
- Direção da extrusão: diagonal para baixo-esquerda (-1px, +1px)
- Número de camadas: 35
- Cor das sombras: gradiente do azul escuro para o azul médio (#1a3a5c → #306998)

Exemplo de implementação:
let shadow = "";
for (let i = 1; i <= 35; i++) {
    shadow += (shadow ? "," : "") + (-i) + "px " + i + "px 0 hsl(210, " + (40 + i) + "%, " + (30 - i * 0.5) + "%)";
}
titulo.style.textShadow = shadow;

SEGUNDA CAMADA DE PROFUNDIDADE:
- Usar ::before ou um pseudo-elemento
- Levemente deslocado (-3px, 3px)
- Escurecido (opacity 0.3)
- Filter: blur(6px)
- Simula sombra ambiente

O Z-INDEX DO TÍTULO DEVE SER 0 para não sobrepor outros elementos.

O título deve ser o elemento principal da capa, centralizado, com tamanho entre 3.8rem e 4.5rem dependendo da resolução.
