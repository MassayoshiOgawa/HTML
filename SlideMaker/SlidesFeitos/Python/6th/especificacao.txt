# 8. ANIMAÇÕES GLOBAIS

## Princípio
Todas as animações seguem um sistema de timing unificado. Nenhuma animação é instantânea. Tudo possui duração, delay, easing e direção.

## Variáveis CSS Globais
```
--ease-enter: cubic-bezier(0.16, 1, 0.3, 1)
--ease-exit: cubic-bezier(0.7, 0, 0.84, 0)
--ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1)
--duration-fast: 300ms
--duration-normal: 600ms
--duration-slow: 900ms
--duration-dramatic: 1200ms
```

## Animação de Entrada Padrão (Elementos de Conteúdo)
- **Opacity:** 0 → 1
- **Transform:** translateY(30px) → translateY(0)
- **Filter:** blur(6px) → blur(0)
- **Duração:** 800ms
- **Easing:** cubic-bezier(0.16, 1, 0.3, 1)

## Animação de Entrada de Títulos
- **Opacity:** 0 → 1
- **Transform:** translateY(20px) + scale(0.96) → translateY(0) + scale(1)
- **Filter:** blur(8px) → blur(0)
- **Duração:** 900ms
- **Easing:** cubic-bezier(0.16, 1, 0.3, 1)
- **Glow:** sombra externa do título aumenta gradualmente durante a animação

## Animação de Entrada de Cards
- **Opacity:** 0 → 1
- **Transform:** translateY(40px) + scale(0.94) → translateY(0) + scale(1)
- **Filter:** blur(10px) → blur(0)
- **Sombra:** aumenta gradualmente
- **Duração:** 900ms
- **Easing:** cubic-bezier(0.16, 1, 0.3, 1)

## Animação de Entrada de Ícones
- **Opacity:** 0 → 1
- **Transform:** scale(0.5) + rotate(-10deg) → scale(1) + rotate(0)
- **Duração:** 700ms
- **Easing:** cubic-bezier(0.34, 1.56, 0.64, 1) (bounce sutil)

## Stagger
- Quando existem múltiplos elementos semelhantes (cards, ícones, itens de lista), eles entram em sequência
- **Atraso entre elementos:** 100-150ms
- **Início:** após a animação do título principal
- **Duração total do stagger:** deve ser confortável, não apressado

## Sequenciamento por Slide
1. Background se estabiliza (0ms)
2. Elementos decorativos surgem (100-300ms)
3. Título principal entra (200-400ms)
4. Subtítulo entra (350-550ms)
5. Conteúdo/cards entram com stagger (500-900ms)
6. Ícones e elementos interativos entram (700-1100ms)
7. Efeitos finais (glow, partículas) (800-1200ms)

## Transição entre Slides
- **Saída do slide atual:** opacity 0, transform scale(0.98), filter blur(4px), duração 400ms, ease-in
- **Entrada do próximo slide:** opacity 0→1, transform translateY(20px)→0, filter blur(6px)→0, duração 600ms, ease-out
- **Intervalo entre saída e entrada:** 100ms
- **Efeito:** dissolve suave, nunca flash

## Microanimações Contínuas
- Partículas: flutuação constante
- Blobs de background: drift lento
- Glow de elementos ativos: respiração sutil (opacidade varia 0.8-1.0 em 4 segundos)
- Elementos decorativos: leve oscillação de 0.5-1 grau
- Reflexos em superfícies glass: movimento sutil
