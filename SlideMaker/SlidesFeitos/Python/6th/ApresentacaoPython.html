Exceções

Tratamento de Exceções

try

O bloco que contém o código que pode gerar erro. Python tenta executar este bloco normalmente.

except

Captura exceções específicas ou genéricas. Permite tratamento granular de erros.

finally

Executa sempre, independente de erro. Ideal para limpeza de recursos.
excecoes.py
try:
  resultado = 10 / 0
except ZeroDivisionError:
  print("Erro: divisão por zero")
except Exception as e:
  print(f"Erro: {e}")
finally:
  print("Executado sempre")
