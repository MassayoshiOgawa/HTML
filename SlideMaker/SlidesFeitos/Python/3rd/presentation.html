O que é Python?

Python é uma linguagem de programação de alto nível, interpretada e multiparadigma.

#1 Linguagem mais amada

Criada por Guido van Rossum (1991)

Desenvolvida nos Países Baixos como sucessora da linguagem ABC.

Há mais de 30 anos moldando o futuro da programação

Foco em legibilidade e produtividade

Filosofia Zen do Python: "Simples é melhor que complexo".

Código limpo que qualquer pessoa pode entender

Principais Características

O que torna o Python especial

Sintaxe simples e expressiva

Blocos definidos por indentação, sem chaves ou palavras-chave desnecessárias. O código Python se aproxima da língua inglesa.

Tipagem dinâmica e forte

Variáveis sem declaração explícita de tipo, com segurança de tipos.

Gerenciamento automático de memória

Garbage collector integrado que gerencia alocação e desalocação.

Grande biblioteca padrão

Mais de 200 módulos inclusos ("batteries included"). Desde manipulação de arquivos até servidores web.

Suporte a multiparadigma

Multiparadigma: escreva do jeito que fizer sentido para o seu problema.
