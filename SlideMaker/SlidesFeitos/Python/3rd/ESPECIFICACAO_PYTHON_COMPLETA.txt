Voce, IA responsavel pelo desenvolvimento, deve criar um UNICO arquivo HTML contendo toda a apresentacao.

IMPORTANTE: Voce NAO deve acessar, ler ou consultar nenhum outro arquivo presente na pasta de trabalho. Desenvolva o HTML completo em uma unica tentativa, sem buscar referencias externas. Nao abra nenhum outro documento. Nao leia nenhum outro arquivo. Crie tudo de uma so vez.

Use obrigatoriamente a codificacao UTF-8 em todo o documento, declare <meta charset="UTF-8"> e garanta que absolutamente nenhum caractere acentuado, cedilha, til ou especial seja exibido incorretamente. TODAS as animacoes devem usar a seguinte convencao:

- Hover em elementos interativos: transicao de 200ms a 300ms, ease-out

RESPONSIVIDADE — DIRETRIZES

Todo o layout deve ser responsivo.

REGRAS:
1. Usar unidades relativas (vh, vw, %, rem) prioritariamente
2. Nuca usar valores fixos em px para dimensoes de layout
3. Testar nas resolucoes: 1920x1080, 1600x900, 1440x900, 1366x768, 1280x720
4. Em resolucoes menores: reduzir gaps, padding, margens (nao fontes)
5. Em resolucoes muito pequenas (menos de 1024px): reorganizar grids para menos colunas
6. NUNCA permitir scroll
7. NUNCA permitir overflow
8. Manter margem de seguranca de 5% a 8% nas 4 bordas

BUDGET DE LAYOUT:
Antes de implementar cada slide, calcular mentalmente:
- Quanto da altura sera ocupado pelo titulo? (~12%)
- Quanto pela navegacao (dots + indicador)? (~5% inferior)
- Quanto pelo conteudo principal? (~65% a 70%)
- Margens de seguranca: 5% superior, 5% inferior, 8% laterais

Se o conteudo nao couber, usar TABS, ACCORDION ou dividir em mais slides.
