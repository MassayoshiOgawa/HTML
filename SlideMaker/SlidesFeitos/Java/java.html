O QUE É JAVA?

Java é uma linguagem de programação orientada a objetos, de alto nível, criada pela Sun Microsystems em 1995. Conhecida por sua portabilidade, segurança e robustez, é uma das linguagens mais utilizadas no mundo para desenvolvimento web, mobile, desktop e corporativo.

ORIENTAÇÃO A OBJETOS

ENCAPSULAMENTO

Proteção de dados com modificadores private/public. Getters e setters controlam o acesso.

private String nome;
HERANÇA

Reutilização de código com extends. Subclasses herdam atributos e métodos da superclasse.

class Gato extends Animal { }
POLIMORFISMO

Mesmo método, comportamentos diferentes. Sobrescrita (@Override) de métodos.

animal.emitirSom(); // cada classe implementa diferente
ABSTRAÇÃO

Classes abstratas e interfaces definem contratos. Ocultação da complexidade.

interface Veiculo { void mover(); }
Classes vs Objetos Construtores Sobrecarga Sobrescrita Interfaces Classes Abstratas
// Classe abstrata
public abstract class Animal {
protected String nome;
public abstract void emitirSom();
}
// Herança e polimorfismo
public class Cachorro extends Animal {
@Override
public void emitirSom() { System.out.println("Au au!"); }
}

TRATAMENTO DE EXCEÇÕES

try

Bloco que tenta executar código perigoso

catch

Captura e trata a exceção

finally

Sempre executa (mesmo com erro)

throw

Lança uma exceção manualmente

throws

Declara que método pode lançar exceção

Checked

Exceções verificadas em compilação

Unchecked

Exceções em tempo de execução

Exemplo

try { int x = 10 / 0; } catch (ArithmeticException e) { e.printStackTrace(); } finally { // cleanup }
Boa Prática: Nunca engole exceções sem tratar. Sempre faça log do erro.
