7. ANIMACOES GLOBAIS
================================================================================

Transicao entre slides: Fade + Scale sutil
  - Slide saindo: opacity 1 -> 0, transform scale(1) -> scale(0.95), duracao 0.4s
  - Slide entrando: opacity 0 -> 1, transform scale(1.05) -> scale(1), duracao 0.5s, delay 0.1s
  - Easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)

Animacoes de entrada de elementos (dentro de cada slide):
  - Tipo: Fade In + Translate Y (30px para cima)
  - Duracao: 0.5s cada elemento
  - Stagger: 0.12s entre cada elemento
  - Easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)
  - Primeiro elemento comeca com delay de 0.2s apos entrar no slide

Classes CSS para animacao:
  .animate { opacity: 0; transform: translateY(30px); transition: all 0.5s var(--ease-smooth); }
  .animate-in { opacity: 1; transform: translateY(0); }

10. OBSERVACOES FINAIS
================================================================================

- Nao usar imagens externas. Todos os icones devem ser SVG inline.
- Nao usar fontes locais. Carregar Google Fonts.
- Todo o CSS deve estar dentro de <style> no <head>.
- Todo o JavaScript deve estar dentro de <script> no final do <body>.
- O HTML deve ser semantico e acessivel.
- Nao criar nenhum arquivo adicional. Apenas o .html.
- Nao usar bibliotecas externas (sem jQuery, sem Three.js, etc). Apenas vanilla JS.
- Nao usar iframes.
- Nao usar audio ou video.
- O contador de slides deve ser numerico com dois digitos (01/20).
- As cores devem ser definidas como variaveis CSS no :root.
- Usar 'Inter' para conteudo geral e 'JetBrains Mono' para codigo e titulos.
- O fundo com particulas deve usar canvas ou divs com CSS.
- Responsividade obrigatoria: breakpoints em 768px (tablet) e 480px (celular).
- Em celular: grids viram 1 coluna, fontes menores, padding reduzido.
- A apresentacao deve iniciar no slide 1 automaticamente.
- Nao deve haver nenhum scroll, nem horizontal nem vertical, em nenhum slide.
- O codigo deve ser organizado com comentarios separando secoes (SLIDE 01, SLIDE 02, etc.).
- Fim do documento. Nao pergunte se ha duvidas. Nao adicione "Perguntas?" no slide final. Apenas "Obrigado!".
