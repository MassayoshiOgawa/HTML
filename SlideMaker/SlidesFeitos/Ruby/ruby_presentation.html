Ruby

O que é Ruby?

Ruby é uma linguagem de programação dinâmica, open source, focada em simplicidade e produtividade. Criada por Yukihiro "Matz" Matsumoto, ela combina uma sintaxe elegante com o poder da orientação a objetos.

Seu objetivo principal é tornar a programação mais intuitiva e agradável, seguindo o princípio de que o código deve ser escrito para ser lido por humanos.

Principais características

  • ◆ Sintaxe simples e legível
  • ◆ Orientação a objetos pura
  • ◆ Tipagem dinâmica
  • ◆ Garbage Collector integrado
Usada em desenvolvimento web, automação, APIs e muito mais.

Ruby é uma linguagem interpretada. O código-fonte é analisado por um parser que constrói uma árvore sintática, que é então executada pelo interpretador Ruby (YARV desde a versão 1.9).

Principais Características

◈

Orientação a Objetos Pura

Tudo em Ruby é um objeto — números, strings, classes, módulos. Até mesmo classes são objetos da classe Class.

⇅

Tipagem Dinâmica

Variáveis em Ruby não têm tipo fixo. O tipo é determinado em tempo de execução.

♻

Garbage Collector

Ruby gerencia automaticamente a memória, liberando objetos que não estão mais em uso.

✎

Sintaxe Simples

Código limpo e expressivo. Ruby se aproxima da linguagem natural.

📖

Código Legível

Ruby prioriza a legibilidade humana acima de tudo. O código parece inglês.

Sintaxe Básica

Simplicidade que encanta

Variáveis
nome = 'Ruby' idade = 30 preco = 9.99
Não precisa declarar tipo. Ruby descobre automaticamente.
Condicionais
if idade >= 18 puts 'Maior' end
Estrutura simples, legível e sem parênteses obrigatórios.
Laços
3.times { puts 'Ruby!' }
Laços elegantes com blocos. Menos código, mais expressividade.
Métodos
def saudacao(nome) "Olá, #{nome}!" end
Métodos simples, retorno implícito da última expressão.

Rails

Ruby on Rails

O framework que revolucionou o desenvolvimento web

Ruby on Rails (ou apenas Rails) é um framework de desenvolvimento web full-stack escrito em Ruby. Criado por David Heinemeier Hansson em 2004, Rails popularizou conceitos como MVC (Model-View-Controller), 'Convention over Configuration' e 'Don't Repeat Yourself' (DRY).

Desvantagens

Desafios a considerar

⚠

Menor desempenho

Comparado a linguagens compiladas como Go, Rust ou Java, Ruby pode ser mais lento.

⚠

Menor popularidade

Ruby perdeu espaço para Python e JavaScript, especialmente em Data Science.

⚠

Mercado regional

Menos oportunidades em algumas regiões fora do ecossistema Rails.

⚠

Consumo de memória

Em projetos de grande escala, Ruby pode consumir mais memória que alternativas.
