================================================================================

8.1 — Transições entre Slides:
Cada slide usa uma transição diferente (variedade), mantendo elegância:

- Slide 1→2: Cross Fade (800ms, easeInOut)
- Slide 2→3: Slide com direção esquerda (700ms, easeInOutCubic)
- Slide 3→4: Fade + Scale sutil (900ms, easeOut)
- Slide 4→5: Cross Fade com blur (1000ms, easeInOut)
- Slide 5→6: Slide esquerda (700ms, easeInOut)
- Slide 6→7: Fade (600ms, easeOut)
- Slide 7→8: Scale + Fade (800ms, easeOut)
- Slide 8→9: Cross Fade (700ms, easeInOut)
- Slide 9→10: Fade + Glow (1000ms, easeOut)

8.2 — Tempos Globais:
- Duração padrão das animações de entrada: 600-1200ms
- Stagger entre elementos: 80-150ms
- Easing padrão: cubic-bezier(0.16, 1, 0.3, 1) — "power ease out"
- Easing para saídas: cubic-bezier(0.55, 0, 1, 0.45) — "power ease in"

8.3 — Animação de Entrada dos Slides:
Quando um slide se torna ativo, seus elementos entram em sequência:
1. Background elements (0ms) — já estão presentes
2. Partículas específicas do slide (0ms)
3. Título do slide (200ms após ativação)
4. Subtítulo (350ms)
5. Conteúdo principal / cards (500ms, com stagger de 100ms entre cards)
6. Elementos decorativos (700ms)
7. Elementos interativos (900ms)
8. Glow/highlights finais (1100ms)

Cada elemento usa opacity: 0 → 1 e transform: translateY(20px) → translateY(0)
(on slide content elements). Título usa translateY(-10px) em vez de baixo.

8.4 — Microanimações Contínuas:
- Cards: leve flutuação vertical de 2-3px com período de 4-6s (respiração)
- Cada card tem um timing diferente (offset de 0.5s entre cards) para não parecerem sincronizados
- Glow em elementos decorativos: oscilação de opacidade entre 0.3 e 0.6 com período de 3-5s
- Partículas: movimento contínuo (descrito no background)
- Botões: leve pulso de brilho na borda a cada 4s (opacidade da borda varia 0.1-0.2)

REGRAS TÉCNICAS FINAIS
================================================================================

- Não usar bibliotecas externas (exceto Google Fonts para Space Grotesk, Inter e JetBrains Mono)
- Todo CSS e JavaScript inline no único arquivo HTML
- CSS: usar variáveis (custom properties) para TODAS as cores

- Canvas para partículas e elementos de fundo
- Animações CSS com @keyframes e transições
- Animações JS com requestAnimationFrame para o que Canvas precisar
- Priorizar performance: limitar partículas, usar will-change com cautela
- Cursor personalizado: oculto em touch devices
- Acessibilidade mínima: aria-labels nos botões, focus visível
