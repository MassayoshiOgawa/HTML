# 1. IDENTIDADE VISUAL GERAL

A apresentação transmite a sensação de explorar algo proibido, abandonado e sobrenatural. É uma experiência visual que combina horror liminal com estética tecnológica corrompida. Cada slide deve parecer um fragmento de memória digital recuperada de um lugar que não deveria existir. A atmosfera é de isolamento, tensão crescente e desconforto existencial. O visual combina o mundo real abandonado (corredores, carpete amarelo, luz fluorescente) com uma camada digital corrompida (glitch, scanlines, interferência).

# 4. ESTILO VISUAL

**Estilo base:** Dark Mode / Horror Liminal / Tech Corrompida

Combinação de:
- **Dark Mode:** Fundo escuro dominante, alta presença de preto
- **Liminal Spaces:** Sensação de lugares familiares mas vazios e errados
- **Glitch/CRT:** Interferência visual, scanlines, distorção sutil
- **Industrial Abandoned:** Texturas de concreto, metal enferrujado, fios expostos
- **Minimalismo sombrio:** Poucos elementos por slide, mas cada um com peso visual enorme

Não se aplica: glassmorphism, neumorphism, futurismo limpo, corporativo, luxuoso.

# 5. CONCEITO ARTÍSTICO

A apresentação deve transmitir a sensação de estar dentro das Backrooms. O usuário não está apenas vendo uma apresentação — está tendo uma experiência de exploração. Cada slide é como caminhar por um corredor infinito onde algo está errado. A luz pisca, o carpete está úmido, o zumbido dos tubos fluorescentes nunca para. A camada digital (glitch, scanlines) representa a "ruptura na realidade" — o momento em que o mundo familiar se fragmenta e revela algo impossível por trás. A experiência deve ser perturbadora, mas visualmente viciante.

# 6. BACKGROUND GLOBAL

## Camadas (de trás para frente):

### Camada 1 — Fundo base
Gradiente radial escuro centrado no viewport:
```css
background: radial-gradient(ellipse at 50% 50%, #1a180f 0%, #0a0a0f 100%);
```

### Camada 2 — Textura de noise/grain
Overlay com noise fino que cobre todo o slide. Grain cinematográfico sutil (opacity 0.03-0.06). Criar via CSS com `background-image: url("data:image/svg+xml,...")` ou gerar via canvas com noise aleatório. Deve ser contínuo e levemente animado.

### Camada 3 — Scanlines
Linhas horizontais finas simulando tela CRT.间距 de 2px, opacity 0.03-0.05. Color: rgba(255,255,255,0.03). Animacao lenta de deslocamento vertical.

### Camada 4 — Vignette
Gradiente radial escurecendo as bordas do viewport. Usar `box-shadow: inset 0 0 150px rgba(0,0,0,0.7)` ou equivalente. Isso cria a sensação de estar olhando através de uma lente ou câmera de segurança.

### Camada 5 — Blobs animados (não em todos os slides)
Em slides específicos (capa, slides de maior impacto), adicionar 1-2 blobs escuros com cor amarela escura (#3d3510) ou verde escuro (#1a2a0a), com animação de movimento lento, blur alto (80-120px), opacity muito baixa (0.08-0.15). Esses blobs transmitem a sensação de luz fluorescente distante se refletindo em superfícies molhadas.

### Camada 6 — Partículas de poeira
Partículas flutuantes simulando poeira suspensa em ar parado. Tipo: pontos brancos com opacity entre 0.02 e 0.08. Movimento: flutuação lenta e aleatória ( translateY + translateX com variação). Velocidade: 20-40 segundos por ciclo. Quantidade: 15-25 partículas. Tamanho: 1-3px. Essas partículas criam a sensação de ar velho e parado, típico de espaços abandonados.

### Camada 7 — Noise de luz (apenas em slides de impacto)
Sobreposição sutil de manchas claras e escuras que simulam reflexo irregular de luz fluorescente em superfícies de concreto. Opacity: 0.02. Movimento: lenta respiração (scale 0.98 → 1.02).

# 7. NAVEGAÇÃO

## Como trocar slides
- **Teclado:** Seta direita (próximo), seta esquerda (anterior). Home = primeiro slide, End = último slide.
- **Mouse:** Apenas os botões de navegação (setas nos cantos inferiores). O scroll do mouse NÃO troca de slides. O clique em qualquer canto da tela NÃO troca de slides.
- **Touch/Swipe:** Arrastar para esquerda (próximo), arrastar para direita (anterior).

## Botões de navegação
- Posicionados nos cantos inferiores do viewport: botão "anterior" no canto inferior esquerdo, botão "próximo" no canto inferior direito.
- Aparência: Ícones de seta (< e >) dentro de círculos sutis.
- Cor: rgba(197, 179, 58, 0.4) normal, rgba(197, 179, 58, 0.9) hover.
- Tamanho: 44px × 44px (mínimo para touch).
- Animação hover: glow amarelo ao redor, leve scale 1.1, transição 300ms ease-out.
- Botão desabilitado (início/fim): opacity 0.2, pointer-events none.

## Navigation dots
- Posicionados na parte inferior central, no mesmo nível de altura dos botões de navegação (alinhados ao centro vertical dos botões).
- Cada dot representa um slide.
- Dot ativo: preenchido com cor amarela (#c5b33a), tamanho 8px.
- Dot inativo: contorno sutil, tamanho 6px, cor rgba(197, 179, 58, 0.3).
- Hover: leve glow, scale 1.3.
- Transição entre dots: suave, 300ms.

## Barra de progresso
- Posicionada ACIMA dos navigation dots (distância de 12px entre a barra e os dots).
- Largura: 200px (ou proporcionais ao número de slides).
- Altura: 3px.
- Cor de fundo: rgba(255,255,255,0.08).
- Cor de preenchimento: gradiente de #c5b33a (esquerda) para #39ff14 (direita).
- Animação de preenchimento: transição suave de 600ms ease-out ao trocar de slide.
- A barra indica o progresso percentual da apresentação.

## Índice de slides
- Pequeno ícone/hambúrguer no canto superior esquerdo.
- Ao clicar, abre painel lateral escuro com lista de todos os slides.
- Cada item clicável leva ao slide correspondente.
- Hover: destaque amarelo.

# 8. ANIMAÇÕES GLOBAIS

## Animações de entrada de elementos
- **Títulos:** Fade In + Move 25px para baixo → 0 + Blur 10px → 0. Duração: 900ms. Easing: cubic-bezier(0.16, 1, 0.3, 1). Delay: 200ms.
- **Subtítulos:** Fade In + Move 15px para cima → 0. Duração: 700ms. Easing: cubic-bezier(0.16, 1, 0.3, 1). Delay: 500ms.
- **Textos de conteúdo:** Fade In + Move 12px para baixo → 0. Duração: 600ms. Easing: ease-out. Delay: 700ms.
- **Cards:** Fade In + Scale 0.94 → 1 + Blur 8px → 0 + Move 20px para baixo → 0. Duração: 800ms. Easing: cubic-bezier(0.16, 1, 0.3, 1). Stagger: 120ms entre cada card.
- **Ícones:** Fade In + Scale 0.5 → 1. Duração: 500ms. Easing: cubic-bezier(0.34, 1.56, 0.64, 1) (spring-like). Delay: variável conforme posição.
- **Elementos com perspectiva 3D:** Entram com fade + translateZ(-30px) → translateZ(0) + leve blur que reduz. Duração: 1000ms. Easing: cubic-bezier(0.16, 1, 0.3, 1).

## Sequência padrão de entrada
1. Background estabiliza (se já não estiver visível)
2. Elementos decorativos (grain, scanlines) já estão ativos
3. Elementos de perspectiva 3D entram
4. Título aparece
5. Subtítulo aparece
6. Conteúdo/cards entram com stagger
7. Ícones e elementos interativos surgem
8. Efeitos finais (glow, partículas extras) aparecem

## Transições entre slides
- **Saída do slide atual:** Todos os elementos fazem Fade Out + Move 15px na direção do avanço + leve Blur. Duração: 500ms. Easing: ease-in.
- **Entrada do novo slide:** Todos os elementos iniciam invisíveis e entram conforme a sequência descrita acima.
- **Delay entre saída e entrada:** 150ms para garantir que o slide anterior terminou completamente.
- **Tipo de transição global:** Dissolve com leve deslocamento horizontal (Push sutil).

## Microanimações contínuas
- Partículas de poeira flutuando: ciclo de 25-40s, movimento sutil.
- Grain noise: leve variação de opacity (0.03 ↔ 0.05) em ciclo de 8s.
- Scanlines: deslocamento vertical lento, ciclo de 12s.
- Blobs de luz (quando presentes): respiração de scale 0.98 ↔ 1.02 em ciclo de 6s.
- Navigation dots: leve pulso do dot ativo (scale 1 ↔ 1.05) em ciclo de 3s.
- Botões de navegação: leve oscilação de opacity (0.4 ↔ 0.6) em ciclo de 4s.

# 9. ELEMENTOS INTERATIVOS GLOBAIS

## Tooltips
- Aparecem no hover de elementos marcados com indicador de tooltip (ícone (?) pequeno).
- Fundo escuro com borda amarela sutil.
- Texto em branco.
- Aparecem com fade + scale 0.95 → 1.
- Posicionamento: acima do elemento, com seta para baixo.

- Transição: 400ms cubic-bezier(0.16, 1, 0.3, 1).

# 10. SISTEMA DE BLOCOS COM PERSPECTIVA 3D

Os blocos com perspectiva 3D real são um elemento recorrente da identidade visual desta apresentação. Eles representam "fragmentos" ou "painéis de controle" encontrados dentro das Backrooms — como monitores de segurança ou painéis industriais abandonados.

## Configurações ( conforme ExemploPerspectiva.html )

**Bloco na metade superior do slide:**
```css
.bloco-perspectiva-superior {
    transform: perspective(250px) rotateX(-10deg) rotateY(25deg);
    transform-origin: 50% 50% 0px;
    perspective-origin: 50% 50%;
}
```

**Bloco na metade inferior do slide:**
```css
.bloco-perspectiva-inferior {
    transform: perspective(250px) rotateX(10deg) rotateY(25deg);
    transform-origin: 50% 50% 0px;
    perspective-origin: 50% 50%;
}
```

## Aparência dos blocos
- **Fundo:** Gradiente escuro com sutil textura de concreto/metal. Exemplo: `linear-gradient(135deg, rgba(30, 28, 20, 0.9), rgba(20, 18, 12, 0.95))`.
- **Borda:** 1px solid rgba(197, 179, 58, 0.12) — borda amarela muito sutil.
- **Sombra:** `box-shadow: 0 20px 40px -12px rgba(0, 0, 0, 0.6), inset 0 1px 0 rgba(197, 179, 58, 0.08)` — sombra profunda + highlight sutil no topo.
- **Border-radius:** 4px.
- **Padding:** mínimo 20px.
- **Largura máxima:** 350px (nunca ultrapassar).
- **Altura máxima:** 420px (nunca ultrapassar).
- **Texto interno:** Herda naturalmente a perspectiva. NENHUMA transformação extra no texto.

## Conteúdo dos blocos
Cada bloco DEVE conter conteúdo real: título, subtítulo, número, ícone com label, ou frase de destaque. NUNCA bloco vazio.

## Animação de entrada dos blocos
- Transição de translateZ(-40px) → translateZ(0) + fade + leve blur que se resolve.
- Duração: 1000ms. Easing: cubic-bezier(0.16, 1, 0.3, 1).

## Responsividade
```css
.bloco-perspectiva {
    width: min(350px, 85vw);
    max-width: 350px;
    max-height: 420px;
    padding: clamp(12px, 3vw, 24px) clamp(16px, 4vw, 32px);
}
```
Em telas < 400px, largura: min(350px, 85vw). A perspectiva 3D é MANTIDA em todas as resoluções.

**Efeito de Extrusão 3D no Título (OBRIGATÓRIO):**
O título "BACKROOMS: O UNIVERSO DO HORROR LIMINAR" deve ter efeito de texto 3D extrudado. O texto em si fica PERFEITAMENTE RETO e HORIZONTAL. A profundidade é criada apenas por dezenas de text-shadow.

Implementação:
```javascript
let shadow = "";
for (let i = 0; i < 35; i++) {
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 #1a1508";
}
titulo.style.textShadow = shadow;
```
A cor da extrusão deve ser #1a1508 (amarelo muito escuro, quase marrom). Isso cria profundidade sem competir com o branco do texto principal.

Além disso, usar `::before` no título com o mesmo texto, posicionado levemente deslocado (2px para baixo, 2px para a direita), com cor #0a0a0f e filter: blur(3px), opacity 0.4. Isso simula uma sombra ambiente sobre a superfície.

O z-index do título deve ser ZERO para não sobrepor outros textos.

**Ordem de entrada dos elementos:**
1. Background estabiliza (já visível)
2. Linha decorativa horizontal aparece (fade in, 800ms)
3. Labels técnicos decorativos surgem (fade in, 600ms)
4. Bloco com perspectiva 3D entra (fade + translateZ, 1000ms, delay 400ms)
5. Título aparece com efeito de extrusão (fade + move 25px para baixo + blur, 900ms, delay 200ms)
6. Subtítulo aparece (fade + move 15px para cima, 700ms, delay 600ms)
7. Glitch intermitente começa a ocorrer periodicamente

**Interações:**
- Botão próximo (canto inferior direito): avança para slide 2
- Navigation dots: clicáveis, indicam slide 1 como ativo
- Botão anterior desabilitado (é o primeiro slide)
- Botão índice (canto superior esquerdo): abre painel lateral
- Título com efeito glitch que responde ao tempo (automático, não ao hover)

**Transição para o próximo slide:**
Fade out de todos os elementos com move 15px na direção do avanço. Duração: 500ms. Easing: ease-in. Delay de 150ms antes de iniciar a entrada do slide 2.

**Observações:**
- Este slide é o mais importante da apresentação. Ele define se o usuário continuará assistindo.
- O efeito de extrusão 3D no título é OBRIGATÓRIO e deve ser impressionante.
- O z-index do título deve ser 0.
