# 8. ANIMAÇÕES GLOBAIS

## Princípios
- Toda animação deve ser fluida, cinematográfica e suave
- Nada deve aparecer instantaneamente
- O primeiro slide deve animar automaticamente no carregamento da página
- Ao trocar de slide, todos os elementos do novo slide devem iniciar invisíveis e aparecer via animação
- Ao voltar para um slide, as animações devem se repetir completamente

## Easing Padrão
- Entrada de elementos: cubic-bezier(0.16, 1, 0.3, 1) — desaceleração suave
- Saída de elementos: cubic-bezier(0.4, 0, 1, 1) — aceleração suave
- Transições de slide: cubic-bezier(0.4, 0, 0.2, 1)

## Sequência Padrão de Entrada (Stagger)
Para a maioria dos slides, a sequência é:
1. Background do slide (0ms)
2. Elementos decorativos/blobs (100ms)
3. Bloco com perspectiva 3D ou elemento de destaque (200-300ms)
4. Título principal (300-400ms)
5. Subtítulo (450-550ms)
6. Conteúdo/cards/lista (600ms+)
7. Elementos interativos (800ms+)
8. Efeitos finais/glow (1000ms+)

## Animação de Títulos
- Fade In + MoveY(20px→0) + Blur(8px→0)
- Duração: 800ms
- Delay: variável por slide (300-500ms)
- Easing: cubic-bezier(0.16, 1, 0.3, 1)

## Animação de Subtítulos
- Fade In + MoveY(15px→0)
- Duração: 700ms
- Delay: título + 150ms
- Easing: cubic-bezier(0.16, 1, 0.3, 1)

## Animação de Cards/Itens de Lista
- Fade In + MoveY(30px→0) + Scale(0.95→1) + Blur(4px→0)
- Duração: 700ms
- Stagger: 120ms entre cada item
- Delay inicial: variável por slide
- Easing: cubic-bezier(0.16, 1, 0.3, 1)

## Animação de Blocos com Perspectiva 3D
- Fade In + MoveY(40px→0) acompanhando a direção da perspectiva
- Duração: 900ms
- Delay: variável
- Easing: cubic-bezier(0.16, 1, 0.3, 1)
- Conteúdo interno aparece 200ms após o bloco

## Animação de Ícones
- Fade In + Scale(0.8→1) + Rotate(-10deg→0)
- Duração: 600ms
- Stagger: 80ms entre ícones
- Easing: cubic-bezier(0.34, 1.56, 0.64, 1) — spring suave

## Animação de Contadores/Números
- Contador numérico de 0 ao valor final
- Duração: 1500ms
- Easing: ease-out
- Suffix automático (%, +, etc.)

## Microanimações Contínuas (após estabilização)
- Blobs de fundo: leve float (±15px em X/Y, 15-25s)
- Partículas: movimento lento ascendente/horizontal
- Glow sutil pulsando: opacidade variando 0.04↔0.08, ciclo 4-6s
- Elementos decorativos: leve oscilação vertical (±3px, 6-8s)
- Cards: leve respiração de sombra (shadow blur variando 1-2px, 5-7s)

# REGRAS GLOBAIS IMPORTANTES

## Responsividade
- Tudo deve ser 100% responsivo
- Nenhum elemento pode sair da tela em nenhuma resolução
- Nenhum slide pode ser scrollável
- Utilizar clamp() para tamanhos de fonte
- Utilizar min()/max() para larguras
- Em telas menores que 768px: reorganizar grids para 1 coluna, reduzir gaps
- Em telas menores que 480px: simplificar ainda mais, manter hierarquia

- Se houver APENAS UM bloco com perspectiva em um slide, ele NÃO pode ficar centralizado na tela
- Deve ficar posicionado à esquerda ou à direita, com conteúdo complementar ao lado oposto
- Centralização só é permitida quando houver 3 ou mais blocos com perspectiva no mesmo slide

## UTF-8
- Meta charset UTF-8 obrigatório
- Todos os textos devem ter acentos corretos
- Nenhum caractere corrompido é aceitável

- NÃO usar scroll do mouse para trocar slides
- NÃO usar clique em canto para trocar slide

- NÃO criar linhas do tempo (timeline) como solicitado nos slides — usar abordagem diferente

### TÍTULO 3D EXTRUDADO — IMPLEMENTAÇÃO OBRIGATÓRIA

O título "Microsoft Teams" no slide de capa deve ter efeito de texto 3D extrudado com múltiplos text-shadow.

O texto deve permanecer COMPLETAMENTE RETO (horizontal). NÃO aplique nenhuma rotação, inclinação ou perspectiva ao elemento do texto. O título fica paralelo ao topo da tela.

A sensação de tridimensionalidade vem EXCLUSIVAMENTE da extrusão por text-shadow:

Implementação via JavaScript no carregamento:
```
let shadow = "";
for (let i = 0; i < 35; i++) {
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 #cfcfcf";
}
titulo.style.textShadow = shadow;
```

CORES DO SHADOW: O shadow NÃO pode ser branco, cinza ou preto. Deve ser um gradiente de cor vívida:
- Camadas próximas ao texto (i=0 a i=10): #8B8FC7 (roxo claro)
- Camadas médias (i=11 a i=22): #6264A7 (roxo Teams)
- Camadas distantes (i=23 a i=35): #464775 (roxo escuro)

A segunda camada usa ::before no título:
- Posicionamento: absolute, sobre o título
- Mesmo conteúdo do título
- Deslocamento: translate(-2px, 2px)
- Cor: escurecida (rgba(0,0,0,0.15))
- filter: blur(3px)
- Opacidade: 0.4
- Função: simular sombra ambiente, aumentar percepção de profundidade

Tamanho do título: clamp(3.2rem, 6.4vw, 5.76rem)
