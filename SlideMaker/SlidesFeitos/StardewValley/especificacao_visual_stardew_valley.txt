1. IDENTIDADE VISUAL — VISÃO GERAL
================================================================================

Estilo: Rural-natureza moderno com DNA Stardew Valley. Dark mode como base.
A identidade visual mescla a estética acolhedora da vida no campo com um design
moderno, limpo e sofisticado. A apresentação deve transmitir aconchego, nostalgia,
natureza, comunidade e a sensação de um pôr do sol na fazenda.

Sensação geral: "Uma apresentação que parece um passeio pelo campo ao entardecer.
Acolhedora, visualmente rica, com cores quentes e elementos naturais. Cada slide
respira a atmosfera única de Stardew Valley."

Público-alvo: Estudantes, gamers, entusiastas de jogos independentes, professores
e público geral interessado em jogos e desenvolvimento de games.

Objetivo: Apresentar Stardew Valley em toda sua profundidade, desde suas mecânicas
de fazenda até seu impacto na indústria de jogos, de forma visualmente memorável e
envolvente.

5. CONCEITO ARTÍSTICO
================================================================================

A apresentação deve evocar a sensação de estar sentado na varanda de uma
fazenda ao entardecer, observando o pôr do sol enquanto vagalumes começam a
aparecer. O ar é fresco, a brisa é suave, e tudo está em paz.

tarde no campo". Os gradientes simulam a transição do céu do dia para a noite.

As partículas de fireflies (vagalumes) flutuam suavemente, dando vida ao fundo
sem distrair.

Elementos pixelados sutis nas bordas e transições homenageiam a estética do
jogo, mas o design geral é moderno e refinado.

Cada slide que aborda uma estação diferente (primavera, verão, outono, inverno)
pode ter uma variação sutil na cor dominante.

8. ANIMAÇÕES GLOBAIS
================================================================================

TRANSIÇÕES ENTRE SLIDES:

Principal: Cross Fade (dissolve cruzado)
- Duração: 600ms
- Easing: ease-in-out
- O slide atual desaparece enquanto o próximo aparece
- Funciona para a maioria das transições

Transições específicas por slide (variam para dar ritmo):
- Slide 1 → 2: Cross Fade (600ms)
- Slide 2 → 3: Fade (500ms)
- Slide 3 → 4: Slide Up (700ms) - o slide novo vem de baixo
- Slide 4 → 5: Cross Fade (600ms)
- Slide 5 → 6: Fade (500ms)
- Slide 6 → 7: Cross Fade com escurecimento (800ms) - mais dramático
- Slide 7 → 8: Slide Right (700ms) - o slide novo vem da direita
- Slide 8 → 9: Cross Fade (600ms)
- Slide 9 → 10: Fade (500ms)
- Slide 10 → 11: Zoom In suave (700ms)
- Slide 11 → 12: Cross Fade (600ms)
- Slide 12 → 13: Slide Up (700ms)
- Slide 13 → 14: Rotate (800ms, 3D perspective, sutil)
- Slide 14 → 15: Cross Fade (600ms)

Implementação: use classes CSS para controlar a transição. Quando um slide
entra, recebe classe "active" e o anterior "exit". Use requestAnimationFrame
ou transitionend events para coordenar.

ANIMAÇÕES DE ENTRADA DE ELEMENTOS (dentro de cada slide):

Timing padrão (ativado quando o slide se torna ativo):
- t=0ms: fundo e elementos decorativos já estão visíveis
- t=200ms: título do slide (Fade In + Slide Up)
- t=400ms: subtítulo (Fade In + Slide Up, ligeiramente mais lento)
- t=600ms: elementos principais começam a aparecer (stagger)
- Stagger entre itens: 100ms entre cada card/item

Easing padrão para entradas: cubic-bezier(0.25, 0.46, 0.45, 0.94)
  (suave, natural)

ATRASOS (delays) específicos:
- Se um slide tem 4 cards, eles entram nos tempos:
  Card 1: 600ms, Card 2: 720ms, Card 3: 840ms, Card 4: 960ms
- Se tem 6 itens em grid:
  Item 1: 600ms, Item 2: 680ms, Item 3: 760ms, Item 4: 840ms,
  Item 5: 920ms, Item 6: 1000ms

MICROINTERAÇÕES GLOBAIS:
- Hover em botões: mudança de cor e escala 1.05 em 0.2s
- Hover em cards: leve elevação (translateY -4px), glow na borda
- Clique em botões: escala 0.95 momentânea (feedback tátil)
- Transições de hover: todas com 0.3s ease

CURSOR:
- Cursor padrão: arrow normal
- Em botões/links: pointer
- Em cards clicáveis: pointer
- Opcional: cursor personalizado com um pequeno ponto que segue o mouse
  (apenas se não prejudicar a performance)

ESPECIFICAÇÃO DO EFEITO 3D DO TÍTULO "Stardew Valley":

REGRAS ABSOLUTAS — O TÍTULO NÃO PODE SER RETO/HORIZONTAL:

O texto deve ser inclinado usando transform: rotate(-28deg) skew(25deg);

Isso faz com que:
- O lado ESQUERDO do texto fique mais BAIXO
- O lado DIREITO do texto fique mais ALTO
- O texto suba na diagonal da esquerda para a direita (↗)

PROPRIEDADES CSS:
  font-family: 'Playfair Display', serif;
  font-weight: 800;
  font-size: clamp(2.5rem, 7vw, 6rem);
  color: #F5EDE0;
  transform: rotate(-28deg) skew(25deg);
  transform-origin: center center;
  text-transform: none;
  letter-spacing: 2px;
  line-height: 1.1;

EXTRUSÃO (text-shadow):
Gerar 30 camadas de text-shadow com deslocamento progressivo.
Cada camada i (de 0 a 29) deve ter:
  offsetX = -i px      (desloca para a esquerda)
  offsetY = i px       (desloca para baixo)
  blur = 0
  cor = gradiente escurecendo progressivamente

Algoritmo JS para gerar o text-shadow:
  let shadow = "";
  for(let i = 0; i < 30; i++){
    const intensity = Math.max(0, 1 - (i / 30));
    const r = Math.round(200 * intensity + 50);
    const g = Math.round(190 * intensity + 40);
    const b = Math.round(170 * intensity + 30);
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 rgb(" + r + "," + g + "," + b + ")";
  }

SOMBRA AMBIENTE (::before):
Criar um pseudo-elemento ::before com o mesmo texto, posicionado atrás,

  content: attr(data-text);
  position: absolute;
  left: 20px;    /* deslocado para baixo e direita */
  top: 20px;
  color: rgba(0, 0, 0, 0.3);
  filter: blur(8px);
  transform: rotate(-28deg) skew(25deg);
  z-index: -1;

O elemento que contém o texto deve usar:
  position: relative;
  data-text = "Stardew Valley"

E envie o texto "Stardew Valley" duplicado no atributo data-text.

================================================================================
REGRAS GLOBAIS DE RESPONSIVIDADE
================================================================================

1. Use clamp() para todos os font-size, padding e margin.
   Exemplo: font-size: clamp(0.8rem, 1.5vw, 1.1rem);

2. Use CSS Grid e Flexbox para layouts flexíveis.

3. Todos os slides devem usar height: 100vh e width: 100vw com
   overflow: hidden.

4. Em viewports menores que 768px (mobile):
   - Grids de 3-4 colunas viram 2 colunas
   - Grids de 2 colunas viram 1 coluna (empilhamento vertical)
   - Fontes reduzem proporcionalmente
   - Cards e elementos se reorganizam para caber na tela

5. Em viewports entre 768px e 1024px (tablet):
   - Grids de 4 colunas viram 3 colunas
   - Espaçamentos reduzem moderadamente

6. Teste mentalmente cada slide em 320px, 768px e 1920px de largura
   para garantir que nada é cortado ou precisa de scroll.

7. A barra de navegação (setas, progresso, contador) deve se ajustar
   proporcionalmente em todas as telas.

================================================================================
REGRAS DE PERFORMANCE
================================================================================

1. Animações CSS devem usar transform e opacity (não use top, left, width,
   height para animar — causa repaint).

2. Use will-change: transform, opacity em elementos animados quando
   apropriado (mas sem exageros).

3. As partículas (fireflies) devem ser implementadas com elementos DOM
   animados via CSS animation ou com Canvas 2D para maior performance
   em quantidades maiores.

4. Use requestAnimationFrame para animações JavaScript.

5. Evite libraries pesadas. Tudo deve ser Vanilla JS + CSS puro.

6. O backdrop-filter: blur() deve ser usado com moderação em mobile
   (pode causar lentidão). Considere fallback com background semi-sólido.

================================================================================
ESPECIFICAÇÕES TÉCNICAS FINAIS
================================================================================

1. Estrutura HTML:
   - Um container principal (#presentation) com 100vw x 100vh
   - Cada slide como uma seção (<section class="slide">) com 100vw x 100vh
   - Navegação fixa (overlay) com botões, barra de progresso, contador
   - CSS embutido no <head> dentro de <style>
   - JS embutido no final do <body> dentro de <script>

2. Estados dos slides:
   - .slide: display none, opacity 0
   - .slide.active: display flex, opacity 1 (com transição)
   - .slide.exit: animação de saída

3. Controle via JavaScript:
   - currentSlide (índice atual)
   - goToSlide(index): função principal de navegação
   - nextSlide() / prevSlide()
   - Event listeners: teclado, mouse click, touch/swipe, scroll
   - Atualização da barra de progresso e contador

4. Animações de entrada:
   - Use classes como .animate-in, .animate-out com delays via
     transition-delay em CSS ou setTimeout em JS
   - Para sequências (stagger), use data-delay attributes ou
     índices pares/ímpares em CSS

5. Transições entre slides:
   - Use classes CSS diferentes para cada tipo de transição
   - A transição ativa controla como o slide atual sai e o novo entra
   - Exemplo: .transition-fade, .transition-slide-up, .transition-cube
