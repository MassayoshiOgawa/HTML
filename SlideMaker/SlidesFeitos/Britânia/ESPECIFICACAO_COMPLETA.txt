1. IDENTIDADE VISUAL GERAL
================================================================================

Tema: Britânia de Pirabeiraba — história, natureza e cultura de uma localidade
rural com forte herança de imigração europeia.

Atmosfera geral: Elegância naturalista com toque histórico. A apresentação deve
transmitir aconchego, autenticidade, profundidade histórica e valorização das
raízes. A estética mescla o rústico e o refinado — como uma descoberta
cuidadosa de um patrimônio escondido.

Sensação: O observador deve sentir que está conhecendo um lugar especial,
envolvido por uma luz dourada de fim de tarde, com a tranquilidade do campo e
o peso da história. Deve haver aconchego, nostalgia suave e orgulho local.

Estilo visual: Naturalista premium. Fundo escuro aveludado com iluminação
dourada e quente, texturas sutis de papel e grão, elementos orgânicos e
geométricos equilibrados. A apresentação alterna entre o minimalismo e a
riqueza de detalhes.

Direção de luz: Luz vindo do canto superior esquerdo, como um sol de final de
tarde. Todas as sombras, glows e reflexos devem respeitar essa direção.

5. CONCEITO ARTÍSTICO
================================================================================

"Luz Dourada sobre a História"

A apresentação é conduzida como um documentário visual. O espectador é
convidado a percorrer Britânia de Pirabeiraba como se estivesse caminhando
por suas terras no final da tarde, quando a luz dourada do sol realça as
cores da vegetação, das construções históricas e dos rostos da comunidade.

O fundo escuro e aveludado representa a terra fértil. A luz dourada que
emerge do canto superior esquerdo é o sol poente que ilumina cada aspecto
da localidade. As partículas são como pólen e poeira dourada suspensos no ar.

Cada slide é uma "janela" para um aspecto diferente desse lugar. A transição
entre slides é como virar as páginas de um livro de memórias ricamente
ilustrado.

8. ANIMAÇÕES GLOBAIS
================================================================================

8.1 Transições entre Slides:
Cada transição deve ser diferente. Seguir a tabela abaixo:

Slide 1 → 2: Fade + Scale
  - Slide 1 fade out com escala 1→0.95, duração 500ms, ease-out
  - Slide 2 fade in com escala 0.95→1, duração 600ms, ease-out
  - Pequeno intervalo de 100ms entre saída e entrada

Slide 2 → 3: Push da direita
  - Slide 2 desliza para esquerda (translateX -100%)
  - Slide 3 desliza da direita (translateX de 100% para 0%)
  - Duração: 550ms, ease-in-out

Slide 3 → 4: Cross Fade
  - Slide 3 fade out, Slide 4 fade in simultaneamente
  - Duração: 700ms, ease

Slide 4 → 5: Slide up (slide 4 sobe, slide 5 vem de baixo)
  - Duração: 550ms, ease-in-out

Slide 5 → 6: Fade + Blur
  - Slide 5 blur de 0→4px + fade out
  - Slide 6 blur de 4px→0 + fade in
  - Duração: 650ms, ease

Slide 6 → 7: Push da esquerda (direção inversa para variar)
  - Duração: 550ms, ease-in-out

Slide 7 → 8: Fade + Scale (scale 1→1.05 saindo, 0.95→1 entrando)
  - Duração: 600ms, ease-out

Slide 8 → 9: Cross Fade lento
  - Duração: 800ms, ease

Para VOLTAR (próximo → anterior), a transição deve ser exatamente a inversa:
  - Push da direita ao avançar → Push da esquerda ao voltar
  - Slide up → Slide down
  - Fade + Blur funciona igual nos dois sentidos
  - Cross fade funciona igual nos dois sentidos
  - Fade + Scale funciona igual nos dois sentidos

IMPLEMENTAÇÃO DAS TRANSIÇÕES:
- Usar JavaScript para controlar classes nos slides
- Cada slide é um elemento .slide com position: absolute, top: 0, left: 0,
  width: 100%, height: 100%
- O slide ativo tem classe .active
- O slide saindo recebe classe .exiting com a animação de saída
- O slide entrando recebe classe .active + .entering com animação de entrada
- Após a animação terminar, remover .exiting e .entering

8.2 Estado Inicial Obrigatório:
- NENHUM elemento pode aparecer antes da animação
- Todos os elementos iniciam com opacidade 0
- Posições, escalas, blurs iniciais definidos individualmente
- NENHUM flash de conteúdo permitido
- O slide 1 deve ser exibido automaticamente ao carregar a página

8.3 Sequência de Animação por Slide:
Cada elemento dentro de um slide segue uma ordem coreográfica:

1. Background (já está lá, não anima)
2. Elementos decorativos de fundo (blobs, gradientes)
3. Grid/linhas de fundo
4. Blocos com perspectiva 3D
5. Cards e painéis
6. Título principal
7. Subtítulo
8. Conteúdo (textos, listas)
9. Ícones e badges
10. Botões e elementos de ação
11. Efeitos finais (glows, destaques)

Delay base entre elementos: 120ms a 200ms
Duração padrão de cada animação: 600ms a 900ms
Easing padrão: cubic-bezier(0.25, 0.46, 0.45, 0.94) — ease-out suave
Easing para entradas dramáticas: cubic-bezier(0.34, 1.56, 0.64, 1) — spring

8.4 Animação de Elementos Individuais (Catálogo):

TÍTULO (entrada):
- Opacidade: 0 → 1
- TranslateY: 20px → 0px
- Escala: 0.97 → 1
- Filter: blur(4px) → blur(0px)
- Duração: 800ms
- Delay: conforme ordem
- Easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)

SUBTÍTULO (entrada):
- Opacidade: 0 → 1
- TranslateY: 15px → 0px
- Filter: blur(3px) → blur(0px)
- Duração: 700ms
- Delay: 200ms após o título
- Easing: ease-out

CARDS/PAINÉIS (entrada):
- Opacidade: 0 → 1
- TranslateY: 30px → 0px
- Escala: 0.95 → 1
- Box-shadow: 0 0 0 rgba(0,0,0,0) → sombra final
- Duração: 700ms
- Stagger entre cards: 150ms
- Easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)

TEXTOS (entrada, parágrafo ou lista):
- Opacidade: 0 → 1
- TranslateY: 12px → 0px
- Duração: 600ms
- Stagger entre itens: 100ms
- Easing: ease-out

BLOCOS 3D PERSPECTIVA (entrada):
- Opacidade: 0 → 1
- TranslateY: 40px → 0px
- RotateY começa em 35deg e vai para 25deg (animar o rotateY)
- Escala: 0.9 → 1
- Filter: blur(6px) → blur(0px)
- Duração: 900ms
- Easing: cubic-bezier(0.34, 1.56, 0.64, 1) (spring leve)
- A transformação final deve manter o rotateY: 25deg original

BOTÕES (entrada):
- Opacidade: 0 → 1
- Escala: 0.9 → 1
- Duração: 400ms
- Delay: calculado para aparecer após o conteúdo
- Easing: ease-out

ÍCONES (entrada):
- Opacidade: 0 → 1
- Rotate: -10deg → 0deg (em elementos decorativos)
- Escala: 0.8 → 1
- Duração: 500ms
- Stagger: 80ms

8.5 Estado de Saída dos Slides:
- Opacidade: 1 → 0 (para fade)
- TranslateY/Y: posição original → deslocamento conforme transição
- Escala: conforme transição
- Duração: 400ms a 550ms
- Todos os elementos saem JUNTOS (não em sequência)
- Ao finalizar, todos os elementos do slide devem resetar para estado inicial

8.6 Reset de Animação ao Retornar:
- Quando o usuário volta para um slide já visitado, TODAS as animações
  devem ser executadas novamente do início
- Todos os elementos devem retornar ao estado inicial (opacidade 0, etc.)
- Após o slide se tornar ativo novamente, a sequência de entrada deve
  disparar imediatamente

EXTRUSÃO COM TEXT-SHADOW (35 camadas):
Implementar com JavaScript:

const startColor = { r: 201, g: 151, b: 78 };   // dourado
const endColor   = { r: 25,  g: 50,  b: 25 };    // verde escuro
let shadow = '';
for (let i = 0; i < 35; i++) {
    const t = i / 34;
    const r = Math.round(startColor.r + (endColor.r - startColor.r) * t);
    const g = Math.round(startColor.g + (endColor.g - startColor.g) * t);
    const b = Math.round(startColor.b + (endColor.b - startColor.b) * t);
    const a = 0.9 - t * 0.6; // de 0.9 até 0.3
    shadow += (shadow ? ',' : '') + `${(-i)}px ${i}px 0 rgba(${r},${g},${b},${a})`;
}
titulo.style.textShadow = shadow;

A sombra deve ir para cima e para a esquerda (x negativo, y positivo),
criando a ilusão de que a luz vem do canto superior esquerdo e o texto
projeta espessura para baixo e para a direita.

- z-index: -1
- pointer-events: none
- O texto deve estar escondido (visível apenas a sombra)

Para implementar o ::before com o mesmo texto, usar data attribute:
<h1 data-text="Britânia de Pirabeiraba">Britânia de Pirabeiraba</h1>

12. INSTRUÇÕES ADICIONAIS PARA A IA DESENVOLVEDORA
================================================================================

12.1 Estrutura do Documento HTML:
- Único arquivo HTML contendo HTML, CSS e JavaScript
- Codificação UTF-8 com <meta charset="UTF-8">
- SEM tela de loading
- O primeiro slide já deve estar ativo ao carregar a página
- Todos os slides são divs com classe .slide, posicionados com
  position: absolute, top: 0, left: 0, width: 100%, height: 100%
- O slide ativo tem classe .active (display: block ou visibility: visible)
- Os slides inativos têm display: none (ou visibility: hidden)

12.2 Estrutura de Pastas:
- NÃO existe estrutura de pastas. Único arquivo HTML.

12.3 Responsividade (OBRIGATÓRIO):
- Usar clamp() para fontes, unidades relativas (vw, vh, %, rem, em)
- container queries ou media queries para breakpoints
- Breakpoints: 1920px, 1600px, 1440px, 1366px, 1280px, 1024px, 768px, 480px
- Em telas menores, reorganizar layout (grid para uma coluna, reduzir gaps)
- NENHUM scroll em nenhum slide
- Viewport: width=device-width, initial-scale=1.0

12.4 Performance (OBRIGATÓRIO):
- Animações CSS优先 (preferir CSS animations/transitions a JS)
- Canvas para partículas (não DOM)
- will-change em elementos animados
- backface-visibility: hidden em elementos 3D
- Use transform e opacity para animações (são propriedades que o GPU acelera)

12.5 Acessibilidade:
- Navegação por teclado funcional
- Contraste adequado (texto claro sobre fundo escuro)
- role="presentation" ou role="document" na apresentação
- aria-label nos botões de navegação

12.6 Código Organizado:
- CSS no <style> no <head>
- JavaScript no final do <body>
- Comentários no código explicando seções
- Nomes de classes consistentes (prefixo slide- para cada slide)
