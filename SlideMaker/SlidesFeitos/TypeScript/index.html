O que é TypeScript?
Linguagem desenvolvida pela Microsoft (2012)
  • ✓ Superset do JavaScript
  • ✓ Adiciona tipagem estática
  • ✓ Novos recursos
  • ✓ Compilado para JavaScript
  • ✓ Executado em qualquer ambiente JS
ℹ️ Navegadores não executam TypeScript diretamente.
TS Code → tsc Compiler → JS Code → ✓ Browser/Node
História do TypeScript
2012
Primeira versão
Primeira versão lançada em outubro de 2012, após 2 anos de desenvolvimento interno na Microsoft.
Microsoft
Criado por Anders Hejlsberg
Criado por Anders Hejlsberg, arquiteto principal do C# e criador do Turbo Pascal.
Anders Hejlsberg
Criador do C# liderou o desenvolvimento
Anders Hejlsberg, também criador do C#, liderou o design da linguagem.
Angular
Crescimento impulsionado pelo Angular
O Angular 2+ adotou TypeScript como linguagem padrão, impulsionando sua adoção em massa.
Atualmente
Milhares de empresas utilizam
TypeScript é usado por milhares de empresas, incluindo Google, Netflix, Airbnb e muitas outras.

TypeScript na prática
example.ts
interface Pessoa { nome: string; idade: number; } function apresentar(pessoa: Pessoa): string { return `Olá, meu nome é ${pessoa.nome} e tenho ${pessoa.idade} anos.`; } console.log(apresentar({ nome: "Ana", idade: 22 }));
