6. BACKGROUND GLOBAL
================================================================================

O background global da apresentação deve ter 3 camadas:

CAMADA 1 (Profundidade):
- Gradiente radial animado central sutil 
- Centro: rgba(247, 223, 30, 0.02) nos slides de conteúdo
- Centro: rgba(247, 223, 30, 0.05) nos slides de destaque
- Bordas para #0A0A0F puro
- Pequenas variações de tom entre slides para evitar monotonia

CAMADA 2 (Partículas):
- Canvas em tela cheia atrás de todos os slides
- Partículas tipo "estrelas/pixels" em número moderado (60-80)
- Cor: branco #F0F0F5 com opacidade 0.15-0.3
- Movimento: flutuação lentíssima vertical (subindo 0.2px/frame)
- Tamanho: 1px a 2.5px
- Ocasionalmente uma partícula em amarelo JS (#F7DF1E) aparece aleatoriamente
- As partículas NÃO interferem com o conteúdo

CAMADA 3 (Grid tecnológico):
- Grid de linhas finas horizontais e verticais ultra sutil
- Opacidade: 0.03
- Cor: #F7DF1E
- Movimento parallax muito lento conforme mouse
- Este grid dá a sensação de "ambiente de código/alinhamento"

RESPONSIVIDADE DO BACKGROUND:
- Em mobile (< 768px), desligar o grid (camada 3) para performance
- Partículas reduzidas para 30
- Gradiente mantido

7. NAVEGAÇÃO GLOBAL
================================================================================

SISTEMA DE NAVEGAÇÃO:

A apresentação usa um sistema de slides único por vez (como PowerPoint), 
NÃO scroll infinito.

a) CONTROLES VISUAIS:
   - Botão "←" (Anterior) no canto inferior esquerdo
   - Botão "→" (Próximo) no canto inferior direito
   - Barra de progresso horizontal fina no topo (altura: 3px)
   - Indicador numérico (ex: "03 / 15") no canto inferior central
   - Botão de tela cheia no canto superior direito (ícone de expandir)
   - Botão toggle tema (claro/escuro) no canto superior direito (ao lado fullscreen)

b) TECLADO:
   - Seta Direita / Seta Abaixo / Espaço: próximo slide
   - Seta Esquerda / Seta Acima: slide anterior
   - Home: primeiro slide
   - End: último slide
   - F: entrar/sair de tela cheia
   - Esc: sair de tela cheia
   - Números 1-9: ir para slide correspondente (1 a 9)
   - 0: ir para slide 10 (se existir)

c) MOUSE:
   - Clique na metade direita da tela: próximo slide
   - Clique na metade esquerda: slide anterior
   - Scroll (roda): próximo/anterior (se scroll > 50px)
   - Hover nos botões de navegação: glow amarelo sutil
   - Cursor personalizado: círculo minimalista de 20px, borda fina branca
     com opacidade 0.4, ponto central amarelo 4px

d) TOQUE:
   - Swipe para esquerda: próximo slide
   - Swipe para direita: slide anterior
   - Tap: avançar slide (delay de 300ms para evitar avanço duplo)
   - Touch drag na barra de progresso: navega por posição

e) BARRA DE PROGRESSO:
   - Altura: 3px
   - Largura total do topo
   - Fundo: rgba(255, 255, 255, 0.05)
   - Preenchimento: gradiente horizontal #F7DF1E → #4FC3F7
   - Transição suave (easeInOut, 400ms)
   - Clicável/arrastável (touch e mouse)
   - Presente em TODOS os slides exceto na capa (slide 1)

f) INDICADOR DE SLIDE:
   - Texto no formato "03 / 15"
   - Fonte: Space Mono, 0.75rem, opacidade 0.4
   - Posição: canto inferior central, 20px acima da borda

================================================================================
8. ANIMAÇÕES GLOBAIS
================================================================================

DURAÇÕES E EASINGS PADRÃO:
- Entrada de elementos: 600ms a 800ms
- Saída de elementos: 400ms a 500ms
- Transições entre slides: 700ms a 900ms
- Hover: 200ms easeOut
- Easing global: cubic-bezier(0.25, 0.1, 0.25, 1.0) — suave natural
- Easing para destaques: cubic-bezier(0.34, 1.56, 0.64, 1) — spring suave

STAGGER (ATRASO EM CADEIA):
- Quando múltiplos elementos entram em sequência:
  - Delay entre elementos: 100ms a 150ms
  - Cada elemento: 500ms de duração
  - Direção: sempre de cima para baixo, esquerda para direita
- Exceção: elementos centrais entram primeiro se forem o foco do slide

REGRAS DE ANIMAÇÃO:
- Texto sempre entra com Fade In + Slide Up (20px)
- Cards sempre entram com Fade In + Scale (1.05 → 1.0)
- Ícones entram com Scale + Rotate (apenas ícones decorativos)
- Imagens entram com Fade In + Zoom (1.1 → 1.0) — efeito Ken Burns suave
- Código entra com Blur In + Fade (desfoque 4px → 0)
- Listas entram item por item com stagger de 120ms
- Nenhum elemento deve pular ou trepidar na entrada

REGRAS DE SAÍDA (antes da transição):
- Fade Out + Slide Down (15px)
- Duração: 400ms
- Itens saem na ordem inversa da entrada (último a entrar, primeiro a sair)

================================================================================
9. ELEMENTOS INTERATIVOS GLOBAIS
================================================================================

CURSOR PERSONALIZADO:
- Substituir cursor padrão por um círculo outline branco 20px, opacidade 0.5
- Ponto central: círculo amarelo #F7DF1E de 4px
- Em hover de links/botões: círculo expande para 35px, glow amarelo
- Em texto: cursor some, mostra cursor padrão de texto
- Em touch devices: cursor personalizado desligado

MAGNETIC BUTTONS:
- Botões de navegação (← →) têm efeito magnético
- Quando mouse está a 60px do botão, ele se move 5px na direção do cursor
- Suave, sem travamentos

GLOW EM HOVER:
- Todo card interativo tem glow amarelo sutil ao passar mouse
- Box-shadow: 0 0 20px rgba(247, 223, 30, 0.1), 0 0 40px rgba(247, 223, 30, 0.05)

FEEDBACK DE CLIQUE:
- Botões têm ripple effect (círculo expansivo) na cor amarela
- Cards têm escala momentânea (1.02) no clique

TILT NOS CARDS:
- Cards principais têm efeito de inclinação 3D seguindo o mouse
- Rotação máxima: 3 graus no eixo X e Y
- Suave, com transição de 200ms ao remover o mouse

EMOÇÃO: Inspiração, encerramento poderoso, "vou aprender JavaScript".

LAYOUT: Hero centralizado, sem elementos laterais. Elegante e limpo.

ORGANIZAÇÃO DOS ELEMENTOS:
1. [Topo] Barra de progresso final
2. [Centro] Síntese em bullets
3. [Destaque central] Mensagem final em destaque
4. [Inferior] "Perguntas?" + botão recomeçar

SÍNTESE (5 bullets, lado esquerdo):
JavaScript é uma linguagem:
• Versátil
• Moderna
• Muito utilizada
• Fácil para iniciantes
• Essencial para desenvolvimento web

MENSAGEM FINAL EM DESTAQUE (centro, grande):
"Se existe interação em um site,
há grandes chances de que
JavaScript esteja por trás dela."

- Fonte: Space Grotesk 700, clamp(1.2rem, 2.5vw, 2rem)
- Cor: #F7DF1E (gradient text sutil)
- Italic (apenas para dar ênfase diferente)
- Aspas decorativas grandes antes e depois (opacidade 0.15)

ABAIXO:
"Obrigado(a)!" — Space Grotesk 500, 1.5rem, #F0F0F5
"Perguntas?" — Space Mono 400, 1rem, #8888A0

BOTÃO RECOMEÇAR:
- Texto: "↺ Ver novamente"
- Fundo transparente, borda 1px #F7DF1E, texto #F7DF1E
- Border-radius: 8px
- Hover: fundo rgba(247, 223, 30, 0.1)
- Ao clicar: volta para o slide 1

BACKGROUND:
- Gradiente radial centralizado mais forte: rgba(247, 223, 30, 0.06)
- Partículas globais
- Efeito de "luz no fim do túnel" — leve glow circular atrás da mensagem final

ELEMENTOS DECORATIVOS:
- Linha fina horizontal separando a síntese da mensagem final
- Pequenos traços de código nas laterais (opacidade 0.04)
- { } brackets nos cantos (opacidade 0.06)

ANIMAÇÕES DE ENTRADA:
1. [0ms] Background + gradiente radial cresce de 0→100% (1000ms)
2. [200ms] Título "Conclusão" (não incluso, slide não tem título tradicional)
   Na verdade, os bullets "JavaScript é uma linguagem:" servem como título
3. [300ms] Bullets entram em sequência (120ms delay)
   Cada bullet: Fade In + Slide Right (30px, 500ms)
4. [1300ms] Mensagem final: Fade In + Scale (0.95→1, 800ms)
   Palavras aparecem com leve stagger (80ms entre palavras)
5. [2500ms] "Obrigado(a)!": Fade In (500ms)
6. [2800ms] "Perguntas?": Fade In (400ms)
7. [3100ms] Botão recomeçar: Fade In (500ms)

INTERAÇÕES:
- Botão "Ver novamente": volta para slide 1
- Clicar ou pressionar →: volta para slide 1 (loop completo)
- Botão de tela cheia disponível

TRANSIÇÃO DE ENCERRAMENTO:
- Ao recomeçar: transição suave de volta ao slide 1
- Tipo: Fade + Scale (zoom out da conclusão, zoom in na capa)
- Duração: 800ms

OBSERVAÇÕES:
- Slide final NÃO tem seta "próximo"
- Apenas botão "↺ Ver novamente"
- É o único slide onde "Obrigado(a)!" aparece

RESPONSIVIDADE:

Desktop (≥ 1024px):
- Layout completo conforme especificado
- Cards em grid normal
- Timeline horizontal

Tablet (768px - 1023px):
- Grids reduzem para 2 colunas
- Timeline: reduzir textos, manter pontos
- Bento Grid: reorganiza para 2 colunas
- Split slide 8: empilha código em cima, explicação embaixo

Mobile (< 768px):
- Grids: 1 coluna
- Timeline: transformar em vertical (rolável)
- Bento Grid: 1 coluna
- Partículas: reduzidas para 30
- Grid decorativo desligado
- Fonte reduzida em 15%
- Espaçamentos reduzidos
- Botões de navegação maiores (mínimo 48px para touch)
- Cursor personalizado desligado (volta cursor padrão do sistema)

MODO TEMA CLARO:
- Alternância via botão no canto superior direito
- Ao ativar:
  - Fundo: #F5F5F0 (off-white)
  - Texto principal: #1A1A2E
  - Texto secundário: #555570
  - Cards: rgba(255,255,255,0.8) com borda rgba(0,0,0,0.06)
  - Título: #F7DF1E (mantém amarelo)
  - Background particles: escuras (opacidade 0.1)
  - Glows: mais sutis
  - Transição: 400ms ease para todas cores

PERFORMANCE:
- Animações CSS: preferir transform e opacity (GPU-accelerated)
- Evitar animar width, height, top, left
- Partículas: usar canvas (não DOM)
- 3D tilts: usar requestAnimationFrame e debounce
- Lazy rendering de partículas em dispositivos lentos
- Detecção de prefers-reduced-motion: desligar animações complexas,
  manter apenas Fade In básicos

TRANSIÇÕES COMPLETAS ENTRE SLIDES:

8→9: Slide Up (700ms)
9→10: Fade (600ms)
10→11: Flip X (800ms)
11→12: Slide Left (700ms)
12→13: Cube X (900ms)

ÁUDIO (opcional, não essencial):
- Click suave ao navegar (som de tecla de terminal, 100ms)
- Hover em elementos interativos: som sutil (50ms, feedback)
- Transição de slides: som ambiente eletrônico (300ms, fade)
- Sem música de fundo

ARQUIVO HTML ÚNICO:
- Tudo em um único arquivo: HTML + CSS + JavaScript
- Google Fonts carregadas via @import no CSS
- Ícones: usar SVG inline ou Lucide/Phosphor icons via CDN (leve)
- Sem dependências externas pesadas
- Código organizado em seções com comentários
