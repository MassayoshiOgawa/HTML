# 1. IDENTIDADE VISUAL

A apresentação se chama "JavaScript: A Linguagem da Web". Seu tema é o ecossistema completo da linguagem JavaScript, desde fundamentos até boas práticas e próximos passos.

A identidade visual é **tecnológica, moderna e imersiva**, inspirada em ambientes de desenvolvimento (IDEs, terminais, editores de código). A apresentação deve transmitir a sensação de estar dentro de um ambiente de programação sofisticado, com referências visuais ao universo do código — mas sem parecer um tutorial genérico. Deve parecer uma experiência premium, como um keynote de lançamento de tecnologia de uma grande empresa.

A atmosfera é **escura (dark mode)**, com brilhos neon amarelos que remetem à cor oficial do JavaScript. A paleta é dominada por tons escuros profundos com destaque em amarelo vibrante, criando alto contraste e elegância. A linguagem visual combina minimalismo com riqueza de detalhes — poucos elementos, mas cada um extremamente polido.

A apresentação deve parecer um produto premium de estúdio de design, não uma página HTML comum. Cada pixel deve parecer intencional.

# 7. NAVEGAÇÃO

## Troca de Slides
- **Teclado**: Setas esquerda/direita para navegar. Home para primeiro slide, End para último.
- **Mouse**: Clique nas setas de navegação nos cantos inferiores. NÃO troca slide com clique em qualquer canto da tela.
- **Touch/Swipe**: Arrastar para esquerda (próximo) ou direita (anterior) em dispositivos móveis.
- **Scroll do mouse**: NÃO troca de slides. O scroll é desabilitado para navegação.

## Botões de Navegação
- **Seta esquerda (anterior)**: Canto inferior esquerdo, 30px das bordas
- **Seta direita (próximo)**: Canto inferior direito, 30px das bordas
- Estilo: circulares, 48px diâmetro, background rgba(255,255,255,0.06), borda 1px solid rgba(255,255,255,0.08)
- Hover: background rgba(247,223,30,0.15), borda rgba(247,223,30,0.3), glow suave
- Ícones: setas SVG simples, stroke 2px, cor rgba(255,255,255,0.6)
- Hover do ícone: cor #F7DF1E
- Transição: 300ms ease
- Opacity 0 no primeiro slide (seta anterior) e no último slide (seta próxima)
- Animação de entrada: fade in com 400ms de delay

## Navigation Dots
- Posição: canto inferior central, mesma altura dos botões de seta (alinhados horizontalmente)
- Quantidade: 10 dots (um por slide)
- Dot inativo: 8px diâmetro, background rgba(255,255,255,0.15), borda nenhuma
- Dot ativo: 24px de largura (expandido horizontalmente), height 8px, border-radius 4px
- Gradiente do dot ativo: linear-gradient(90deg, #F7DF1E, #D4A814)
- Transição do dot: 400ms cubic-bezier(0.4, 0, 0.2, 1)
- Hover: leve aumento de opacidade
- Click: navega para o slide correspondente
- Total de dots: 10 (posições 0 a 9)

## Barra de Progresso
- Posição: acima dos navigation dots, canto inferior中央
- Largura: 200px (ou largura total dos dots + 40px)
- Altura: 3px
- Background: rgba(255,255,255,0.08)
- Preenchimento: gradiente linear da esquerda para a direita
- Gradiente: linear-gradient(90deg, #F7DF1E, #FFC107, #F7DF1E)
- Animação do preenchimento: transição suave de 500ms cubic-bezier(0.4, 0, 0.2, 1)
- Largura do preenchimento: (slide atual / total de slides) * 100%
- Glow sutil no ponto mais avançado: box-shadow com rgba(247,223,30,0.4)

# 8. ANIMAÇÕES GLOBAIS

## Transição entre Slides
- Tipo: **Cross Fade com leve Zoom**
- Duração da saída: 500ms
- Duração da entrada: 600ms
- Easing: cubic-bezier(0.4, 0, 0.2, 1)
- Slide atual: opacidade 1→0, scale 1→0.98, leve blur 0→4px
- Novo slide: opacidade 0→1, scale 1.02→1, blur 4px→0
- Não existe intervalo visível entre a saída e entrada — elas se sobrepõem levemente (crossfade)

## Animações de Entrada de Elementos
- **Easing padrão**: cubic-bezier(0.16, 1, 0.3, 1) (ease-out exponencial)
- **Duração base dos títulos**: 800ms
- **Duração base dos subtítulos**: 700ms
- **Duração base dos textos**: 600ms
- **Duração base dos cards**: 900ms
- **Duração base dos ícones**: 600ms
- **Duração base dos elementos de código**: 800ms

## Stagger
- Atraso entre itens semelhantes (cards, listas, ícones): 100ms
- Atraso entre elementos de hierarquia diferente: 200-300ms
- Sequência típica: background → elementos decorativos → títulos → subtítulos → conteúdo → cards → elementos interativos

## Animações Contínuas (após entrada)
- Partículas: flutuação constante
- Blobs de background: drift lento
- Glow de elementos destacados: respiração sutil (opacidade alterna 0.6↔1 em 4 segundos)
- Elementos decorativos: micro-oscilação de 1-2px em Y

## Proibição
- Nenhum elemento pode aparecer instantaneamente antes de sua animação
- Nenhum conteúdo pode "piscar" durante transição de slides
- Todas as animações devem ser reiniciadas ao retornar a um slide

# 10. REGRAS DE BLOCOS COM PERSPECTIVA 3D

Os blocos com perspectiva 3D devem ser usados recorrentemente na apresentação como parte da identidade visual. Eles transmitem profundidade, sofisticação e linguagem tecnológica.

## Configuração Superior (acima de 50% da altura do slide)
```css
.bloco-perspectiva-superior {
    transform: perspective(250px) rotateX(-10deg) rotateY(25deg);
    transform-origin: 50% 50% 0px;
    perspective-origin: 50% 50%;
}
```

## Configuração Inferior (abaixo de 50% da altura do slide)
```css
.bloco-perspectiva-inferior {
    transform: perspective(250px) rotateX(10deg) rotateY(25deg);
    transform-origin: 50% 50% 0px;
    perspective-origin: 50% 50%;
}
```

## Limites
- Largura máxima: 350px (absoluto, nunca ultrapassar)
- Altura máxima: 420px (absoluto, nunca ultrapassar)
- Largura deve ser ajustada ao conteúdo — nunca usar 350px sem justificativa
- Padding mínimo interno: 20px
- Responsivo: width: min(350px, 85vw)

## Regras
- Todo bloco DEVE conter conteúdo real (texto, número, ícone)
- É proibido usar como decoração vazia
- O texto interno herda naturalmente a perspectiva — NÃO aplicar skew ou rotação extra no texto
- Se há apenas 1 bloco no slide, NÃO pode ficar centralizado — deve ter posicionamento lateral
- 3 ou mais blocos no mesmo slide podem ficar centralizados
- Cada bloco deve ter comentário no código justificando seu tamanho
- A perspectiva 3D NUNCA é removida em telas menores
- Sombras devem respeitar a direção da perspectiva (luz do canto superior esquerdo)
- Gradiente sutil no fundo do bloco para reforçar profundidade
- Highlight/borda iluminada na borda superior

# 11. REGRAS DE RESPONSIVIDADE

- Tudo deve caber em qualquer resolução (1920x1080 até celulares 320px)
- Nenhum elemento pode sair da tela
- Nenhum slide pode ser scrollável (horizontal ou vertical)

- Cards e grids devem se reorganizar (2 colunas → 1 coluna em telas pequenas)
- Blocos com perspectiva usam width: min(350px, 85vw)
- Margem de segurança de 5-8% em todas as bordas

# 12. REGRAS DE CODIFICAÇÃO

- Documento HTML com `<meta charset="UTF-8">`
- Todo conteúdo em UTF-8 sem caracteres corrompidos
- Sem caracteres em chinês
- Sem tela de loading
- Título da capa com efeito 3D extrudado (text-shadow em dezenas de camadas)
- A extrusão é feita apenas com text-shadow, sem rotate/skew/perspective no elemento de texto
- O texto principal do título é BRANCO (#FFFFFF)
- O shadow do título NÃO pode ser branco, cinza ou preto — deve ser gradiente de amarelo claro (próximo do texto) para amarelo escuro/dourado (longe do texto)
- O texto principal não pode ter gradiente
- z-index do título no slide 1 deve ser ZERO
- Proibição absoluta de "cover shapes" (polígonos decorativos com clip-path atrás do título)
- O background do slide de capa contém apenas as camadas globais

## Implementação da Extrusão do Título (Capa)
```javascript
let shadow = "";
for (let i = 0; i < 35; i++) {
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 #cfcfcf"; // Este é apenas exemplo — usar cores amarelas
}
// Cores corretas: gradiente de #FFF8DC (amarelo bem claro) até #8B6914 (amarelo escuro/dourado)
// Camada 1 (próxima ao texto): #FFF8DC
// Camada 35 (mais distante): #8B6914
// Interpolar linearmente entre essas duas cores ao longo das 35 camadas
```

## Segunda Camada (Sombra Ambiente via ::before)
- Deslocada levemente
- Escurecida
- Com filter: blur(3-5px)
- Opacidade reduzida (0.3-0.5)
- Simula sombra ambiente para aumentar percepção de profundidade

## SLIDE 1 — JavaScript: A Linguagem da Web (CAPA)

### Objetivo
Impressionar imediatamente. Estabelecer a identidade visual da apresentação. Criar um momento "wow" que prenda a atenção do usuário desde o primeiro segundo. Este slide é a porta de entrada — ele define se o usuário将继续 assistindo ou não.

### Emoção que deve transmitir
Poder, elegância, modernidade. O usuário deve pensar: "Isso vai ser incrível." Deve sentir que está prestes a entrar em uma experiência visual imersiva sobre uma das linguagens mais importantes do mundo.

### Layout
- Layout centralizado e dramático
- O título ocupa a região central do slide, levemente acima do centro vertical (região dos 40-55% da altura)
- Abaixo do título, um subtítulo/descrição curta
- Na parte inferior, navigation dots e barra de progresso
- Setas de navegação nos cantos inferiores
- Background com todas as camadas globais (grid, blobs, partículas, névoa, vignette, noise)

### Organização dos Elementos
1. **Background global** (todas as 7 camadas — já descritas na seção 6)
2. **Partículas distantes** — flutuando suavemente
3. **Blobs amarelos** — drift lento, très difusos
4. **Grid sutil** — estático
5. **Título principal** — "JavaScript" — centro do slide, com efeito 3D extrudado
6. **Subtítulo** — "A Linguagem da Web" — abaixo do título, com animação de fade
7. **Tagline/ano** — "2024" ou badge pequeno abaixo do subtítulo
8. **Navigation dots** — canto inferior中央
9. **Barra de progresso** — acima dos dots
10. **Setas de navegação** — cantos inferiores

### Background
- Todas as 7 camadas globais ativas
- Blobs amarelos mais intensos neste slide (opacidade levemente maior) para criar impacto visual inicial
- Partículas em quantidade moderada (40-50)
- Vignette mais pronunciado para focar no centro

### Elementos Decorativos
- **Código flutuando ao fundo**: trechos de código JavaScript (ex: `const`, `=>`, `{}`, `function`, `[]`) posicionados aleatoriamente no background, com opacidade muito baixa (0.03-0.06), font-size pequena (12-14px), cor rgba(247,223,30,0.04). Eles criam textura temática sem competir com o conteúdo. Movimento: deriva lenta vertical ascendente.
- **Linhas de conexão sutis**: 2-3 linhas diagonais muito finas (1px) com rgba(247,223,30,0.05), conectando pontos distantes do slide. Criam sensação de rede/tecnologia.

### Elementos Interativos
- Navigation dots clicáveis
- Setas de navegação com hover
- Nenhum outro elemento interativo neste slide (é a capa, foco visual puro)

### Elementos Visuais
- **Título "JavaScript"**: efeito 3D extrudado com dezenas de text-shadow (35 camadas). Texto branco (#FFFFFF). Shadow gradiente de amarelo claro (#FFF8DC) até amarelo escuro/dourado (#8B6914). O texto fica horizontal e reto — a profundidade vem apenas do text-shadow.
- **::before do título**: segunda camada de sombra, deslocada 2-3px, com filter: blur(4px), opacidade 0.35, cor #8B6914. Reforça a percepção de profundidade.
- **Subtítulo "A Linguagem da Web"**: fonte menor, peso 400, cor rgba(255,255,255,0.6), animação de fade+slide de baixo

### Partículas
- Tipo: poeira/dust dourada
