Funções e Escopo
Declaração, escopo e closures
Function Declaration
Hoisted. Disponível antes da declaração.
function soma(a, b) { return a + b; }
Function Expression
Atribuída a uma variável. Não é hoisted.
const soma = function(a, b) { return a + b; };
Arrow Function
Sintaxe concisa. Não tem próprio this.
const soma = (a, b) => a + b;
◉ Escopo Global
Variáveis acessíveis em qualquer lugar do programa. Use com moderação.
◉◉ Escopo de Bloco
Variáveis let e const ficam confinadas ao bloco {}.
Closures — O que são e por que importam ▼
Uma closure é quando uma função "lembra" do escopo onde foi criada, mesmo após esse escopo ter terminado.
function criarContador() { let count = 0; return function() { return ++count; }; } const contar = criarContador(); contar(); // 1 contar(); // 2
Objetos e Arrays
Métodos poderosos para manipulação de dados
.map()
Transforma cada elemento e retorna um novo array.
nums.map(n => n * 2)
.filter()
Retorna apenas os elementos que passam no teste.
nums.filter(n => n > 5)
.reduce()
Acumula os elementos em um único valor.
nums.reduce((a,b) => a+b, 0)
.forEach()
Executa uma função para cada elemento (sem retorno).
nums.forEach(n => console.log(n))

Programação Assíncrona
De Callbacks a Async/Await
Essencial
Callbacks
Difícil de ler
getData('user', (user) => { getPosts(user.id, (posts) => { getComments(posts[0].id, (cmts) => { // callback hell }); }); });
Promises
Mais organizado
getData('user') .then(user => getPosts(user.id)) .then(posts => getComments(posts[0].id)) .then(cmts => { /* ... */ }) .catch(err => console.error(err));
Async/Await
Elegante e limpo
async function load() { const user = await getData('user'); const posts = await getPosts(user.id); const cmts = await getComments( posts[0].id); return cmts; }
