O que e JavaScript?

Uma linguagem que revolucionou a web e continua evoluindo

DEFINICAO
Linguagem de programacao de alto nivel, dinamica e interpretada que permite criar aplicacoes web interativas.

Linguagem de Alto Nivel

Dinamica, flexivel e de sintaxe acessivel para desenvolvedores de todos os niveis.

Criada em 1995

Desenvolvida por Brendan Eich em apenas 10 dias para o navegador Netscape.

Web Interativa

Permite criar paginas web dinamicas, interativas e ricas em experiencia.

Client & Server

Executada no navegador Client-side: via motores como V8, SpiderMonkey e tambem no servidor com Node.js Server-side: permite backends completos em JS
