CRIPTOGRAFIA: UTF-8 OBRIGATÓRIO. Declare <meta charset="UTF-8"> e garanta que TODOS os caracteres do arquivo estejam realmente em UTF-8. Nenhum caractere acentuado poderá ser corrompido. Não utilize caracteres especiais diretamente em strings JavaScript sem garantia de encoding.

SISTEMA DE ANIMAÇÕES GLOBAIS
============================================================

PRINCÍPIOS:
- TODOS os elementos iniciam invisíveis (opacity: 0) antes de suas animações
- NENHUM elemento aparece instantaneamente
- As animações são cinematográficas e coreografadas
- Easing padrão: cubic-bezier(0.25, 0.1, 0.25, 1) — suave e natural
- Para elementos que surgem: cubic-bezier(0.16, 1, 0.3, 1) — overshoot sutil
- Para elementos que desaparecem: cubic-bezier(0.4, 0, 1, 1) — desaceleração

DURAÇÕES PADRÃO:
- Títulos: 800-1000ms
- Subtítulos: 700-900ms
- Texto corpo: 600-800ms
- Cards: 700-900ms
- Ícones: 500-700ms
- Efeitos: 1000-1500ms
- Microanimações: 200-400ms

DELAY PADRÃO (entre elementos):
- Título → Subtítulo: 150ms
- Subtítulo → Texto: 100ms
- Texto → Card 1: 100ms
- Card 1 → Card 2: 80ms (stagger)
- Card 2 → Card 3: 80ms
- Etc.
- Atraso total máximo para o primeiro elemento visível: 200ms após o slide ficar ativo

CHOREOGRAFIA PADRÃO (para todos os slides):
1. Background permanece estável (já visível)
2. Elementos decorativos sutis aparecem (se houver)
3. Título principal entra (fade + moveY -20px → 0 + blur 8px → 0)
4. Subtítulo entra (fade + moveY -15px → 0, 150ms depois do título)
5. Conteúdo principal entra (fade + moveY 15px → 0, 100ms depois do subtítulo)
6. Cards/elementos entram em stagger (cada um com 80ms de atraso)
7. Elementos interativos ficam ativos (somente após todas as animações de entrada)
8. Partículas/efeitos de polish iniciam (se aplicável)

ANIMAÇÃO DE SAÍDA (ao trocar de slide):
- Todos os elementos saem com: opacity 0, moveY 10px, duration 400ms
- O slide sai completamente antes do novo entrar
- A saída é mais rápida que a entrada

REINICIALIZAÇÃO:
- Ao voltar para um slide, TODAS as animações reiniciam do zero
- Nenhum elemento fica em estado intermediário
