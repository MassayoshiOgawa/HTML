A navegação é realizada exclusivamente por:

PROIBIÇÕES DE NAVEGAÇÃO:
- O scroll do mouse NÃO troca de slides

BOTÕES DE SETA (CANTOS INFERIORES):
- Posição: canto inferior esquerdo (anterior) e canto inferior direito (próximo)
- Formato: setas simples em SVG (< e >)

NAVIGATION DOTS (CENTRO INFERIOR):
- Posição: parte inferior central, no mesmo nível vertical dos botões de seta

8. SISTEMA DE ANIMAÇÕES GLOBAIS
================================================================================

PRINCÍPIOS FUNDAMENTAIS:
- Nenhum elemento aparece antes de sua animação começar
- O slide atual termina sua saída completamente antes do próximo iniciar
- Existe um intervalo de 80-120ms entre a troca do slide e o início das animações
- Todos os elementos voltam ao estado inicial ao sair do slide
- As animações são reiniciadas completamente ao retornar a um slide

DURAÇÕES PADRÃO:
- Animação de entrada principal: 800-1000ms
- Microanimações (hover, focus): 200-300ms
- Transições de estado: 300-400ms
- Transição entre slides: 500-600ms
- Animações de partículas: 40-80 segundos (ciclo completo)
- Breathing/respiração: 3-6 segundos (ciclo)
- Stagger entre elementos: 80-120ms

EASING PADRÃO:
- Entrada de elementos: cubic-bezier(0.16, 1, 0.3, 1) — desaceleração suave
- Saída de elementos: cubic-bezier(0.7, 0, 0.84, 0) — aceleração suave
- Transições de estado: ease-out
- Microanimações: ease-in-out
- Partículas: linear (movimento constante)
- Breathing: ease-in-out (ciclo suave)

SEQUENCIAMENTO PADRÃO (COREOGRAFIA):
1. Background (imediato, sem delay)
2. Blobs animados (imediato, sem delay)
3. Grid (aparece com fade de 800ms, delay 100ms)
4. Elementos decorativos (delay 200-300ms)
5. Ícones eSVGs (delay 400-500ms)
6. Imagens e gráficos (delay 500-700ms)
7. Cards e painéis (delay 600-800ms)
8. Título principal (delay 300-400ms)
9. Subtítulo (delay 500-600ms)
10. Conteúdo textual (delay 700-900ms)
11. Dados e números (delay 800-1000ms)
12. Botões e elementos interativos (delay 1000-1200ms)
13. Efeitos finais (delay 1200-1400ms)

STAGGER OBRIGATÓRIO:
Quando existirem múltiplos elementos do mesmo tipo (cards, itens de lista, badges, números):
- Delay entre cada: 80-120ms
- Efeito cascata suave
- Todos usam a mesma curva de easing
- O último elemento estabiliza antes do próximo grupo iniciar

ESTADO INICIAL DE TODOS OS ELEMENTOS:
- Opacidade: 0
- Transform: translate Y 20-30px (deslocamento vertical)
- Filter: blur(4px) para elementos de destaque
- Todos os elementos ficam invisíveis até a animação iniciar

ANIMAÇÃO DE SAÍDA:
- Opacidade: 1 → 0
- Transform: translate Y 0 → -10px
- Duração: 300-400ms
- Easing: cubic-bezier(0.7, 0, 0.84, 0)

10. REGRAS DE BLOCOS COM PERSPECTIVA 3D REAL
================================================================================

A apresentação utiliza blocos com perspectiva 3D real como elemento recorrente de identidade visual. Estes blocos aparecem em vários slides ao longo da apresentação, contendo conteúdo real (nunca decoração vazia).

CONFIGURAÇÕES FIXAS:

Tipo 1 — Bloco na metade SUPERIOR do slide (acima de 50% da altura):
  transform: perspective(250px) rotateX(-10deg) rotateY(25deg);
  transform-origin: 50% 50% 0px;
  perspective-origin: 50% 50%;

Tipo 2 — Bloco na metade INFERIOR do slide (abaixo de 50% da altura):
  transform: perspective(250px) rotateX(10deg) rotateY(25deg);
  transform-origin: 50% 50% 0px;
  perspective-origin: 50% 50%;

A ÚNICA DIFERENÇA entre os dois tipos é o rotateX (-10deg vs 10deg). Todas as demais propriedades são idênticas.

LIMITES DE TAMANHO:
- Largura máxima: 350px (teto absoluto, nunca ultrapassar)
- Altura máxima: 420px (teto absoluto, nunca ultrapassar)
- O bloco deve ter o tamanho justo para seu conteúdo — nunca esticar até os limites sem necessidade
- Todo bloco DEVE ter um comentário no código justificando seu tamanho

MATERIAL DO BLOCO:
- Fundo: gradiente linear de cores da paleta (ex: #1E6FD9 para #1565C0, ou tons de cinza)
- Borda: 1px solid rgba(255, 255, 255, 0.1)
- Sombra: sombra coerente com a direção da perspectiva (luz do canto superior esquerdo)
- Highlight: linha sutil na borda superior com rgba(255, 255, 255, 0.15)
- Borda arredondada: 8px
- Padding mínimo: 20px

CONTEÚDO INTERNO:
- O texto herda automaticamente a perspectiva 3D do container
- É PROIBIDO aplicar skew, rotate ou transformação extra no texto
- O conteúdo deve parecer intrinsecamente gravado na superfície perspectivada
- Legibilidade deve ser garantida com tamanho de fonte adequado e padding generoso

ANIMAÇÃO DO BLOCO:
- Entrada: deslize acompanhando a direção da perspectiva + fade
- Duração: 900ms
- Easing: cubic-bezier(0.16, 1, 0.3, 1)
- Delay: variável conforme posição na coreografia do slide

RESPONSIVIDADE:
- Em telas menores que 400px: width: min(350px, 85vw)
- Em tablets: max-width: 350px, max-height: 420px
- A transformação 3D NÃO é removida em telas menores
- O rotateX por posição é MANTIDO em todas as resoluções

PROIBIÇÕES:
- NÃO usar clip-path ou skew 2D para criar falsa perspectiva
- NÃO ultrapassar 350px de largura em nenhuma resolução
- NÃO ultrapassar 420px de altura em nenhuma resolução
- NÃO usar o bloco sem conteúdo real
- NÃO colocar um único bloco com perspectiva exatamente no centro do slide (só se houver 3+ blocos)

Onde usar blocos com perspectiva nesta apresentação:
- Slide 1 (capa): badge "5G" em perspectiva

- Slide 4: destaque "120Hz" e "1300 nits"

11. TÍTULO DA CAPA — EFEITO 3D EXTRUDADO
================================================================================

O título do primeiro slide (Motorola G84 5G) deve utilizar efeito de texto 3D extrudado com múltiplos text-shadow.

REGRA: O texto deve permanecer COMPLETAMENTE RETO (horizontal). NÃO aplique nenhuma rotação, inclinação ou perspectiva ao elemento do título.

EXTRUSÃO:
A profundidade é formada por dezenas de sombras, cada uma deslocada 1px em relação à anterior.

Implementação:
let shadow = "";
for (let i = 0; i < 35; i++) {
    shadow += (shadow ? "," : "") +
              (-i) + "px " +
              i + "px 0 #0B1930"; // cor escura do background, escurecendo progressivamente
}
titulo.style.textShadow = shadow;

COR DAS SOMBRAS DAS EXTRUSÃO:
As sombras devem formar um gradiente de uma cor mais clara (próxima do texto) para uma cor mais escura (longe do texto). NÃO use branco, cinza ou preto para as sombras — use cores vívidas da paleta.

Gradiente das sombras da extrusão (do mais claro ao mais escuro):
- Camadas 0-7: #1E6FD9 (azul médio)
- Camadas 8-15: #1565C0 (azul escuro)
- Camadas 16-23: #0D47A1 (azul profundo)
- Camadas 24-31: #0B1930 (quase preto azulado)
- Camadas 32-35: #080C14 (background)

Implementação com gradiente:
let shadow = "";
for (let i = 0; i < 35; i++) {
    let r, g, b;
    if (i < 8) {
        // #1E6FD9 → #1565C0
        r = Math.round(30 + (21 - 30) * (i / 7));
        g = Math.round(111 + (101 - 111) * (i / 7));
        b = Math.round(217 + (192 - 217) * (i / 7));
    } else if (i < 16) {
        // #1565C0 → #0D47A1
        r = Math.round(21 + (13 - 21) * ((i - 8) / 7));
        g = Math.round(101 + (71 - 101) * ((i - 8) / 7));
        b = Math.round(192 + (161 - 192) * ((i - 8) / 7));
    } else if (i < 24) {
        // #0D47A1 → #0B1930
        r = Math.round(13 + (11 - 13) * ((i - 16) / 7));
        g = Math.round(71 + (25 - 71) * ((i - 16) / 7));
        b = Math.round(161 + (48 - 161) * ((i - 16) / 7));
    } else {
        // #0B1930 → #080C14
        r = Math.round(11 + (8 - 11) * ((i - 24) / 10));
        g = Math.round(25 + (12 - 25) * ((i - 24) / 10));
        b = Math.round(48 + (20 - 48) * ((i - 24) / 10));
    }
    shadow += (shadow ? "," : "") + (-i) + "px " + i + "px 0 rgb(" + r + "," + g + "," + b + ")";
}
