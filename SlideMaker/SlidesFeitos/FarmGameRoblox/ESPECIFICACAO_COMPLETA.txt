================================================================================
1. IDENTIDADE VISUAL — VISÃO GERAL
================================================================================

A apresentação mescla o universo lúdico/natureza de um jogo de fazenda com a
estética tecnológica do desenvolvimento Roblox. É uma fusão "Nature-Tech":
orgânico encontra digital. O visual é limpo, moderno, com cores vibrantes da
natureza (verdes, terra, dourado) sobre fundos escuros que remetem a uma
interface de game HUD. A sensação é de estar dentro de um jogo: imersivo,
colorido, mas profissional.

================================================================================

ESTRUTURA:
- Apresentação em slides (não scroll), 100vw x 100vh cada.

- Apenas um slide visível por vez (opacity + transform).

TROCAR DE SLIDES:

- Botão Anterior (seta esquerda): canto inferior direito, ao lado do Próximo.

  border 1px rgba(149,213,178,0.2), border-radius 50%).
- FadeIn dos botões apenas a partir do slide 2 (slide 1 não tem botões).

NAVEGAÇÃO POR TECLADO:
  Seta Direita / Page Down / L / Espaço: próximo slide
  Seta Esquerda / Page Up / H: slide anterior
  Home: primeiro slide
  End: último slide
  ESC: sai de fullscreen
  F: alterna fullscreen
  Números 1-9: vai para slide 1-9
  Número 0: vai para slide 10

BARRA DE PROGRESSO:
- Barra horizontal fina (4px) no topo da tela, z-index 100.
- Cor: linear-gradient(90deg, #2D6A4F, #52B788).
- Fundo: rgba(255,255,255,0.1).
- Largura animada (CSS transition width 0.5s ease).
- Abaixo, à direita: contador "01 / 20" em Inter 0.8rem, cor #95D5B2, opacidade 0.7.

BOTÃO FULLSCREEN:
- Canto superior direito, ícone de maximizar (16x16px).
- Glassmorphism, visível em todos os slides exceto o 1.

MOUSE WHEEL:
- Roda do mouse avança/volta 1 slide por click.
- Debounce de 800ms para evitar troca múltipla.

TOUCH (SWIPE):
- Swipe esquerda: próximo slide. Swipe direita: anterior.
- Detectado com touchstart/touchend, mínimo 50px de deslocamento horizontal.

NAVEGAÇÃO POR ÍNDICE (atalho "I"):
- Overlay com grid de 20 miniaturas numeradas (80x60px cada).
- Clicar leva ao slide correspondente. Fechar com ESC ou clique fora.
- Miniaturas: fundo #132B1E, número branco grande, borda sutil.

INSTRUÇÕES FINAIS PARA A IA EXECUTORA
================================================================================

1. O arquivo HTML deve ser 100% autocontido. Nenhum arquivo externo além das
   CDNs (Google Fonts, Lucide Icons) deve ser carregado.

2. Use @import no CSS para Google Fonts:
   @import url('https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;600;700;900&family=Inter:wght@300;400;500;600;700&family=JetBrains+Mono:wght@400;700&display=swap');

3. Use Lucide Icons: <script src="https://unpkg.com/lucide@latest"></script>
   e depois lucide.createIcons() no JS.

4. CSS Reset básico no início: *, *::before, *::after { margin:0; padding:0; box-sizing:border-box; }

5. Estrutura HTML:
   <body>
     <div id="progress-bar"><div id="progress-fill"></div><span id="slide-counter">01 / 20</span></div>
     <button id="btn-fullscreen">⛶</button>
     <div id="slides-container">
       <section class="slide active" data-slide="1">...</section>
       <section class="slide" data-slide="2">...</section>
       ... até 20
     </div>
     <div id="navigation">
       <button id="prev-btn">←</button>
       <button id="next-btn">→</button>
     </div>
     <canvas id="bg-canvas"></canvas>
     <!-- cursor personalizado -->
     <div id="custom-cursor"></div>
   </body>

6. JavaScript deve conter:
   - Navegação (teclado, clique, wheel, swipe)
   - Transições entre slides (classe toggle com CSS)
   - Canvas background (blobs, fireflies, grid)
   - Texto 3D no slide 1 (30 camadas text-shadow)
   - Stagger de entrada de elementos
   - Barra de progresso
   - Contador de slides
   - Fullscreen toggle
   - Popups (slide 4 e 19)
   - Hotspots (slide 19)
   - Tooltips
   - Magnetic buttons
   - Cursor personalizado
   - Contadores animados (slide 10 e 18)

7. Responsividade:
   - Desktop: layout completo como especificado.
   - Tablet: fontes reduzem 20%, cards adaptam para 2 colunas.
   - Mobile: fontes reduzem 35%, cards em 1 coluna, botões maiores.
   - Usar media queries (max-width: 1024px, max-width: 768px, max-width: 480px).

8. Performance:
   - requestAnimationFrame para Canvas e animações.
   - Debounce em wheel event (800ms).
   - will-change: transform em elementos animados.
   - Evitar layout thrashing.

9. Transições CSS:
   - Cada slide precisa de classes:
     .slide { position: absolute; top:0; left:0; width:100%; height:100%; opacity:0; pointer-events:none; transition: all 0.6s cubic-bezier(0.25,0.46,0.45,0.94); }
     .slide.active { opacity:1; pointer-events:auto; }
   - As transições específicas (fade, slide, scale, blur, glitch, cube) devem
     ser implementadas com classes CSS adicionais e/ou JS para manipular estilos.
